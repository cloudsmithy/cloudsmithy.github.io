# 如何白嫖嘉立创每个月免费打板？

- URL: https://blog.no-claw.com/de1fd60a/
- 日期: 2025-08-12
- 分类: 电子产品 / 纯硬件
- 标签: 外设

首先，搜索嘉立创下单助手，需要用这个 APP 来领取优惠券。

[图：image-20250812185545780]

左下角 - 优惠群中心 - 免费 PCB 券。每个月可以领取两张。

[图：48dabeb1-2140-4350-9f07-48d85d39aa79]

然后领取这个 1-4 层专用券，可以抵扣 20 元。不完全测试下仅限标准套餐，打磨什么的需要额外加钱，不能抵扣。

[图：ae8bbf60aa7904e6ec1a566cf896205a]

然后回到 PCB，有两种办法

1. 直接在软件页面下单
2. 导出 gerber 文件下单

首先确定 DRC 通过，没有问题。

[图：image-20250812190433561]

[图：image-20250812190659887]

[图：image-20250812190713210]

或者导出还是嘉立创主页：https://www.jlc.com/

[图：image-20250812190601680]

然后就会跳转到下单的平台，我们可以选择 PCB 的类别和参数，数量就选择 5 个，右边显示价格的地方可以选择优惠券。

[图：image-20250812191150619]

选择了优惠券的后，价格直接变成免费。

[图：image-20250812191110649]

出货方式选择单片就行，然后板厚 1.0 - 1.6。颜色除了黄色这种冷门工艺，基本都是在免费范围。（可能会有调整）

绿色的板子是最快的，其他颜色会慢 1-2 天。

[图：image-20250812193640555]

个性化服务大多数都需要额外付费，所以保持默认就好。

[图：image-20250812191658730]

还有一个加 PCB 添加标识的。按照需要使用就好。

[图：image-20250812191959578]

SMT 和刚网通通不需要。然后选择快递下单就可以了。

[图：image-20250812193953001]

剩下就是收板子。
