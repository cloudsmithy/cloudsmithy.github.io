我最早写这些内容，不是为了整理一套 SDK 文档，而是想把自己已经跑在 Docker Compose 里的应用搬进懒猫商店。真正开始做，才发现打包只是第一步，后面还有路由、权限、登录、调试和证书。

开发篇从应用包的基本结构开始，接着处理 Devshell、现有 Compose 项目的移植和完整的构建上架流程。OIDC 分成上下两篇，因为只有把授权跳转、回调、Token 和用户信息走一遍，单点登录才不是一句配置说明。

后面的 OpenResty、Compose Override 和自签名 SSL，都是应用真的跑起来之后遇到的问题。它们不一定会出现在每个项目里，但出现时往往绕不开。

这部分记录的是我验证过的路径，不替代官方文档。Manifest 字段、构建工具和商店规则可能调整，照着做之前最好再对照当前文档；但从 Compose 到应用包的思路，以及排查路由和认证的方法，仍然可以复用。
