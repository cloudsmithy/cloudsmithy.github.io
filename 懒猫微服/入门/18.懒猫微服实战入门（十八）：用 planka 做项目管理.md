工作里用 Jira 管理项目进度。在家里，我也想找个类似的软件来管理一些长期事项，如果能支持多人协作就更好了。在网上找了很久，一直没有遇到特别合适的，直到在懒猫微服中找到 Planka。对比几个同类软件之后，我决定用它来管理自己的事情。

其他的软件体验不佳的点主要是：

1. 付费，而且大多是订阅制，没有找到合适的买断制软件
2. 界面太丑，操作太复杂
3. SaaS 免费版延迟太高
4. 移动端访问体验不佳

Planka 算是解决了大部分的问题：

![Planka 项目看板首页](https://raw.githubusercontent.com/cloudsmithy/picgo-imh/master/image-20250706142600994.png)

虽然这个页面不算特别现代，但也不丑，响应速度很快。其他软件大多比较臃肿，要么延迟很高，影响使用体验。

简洁的 UI 和快速的响应，很好地诠释了 Less is more。

进入主页之后可以新建多个项目，算是一个隔离吧，虽然我目前也只是用到了一个。

![image-20250706140800760](https://raw.githubusercontent.com/cloudsmithy/picgo-imh/master/image-20250706140800760.png)

每个 Project 都能创建多个 Board，这样就能把不同类别的事情区分开。

然后在每个 Board 上用 Todo、Doing、Pending、Done、Deprecated 标记事情的进度，有点白板卡片的味道。不用像线下那样写贴纸来回移动，也不用再支付软件订阅费用。

![Planka 看板用 Todo、Doing、Pending 和 Done 列表跟踪任务进度](https://raw.githubusercontent.com/cloudsmithy/picgo-imh/master/103a3a28-0ceb-466d-9d96-50161d150b04.png)

这个是我和前端协作开发时候一起做的 Dashboard，当时在一起开发一个前后端分离的大语言模型的 APP。

![8703083443e36972236a8450eab7c1c7](https://raw.githubusercontent.com/cloudsmithy/picgo-imh/master/8703083443e36972236a8450eab7c1c7.png)

只要给他新建一个用户，再分配某个面板的权限，就可以一起愉快地协作了。（前提是他安装了懒猫微服客户端，并且拥有这个 App 的访问权限。）

![image-20250706145557778](https://raw.githubusercontent.com/cloudsmithy/picgo-imh/master/image-20250706145557778.png)

这里可以查看面板的详细参数：把 Task 分配给某个成员，添加任务描述、拆解子任务，也可以让成员发表评论。拿来记录 Change Log 还不错，至少测试过程可以随手记在这里。

![image-20250706140941967](https://raw.githubusercontent.com/cloudsmithy/picgo-imh/master/image-20250706140941967.png)

Dashboard 功能还需要继续探索，比如计时、打标签之类的功能。

不过我目前用到的功能就这么多，也算能基本覆盖全部的场景了。

这是我用 Planka 追踪懒猫微服写作和应用上架事项的看板，确实帮了我很多。

![image-20250707080727189](https://raw.githubusercontent.com/cloudsmithy/picgo-imh/master/image-20250707080727189.png)
