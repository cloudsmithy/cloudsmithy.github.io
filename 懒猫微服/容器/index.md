date: 1970-01-01 08:00:00

我用了很久 Docker，后来发现很多问题并不是命令不会写，而是镜像、容器、宿主机和数据卷之间的关系一直没有真正想清楚。于是有了这五篇小故事。

从“在我电脑上明明能跑”开始，后面依次讲镜像、运行中的容器、持久化数据，以及多个服务怎样交给 Docker Compose 管理。旅馆、部落和岛屿只是帮助理解的比喻，最后还是要回到真实的目录、进程、网络和配置文件。

这部分适合先建立直觉，再去看命令和文档。它不会替代一份完整的 Docker 手册，也不承诺读完就能处理所有容器问题；至少下一次看到镜像层、卷挂载或 Compose 依赖时，不会只剩下一堆需要背的名词。
