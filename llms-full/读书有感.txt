## 《搞定》个人工作流 SOP

- URL: https://blog.no-claw.com/db9df156/
- 日期: 2026-09-16
- 分类: 读书有感
- 标签: 效率, 搞定三部曲

> **SOP 编号**：GTD-PW-001
> **版本**：1.0
> **适用范围**：个人工作与生活事务管理
> **依据**：《搞定Ⅰ》的五步工作流与自然式计划法、《搞定Ⅱ》的 52 项原则和基本要素、《搞定Ⅲ》的掌控与视角模型
> **相关资料**：[搞定(AI提取)](/6220a80a/) · [《搞定》实践清单手册](/f009420a/)

### 一、目的

建立一个可信的外部系统，使所有需要关注的事项都能经过同一套流程：

1. 被及时捕捉；
2. 被明确其意义；
3. 被放进正确的位置；
4. 在需要时被重新看到；
5. 转化为可以执行的行动。

执行本 SOP 的完成标准不是“把所有事情做完”，而是：

- 知道自己已经承诺了什么；
- 知道每件事下一步怎样推进；
- 知道暂时不做的事情存放在哪里；
- 能够放心地专注于当前选择。

### 二、输入与输出

#### 输入

任何正在吸引注意力的内容：

- 电子邮件、聊天消息和语音留言；
- 文件、票据、会议记录和便条；
- 别人提出的请求；
- 自己作出的承诺；
- 突然产生的想法；
- 尚未解决的问题和担忧；
- 工作、家庭、健康、财务等方面的变化。

#### 输出

每项输入必须转化为以下结果之一：

| 输出位置 | 内容 |
| --- | --- |
| 删除／垃圾 | 没有价值且不需要行动 |
| 参考资料 | 不需要行动，但以后可能查询 |
| 将来／也许 | 目前不承诺，以后可能启动 |
| 日程表 | 必须在指定日期或时间发生 |
| 项目清单 | 需要两个及以上行动才能完成的结果 |
| 下一步行动 | 已明确、可以直接开始的具体动作 |
| 等待清单 | 由别人负责、自己仍需追踪 |

### 三、执行频率

| 流程 | 执行频率 |
| --- | --- |
| 捕捉 | 事项出现时立即进行 |
| 工作篮处理 | 每天进行，全部入口在 24～48 小时内清零 |
| 日程表检查 | 每天开始工作前，并在日程变化后检查 |
| 行动清单检查 | 每次选择下一项工作时 |
| 项目和等待清单回顾 | 每周一次 |
| 完整每周回顾 | 每 7 天一次，初期预留连续两小时 |
| 责任范围检查 | 大约每月，或职责发生变化时 |
| 一两年目标检查 | 按季度或至少每年一次 |
| 长期愿景、宗旨和原则 | 每年、重大变化或重要取舍时 |

### 四、标准流程

```mermaid
flowchart TD
    A[事项出现] --> B[立即捕捉]
    B --> C[进入工作篮]
    C --> D{这是什么？}
    D --> E{需要行动吗？}
    E -- 否 --> F[删除]
    E -- 否 --> G[参考资料]
    E -- 否 --> H[将来／也许]
    E -- 是 --> I[明确完成结果]
    I --> J{需要多个步骤吗？}
    J -- 是 --> K[加入项目清单]
    J -- 否 --> L[明确下一步行动]
    K --> L
    L --> M{两分钟内能完成吗？}
    M -- 是 --> N[立即执行]
    M -- 否 --> O{应由别人完成吗？}
    O -- 是 --> P[委派并加入等待清单]
    O -- 否 --> Q{有指定日期或时间吗？}
    Q -- 是 --> R[加入日程表]
    Q -- 否 --> S[加入行动清单]
    N --> T[定期回顾]
    P --> T
    R --> T
    S --> T
    T --> U[选择并执行]
```

#### 步骤 1：捕捉

##### 触发条件

只要一件事开始占据注意力，就启动捕捉。

##### 操作

1. 用固定工具写下或收下这件事；
2. 一条记录只表达一件事；
3. 暂时不判断优先级；
4. 暂时不展开计划；
5. 将记录放进会被处理的工作篮。

##### 完成标准

- 事项已经离开大脑；
- 记录足以让自己之后想起原意；
- 知道这条记录何时会再次被看到。

#### 步骤 2：明确意义

从工作篮最上面一项开始，一次处理一项，不挑选，不原样放回。

依次回答：

1. **这是什么？**
2. **需要行动吗？**
3. **如果完成，想得到什么结果？**
4. **下一步可以直接执行的动作是什么？**

##### 不需要行动

- 没有价值：删除；
- 以后可能有用：归入参考资料；
- 以后可能去做：归入将来／也许；
- 只在未来某日才需要看到：设置日期提醒。

##### 需要行动

先明确完成结果。一个行动无法完成的事项，同时加入项目清单。

下一步行动必须可以直接开始，例如：

- “给财务打电话确认预算口径”；
- “搜索三家供应商的报价”；
- “起草给客户的确认邮件”。

“研究一下”“推进项目”“处理合同”不算已经明确的行动。

##### 完成标准

- 材料的意义已经明确；
- 需要的完成结果已经写出；
- 下一步行动已经决定；
- 不再需要重新思考同一个问题。

#### 步骤 3：组织整理

根据前一步作出的决定归位。

##### 日程表

只放三类内容：

1. 指定时间的行动；
2. 指定日期的行动；
3. 指定日期才需要看到的信息。

普通任务不得因为“希望今天完成”就放进日程表。

##### 项目清单

使用完成结果描述项目，例如：

- “合同完成双方签署”；
- “父母体检安排完成”；
- “新网站上线”。

每个活跃项目至少有一个下一步行动。

##### 下一步行动清单

按真正影响执行的情境分类，例如：

- 电话；
- 电脑；
- 办公室；
- 家；
- 外出；
- 阅读／回顾。

##### 等待清单

至少记录：

```text
责任人｜等待的结果或行动｜委派日期｜约定日期｜下次跟进
```

##### 完成标准

- 所有处理结果已经归位；
- 行动出现时能快速找到；
- 项目资料没有代替项目和行动提醒；
- 会议记录和邮件中没有隐藏的承诺。

#### 步骤 4：选择并执行

每天先查看日程表，再从行动清单选择工作。

选择顺序：

1. **情境**：现在能在哪里、使用什么工具、联系什么人？
2. **时间**：距离下一项固定安排还有多久？
3. **精力**：当前适合深度工作还是简单任务？
4. **相对重要性**：剩余选项中哪一项最值得现在做？

日常工作分成三种状态：

- 执行预先确定的工作；
- 处理突然出现的工作；
- 收集、明确和重新定义工作。

切换之前确认：

- 新事项是否真的要求立刻改变计划；
- 如果暂时不处理，是否已经捕捉；
- 当前行动是否仍服务于有效的项目和目标。

##### 完成标准

- 同一时刻只专注于一个行动；
- 改变计划是有意识的决定；
- 新事项不会因为打断而遗失；
- 行动结束后，相关清单得到更新。

#### 步骤 5：每日维护

##### 开始工作前

- [ ] 查看今天的日程表；
- [ ] 查看未来一两天需要提前准备的事项；
- [ ] 确认可用时间和当前情境；
- [ ] 选择第一项行动。

##### 工作结束前

- [ ] 收集桌面和临时记录；
- [ ] 记录新产生的项目和行动；
- [ ] 更新已经完成的行动；
- [ ] 更新等待事项；
- [ ] 查看明天的日程；
- [ ] 确认工作篮何时处理。

#### 步骤 6：每周回顾

每周回顾分为三个阶段。

##### A. 保持清爽

- [ ] 收集零散纸片、票据、会议记录和临时笔记；
- [ ] 清空纸质和电子工作篮；
- [ ] 写下脑中尚未进入系统的事项。

##### B. 保持最新

- [ ] 查看过去的日程，提取遗留行动和信息；
- [ ] 查看未来几周，发现准备事项和日期冲突；
- [ ] 更新下一步行动清单；
- [ ] 更新等待清单；
- [ ] 逐项查看项目清单；
- [ ] 确保每个项目至少有一个下一步行动；
- [ ] 查看议事日程和将来／也许清单。

##### C. 发挥创造性

- [ ] 有什么新项目值得启动？
- [ ] 哪个项目应当暂停或取消？
- [ ] 有什么可以委派？
- [ ] 哪个重复问题需要建立核查清单？
- [ ] 将来／也许中有什么现在可以启动？

##### 每周回顾完成标准

- 项目清单完整、清楚、最新；
- 每个活跃项目都有下一步行动；
- 等待事项知道由谁负责、何时跟进；
- 日程表准确反映未来的硬边界；
- 可以直接根据行动清单开始工作；
- 大脑不必继续承担提醒责任。

### 五、项目规划子流程

当项目模糊、停滞、多人协作或风险较高时，执行自然式计划：

1. **宗旨**：为什么要做？
2. **原则**：有哪些不能突破的边界？
3. **成功结果**：大功告成是什么样？
4. **头脑风暴**：已知什么、未知什么、有哪些可能性？
5. **组织整理**：组成部分、顺序、优先级和责任人是什么？
6. **下一步行动**：现在由谁做什么？

项目计划完成后，必须把具体结果放回项目清单，把动作放回日程表、行动清单或等待清单。

### 六、异常与恢复流程

#### 真正紧急的事项

先处理人身、财务、法律、业务风险和当天的硬日期事项。计划已经无法兑现时，立即通知相关人员并重新商定承诺。

#### 系统失控

依次执行：

1. 停止在脑中反复排序；
2. 写下所有正在吸引注意力的事项；
3. 收集散落材料和消息；
4. 逐项明确结果和下一步行动；
5. 更新项目、行动、等待和日程表；
6. 查看未来几天的硬日期；
7. 选择一个当前可以执行的行动；
8. 安排一次完整每周回顾。

#### 判断最薄弱的环节

| 表现 | 薄弱环节 | 修复动作 |
| --- | --- | --- |
| 害怕遗漏，脑中一直记事 | 捕捉 | 进行大脑清扫，统一入口 |
| 清单都是“推进、处理、研究” | 明确 | 写出结果和具体行动 |
| 知道要做，但找不到记录 | 组织 | 统一清单和归档位置 |
| 不愿查看清单 | 回顾 | 执行完整每周回顾 |
| 一直规划，很少完成 | 参与 | 选择一个动作并执行 |
| 做了很多事，不知道为了什么 | 视角 | 检查项目、责任和目标 |

### 七、质量检查

每周回顾结束时确认：

- [ ] 所有捕捉入口都在控制之下；
- [ ] 工作篮中没有长期积压的不明事项；
- [ ] 日程表只保存硬日期；
- [ ] 项目都以完成结果描述；
- [ ] 每个项目都有下一步行动；
- [ ] 下一步行动可以直接执行；
- [ ] 等待事项包含责任人和跟进时间；
- [ ] 参考资料能够快速找到；
- [ ] 系统没有因为分类和工具过多而变得难用；
- [ ] 面对压力时，自己会使用系统而不是放弃系统。

### 八、一页执行版

```text
事项出现
  ↓
立即捕捉，进入工作篮
  ↓
这是什么？
  ↓
需要行动吗？
  ├─ 否：删除／参考资料／将来或也许
  └─ 是：
       1. 想得到什么结果？
       2. 是否是项目？
       3. 下一步具体行动是什么？
       4. 两分钟内完成 → 立即做
       5. 应由别人完成 → 委派＋等待
       6. 指定日期或时间 → 日程表
       7. 其余 → 下一步行动清单

每天：
  日程表 → 情境清单 → 选择一个行动 → 专心完成

每周：
  收集 → 清空工作篮 → 更新日程 → 更新行动
  → 更新等待 → 逐项检查项目 → 查看将来／也许

失控时：
  先处理真实紧急事项 → 大脑清扫 → 明确结果
  → 找出下一步行动 → 恢复每周回顾
```

## 潇洒姐《时间看得见》摘抄和感受

- URL: https://blog.no-claw.com/7c4ae2d1/
- 日期: 2026-09-04
- 分类: 读书有感
- 标签: 效率

和《山洞四律》一样，还是那套"把时间显性化"的思路，只是这本更偏工具和表格。

核心就一句话：

> 复盘的核心功能是为自己建立一个系统。让自己做事依靠系统，而不是单纯依靠感觉。系统能帮助你分散精力和关注点，能区别现象和本质。

### 一、一天的八项时间配额

| # | 配额 | 说明 |
|---|---|---|
| 1 | 保证睡眠 | 7 小时 |
| 2 | 健身 | 1 小时 |
| 3 | 公司生存 | 现金流和销售业务 |
| 4 | 公司发展 | 策略、人、资源、钱 |
| 5 | 传播认知和点燃团队成员 | 谈话 30 分钟 |
| 6 | 长板时间 | 打磨优势 |
| 7 | 瓶颈时间 | 补最卡住的那一环 |
| 8 | 心流专注时间 | 可与长板时间重合，也可以分配给转移注意力的情绪处理型心流活动 |

看下来最有启发的是 **6 和 7 分开算**。平时容易只干长板（爽）或者只补瓶颈（累），两者各占独立时间块才不会互相吞掉。

另外 1、2 排在最前面——睡眠和健身是底线，不是变量。

### 二、复盘四步法

整个方法论是一个无限循环：

```
计划 → 行为 → 结果 → 比对 → 追问 → 解决方案 → 再计划
```

#### 第一步，回顾目标

找到一个里程碑，拿出纸笔，写下里程碑的名字。这件事要非常具体，而且必须是你曾经计划过的，包括**起点状态、目标、行为、周期**。

> 请确保这些因素在计划设立初期都存在过，如果不存在，你需要重新制订计划，重写剧本。

这条挺狠的。很多所谓的复盘其实是事后编故事，因为当初根本没有计划。

#### 第二步，评估结果

目标一定有一个或更多**可以量化的数字指标**，只有如此，才可以检视目标达成情况和行为实施情况。

写下三样东西，和原始指标做对比：

- 实际终点状态
- 目标达成情况
- 行为实施情况

目的是明晰计划和现实两者之间的**差距**。

#### 第三步，分析原因（最重要的一环）

在每个差距下面做"鱼骨式"追问：

1. 罗列所有原因
2. **分类**。一般原因可分为材料、人员、环境、方法、设备等
3. 在每一个分类下继续追问，直到无法继续追问为止
4. **评估**。将所有原因分为三类：

| 类别 | 含义 | 该怎么办 |
|---|---|---|
| **C**（Controllable） | 知道解决方案在可控范围内 | 直接写进行动清单 |
| **X**（Experimental） | 不知道解决方案，需要进一步探索、咨询 | 转成一个调研任务 |
| **N**（Noise） | 命运操控的部分，超出可控范围 | 放下，别在这儿发力 |

CXN 这个分类很实用。以前复盘完容易陷在一堆自责里，其实很多是 N，标出来就可以放下了；X 也不该当成失败，它只是"还没研究"。

#### 第四步，总结经验

> 对于每一层问题的追问，你必须填写解决方案。你如果在这一层不能给出答案，再填一层追问，直到全部能回答。请你将所有解决方案都重点标记、合并同类项，形成一份行动清单，纳入下一次的执行当中。

> 任何不以改变行为为目的的复盘都是"耍流氓"。新行为必须被执行，否则一切所谓的复盘都徒劳无功。

复盘的三个维度：**灵魂、肉体、金钱**。

---

顺一句：这套东西本质就是 **PDCA**。计划 = Plan，行为 = Do，结果/比对/追问 = Check，解决方案/再计划 = Act。鱼骨图就是石川图（Ishikawa diagram），出自日本 TQM，和 PDCA 同属戴明那一脉；"材料、人员、环境、方法、设备"是制造业经典的 5M 分类。她提到的"联想式复盘"则源自美军的 AAR。

有增量的地方在于她给 **C 阶段做了加法**。PDCA 在个人实践里最容易废掉的环节正是 Check——大多数人的 Check 就是一句"这次没做好"，然后直接跳到 Act 拍一个新计划。她把 Check 拆成三步（量化结果 → 与原始指标比对 → 鱼骨式下钻），再用 CXN 给原因分诊。而"不以改变行为为目的的复盘都是耍流氓"守的是 Act 那一环，也正是 PDCA 断链最常见的位置。

---

### 三、两个补充机制

**问题日志**——如果在鱼骨式追问中发现某个问题重复出现，就要给自己建立问题日志。

> 就像我们在上学时候，哪儿错的多，哪儿就多验算。错误日志对照得多了，你就会形成行为的条件反射，这种条件反射就是一种行为的内化，你会慢慢进入高手的境界。

**邀请别人推演**——复盘首先肯定是一个人做，之后可以邀请别人一起推演："要是你，你接下来怎么写？"一千个编剧心中有一千个哈姆雷特。

### 四、几句摘抄

> 哪有不经过彩排和推敲的好戏呢？偶然的精彩是运气，经常性的精彩一定是"运维"的结果。电影如是，人生也如是。

> 我最怕所有的问题最后就归于一个字——懒。

> 如果说联想式复盘是企业的一种管理方式，那么其管理的是商业结果。我这种复盘可以叫个人电影制片人管理，管理的是个人的人生质量和体验。说白了就是看回放、改剧本、调整人设。

> 保持好奇心，保持将事情弄明白的兴趣。每日，每月，每年，以求寸进。

> 坚信自己的人生是一场好戏，永远期待下一场好戏。

### 六、富兰克林的手账法

书里拿富兰克林当范例。他兴趣广泛，手账内容也很多元——小至酿造葡萄酒的方法，大至讨论美国州议会推行的新政策。作者认为，这一切外部条件，包括使用手账，都奠定了他一生成就的基础。

他在自传里写：

> 我想出了一个达到完美品德的勇敢而艰辛的计划。我期望一生当中的任何时候都能够不犯任何错误，我想克服所有缺点，不管它们是因为天生的爱好、后天的习惯，还是由交友不慎引发的。

#### 十三条"自我修炼戒律"

| # | 德行 | 释义 |
|---|---|---|
| 1 | 节制 Temperance | 食不过饱，饮不过量 |
| 2 | 沉默 Silence | 言必于人于己有益；禁止无益的闲谈 |
| 3 | 秩序 Order | 一切东西都有自己的位置；日常事务何时起、何时完，当有它们的安排 |
| 4 | 决心 Resolution | 当做必做；决心要做的事坚持不懈 |
| 5 | 俭朴 Frugality | 用钱必于人于己有益，戒除浪费 |
| 6 | 勤劳 Industry | 勿浪费时间；每时每刻做有用的事，戒除不必要的行动 |
| 7 | 诚恳 Sincerity | 不欺骗人；勿思邪恶，唯念正义，说话也应如此 |
| 8 | 正直 Justice | 不做有害他人的事，也不要忘记履行对人有益的应尽义务 |
| 9 | 中庸 Moderation | 避免极端；若受到应得的处罚，要容忍，勿发怒 |
| 10 | 清洁 Cleanliness | 身体、衣服、住所力求清洁 |
| 11 | 宁静 Tranquility | 勿因琐事或无法避免的普通小事而惊慌失措 |
| 12 | 贞洁 Chastity | 除为了健康或者生育后代，不行房事；万不可房事过度伤害身体，不要损害自己或者他人的安宁或者名誉 |
| 13 | 谦逊 Humility | 仿效耶稣和苏格拉底 |

#### 关键不在这十三条，而在执行策略

> 富兰克林认为，同时全面实行会分散注意力，他的策略是在一个时期内集中精力只培养一条，达到了一条之后，再开始另外一个。这叫作集中优势资源，各个击破。

具体做法是做一个小册子：

- 每一种德行占用一页
- 横轴按周一至周日分成 **7 列**，纵轴分成 **13 行**，每行是一个美德的缩写
- 用小黑点记录这一天是否做到
- 每一周只专注培养一条——比如这周重点是"节制"，就保证"节制"那一行不出现小黑点，其他美德只是顺带记录

13 条 × 每周一条 = **一个季度一轮，一年跑四轮**。这个节奏感比"从明天起我要全面改变"靠谱得多。

#### 他的作息时间表

| 时间 | 安排 |
|---|---|
| 5:00 | 起床，自省：**今天我将有何收获？** |
| 5:00—7:00 | 起床、洗漱、向万能的上帝祈祷、安排一天的事情，继续研究，吃早饭 |
| 8:00—11:00 | 工作 |
| 12:00—13:00 | 读书、浏览账单、吃午饭 |
| 14:00—17:00 | 工作 |
| 18:00—21:00 | 再次自省：**今天我有什么收获？** 然后把东西归位，吃晚饭、听音乐、娱乐、聊天 |
| 22:00—4:00 | 睡觉 |

结构上就是**早问 + 晚省**，两个问题把一天封口。中间两段各三小时的工作块，其余全是恢复。看着比现在很多人的作息克制多了。

### 七、如果回到 20 岁不会再做的事

> 第一是虚度时间；第二是不敢试错；第三是没有开始 1 万小时的追求、专注和喜爱；第四，没有离家；第五，没有健身，没有在巅峰年纪让我的身材进入巅峰状态。

### 总的感受

这本和《山洞四律》连起来看是完整的：**山洞四律解决"怎么把注意力收回来"，时间看得见解决"收回来之后怎么记账和迭代"**。

真要落地，我打算先只做三件事：

1. 八项配额里挑出**长板 / 瓶颈**两个独立时间块
2. 复盘时套 **CXN** 分类
3. 富兰克林式**一次只改一条**习惯

## 《搞定》实践清单手册

- URL: https://blog.no-claw.com/f009420a/
- 日期: 2026-08-28
- 分类: 读书有感
- 标签: 效率, 搞定三部曲

> **使用范围**：这不是三本书的内容提炼，而是根据《搞定Ⅰ》的五步工作流与自然式计划法、《搞定Ⅱ》第五部分的核查清单，以及《搞定Ⅲ》的掌控与视角模型、实际运用方法整理成的实践手册。
>
> 原理和原书例子见 [搞定(AI提取)](/6220a80a/)。需要简短流程时使用 [《搞定》个人工作流 SOP](/db9df156/)。这篇只保留执行时需要查看、填写和勾选的内容。

### 一、先记住这几条规则

- [ ] 大脑用来思考，不用来保存提醒。
- [ ] 任何持续吸引注意力的事情，都先进入外部系统。
- [ ] 收集、明确、组织、回顾和执行是五个不同动作。
- [ ] 意义先于条理。先决定一件事是什么，再决定放在哪里。
- [ ] 项目不能直接执行，只能执行下一步具体行动。
- [ ] 日程表只放必须在特定日期或时间发生的事情。
- [ ] 清单只有持续更新和回顾，才值得信任。
- [ ] 已经接受的承诺只有三种处理办法：完成、取消或重新商定。
- [ ] 系统只提供可信的行动选项，最后仍由自己作出选择。

### 二、建立自己的 GTD 系统

> **来源：《搞定Ⅰ》第 4 章、《搞定Ⅲ》第 18 章。**

#### 1. 准备捕捉入口

捕捉工具不必统一成同一种形式，但入口不能多到自己也记不清。

- [ ] 办公桌上有一个实体工作篮。
- [ ] 随身有一种能立即记录的工具。
- [ ] 手机上有一个固定的快速记录入口。
- [ ] 电子邮件有明确的收件箱。
- [ ] 语音、聊天消息和会议笔记有固定的汇总位置。
- [ ] 家里有一个收集票据、信件和待处理物品的位置。
- [ ] 所有捕捉入口都能在之后被清空。

**检查：**

- 我现在突然想到一件事，会写在哪里？
- 写完以后，我什么时候会重新看到它？
- 是否存在自己已经忘记检查的记录工具？

如果第三个问题的答案是“有”，就减少入口，或把旧入口中的内容迁移到主系统。

#### 2. 建立八类基本容器

- [ ] **日程表**：必须在指定日期或时间发生的行动、约会和信息。
- [ ] **项目清单**：需要两个及以上行动才能完成的结果。
- [ ] **下一步行动清单**：已经明确、可以直接执行的具体动作。
- [ ] **等待清单**：已经交给别人，但仍需自己追踪的结果和行动。
- [ ] **议事日程清单**：下次见到某个人或参加某个会议时要讨论的内容。
- [ ] **将来／也许清单**：尚未承诺，但以后可能启动的想法。
- [ ] **项目辅助资料**：项目的计划、草稿、研究材料和相关文件。
- [ ] **参考资料**：不需要行动、以后可能查阅的信息。

#### 3. 按情境拆分行动清单

只建立真正能帮助选择行动的分类。常见分类如下：

- [ ] 电话
- [ ] 电脑
- [ ] 办公室
- [ ] 家
- [ ] 外出事宜
- [ ] 阅读／回顾
- [ ] 任何地方
- [ ] 低精力也能完成

如果某个分类长期没有内容，或者每次选择行动时都不起作用，可以删除。系统的分类是为了方便执行，不是为了追求形式完整。

#### 4. 建立工作台和参考系统

- [ ] 办公室有一个可以直接开始工作的固定位置。
- [ ] 家里有一个可以处理个人事务的位置。
- [ ] 外出时有一套最小化的移动工作工具。
- [ ] 常用工具伸手可取。
- [ ] 项目辅助资料和一般参考资料能够被快速区分。
- [ ] 纸质资料有统一归档方法。
- [ ] 电子资料有固定命名和保存位置。
- [ ] 找一份普通参考资料不需要翻遍多个地方。

### 三、第一次大脑清扫

> **来源：《搞定Ⅰ》第 5 章、《搞定Ⅲ》第 4 章和附录“未完成事务提示清单”。**

第一次收集时不要分类、排序或评估。每张纸、每一行只写一件事。

#### 1. 扫描周围环境

- [ ] 办公桌表面
- [ ] 桌下和桌旁
- [ ] 抽屉
- [ ] 书架和文件柜
- [ ] 白板和公告栏
- [ ] 背包、公文包和钱包
- [ ] 纸质信件、票据和名片
- [ ] 下载目录和电脑桌面
- [ ] 浏览器标签页和收藏夹
- [ ] 电子邮件和聊天消息
- [ ] 家中需要修理、归还、购买或处理的物品

只要某件东西不是办公设备、装饰或已经归位的参考资料，而且它正在提醒你“还要处理”，就把它放进工作篮，或者为它写一条提示。

#### 2. 清扫脑中的未完成事务

##### 工作

- [ ] 尚未完成的项目
- [ ] 已经承诺但还没有开始的事情
- [ ] 要回复的人
- [ ] 要安排的会议
- [ ] 要提交的材料
- [ ] 要作出的决定
- [ ] 要学习或调查的问题
- [ ] 要修复的流程和设备
- [ ] 团队、客户和合作方的问题
- [ ] 预算、合同、付款和报销
- [ ] 可能错过的截止日期
- [ ] 想提出但还没有说出的建议

##### 个人

- [ ] 家庭和亲友
- [ ] 健康、体检和用药
- [ ] 财务、账单、保险和税务
- [ ] 房屋、车辆和设备维护
- [ ] 购物和补充物品
- [ ] 旅行和活动安排
- [ ] 要归还或借出的东西
- [ ] 想学习的技能
- [ ] 想去的地方
- [ ] 想尝试但还没有承诺的事情
- [ ] 对未来一两年的担忧和期待
- [ ] 长期愿景、价值观和人生方向

#### 3. 收集完成的判断

- [ ] 继续看周围环境时，没有明显物品在提醒我“处理一下”。
- [ ] 暂停几分钟后，脑中出现的新事项都已写下。
- [ ] 没有因为觉得事情太小、太大或太难而故意跳过。
- [ ] 尚未判断优先级，也没有急着建立大量分类。

### 四、清空工作篮

> **来源：《搞定Ⅰ》第 6 章、《搞定Ⅱ》第五部分“处理与组织整理流程图”、《搞定Ⅲ》第 5 章。**

处理工作篮时，一次只拿一项，从最上面开始，不挑喜欢的，不把拿出来的东西原样放回。

```mermaid
flowchart TD
    A[拿起一项材料] --> B{这是什么？}
    B --> C{需要行动吗？}
    C -- 不需要 --> D[删除／丢弃]
    C -- 不需要 --> E[参考资料]
    C -- 不需要 --> F[将来／也许或指定日期提醒]
    C -- 需要 --> G[明确想得到的结果]
    G --> H{需要多个步骤吗？}
    H -- 是 --> I[加入项目清单]
    H -- 否 --> J[继续明确行动]
    I --> J[确定下一步具体行动]
    J --> K{两分钟内能完成吗？}
    K -- 是 --> L[立即完成]
    K -- 否 --> M{应该由别人完成吗？}
    M -- 是 --> N[委派并加入等待清单]
    M -- 否 --> O{必须在特定日期或时间完成吗？}
    O -- 是 --> P[加入日程表]
    O -- 否 --> Q[加入下一步行动清单]
```

#### 逐项处理清单

- [ ] 这到底是什么？
- [ ] 它需要采取行动吗？
- [ ] 如果不需要行动，是垃圾、参考资料，还是将来／也许？
- [ ] 如果需要行动，我想得到什么结果？
- [ ] 这个结果能否通过一个行动完成？
- [ ] 如果不能，是否已经加入项目清单？
- [ ] 下一步可以观察到的具体动作是什么？
- [ ] 两分钟内能完成吗？
- [ ] 应该自己做，还是交给别人？
- [ ] 如果委派，是否记下责任人和委派日期？
- [ ] 如果延后，它属于日程表还是行动清单？
- [ ] 相关材料放在哪里？

#### 把模糊任务改成具体行动

| 模糊写法 | 可以执行的写法 |
| --- | --- |
| 处理预算 | 给财务打电话确认预算口径 |
| 研究打印机 | 搜索三款支持双面扫描的打印机 |
| 推进合作 | 起草给合作方的确认邮件 |
| 准备会议 | 写出会议要解决的三个问题 |
| 搞定年检 | 打开交管网站查看所需材料 |
| 整理旅行 | 给酒店打电话确认取消政策 |
| 学英语 | 打开课程完成第一节练习 |

下一步行动必须是可以直接开始的动作。只写“研究、推进、处理、准备、规划”，通常还没有完成明确意义这一步。

#### 两分钟原则的边界

- [ ] 两分钟原则用在处理工作篮时。
- [ ] 能在两分钟内完成的行动，立即做掉比记录和追踪更省时间。
- [ ] 如果当前正在完成一项需要专注的重要工作，不因新出现的小事反复中断。
- [ ] 新事项先捕捉，等进入处理状态后再使用两分钟原则。

### 五、组织整理检查表

> **来源：《搞定Ⅰ》第 7 章、《搞定Ⅲ》第 6 章。**

| 容器 | 应该放什么 | 不应该放什么 |
| --- | --- | --- |
| 日程表 | 指定时间的会议、约会、截止动作；指定日期才需要看到的信息 | 希望今天完成、但日期可以变化的普通任务 |
| 项目清单 | 需要多个行动才能完成的明确结果 | 具体动作、参考资料、长期愿望 |
| 下一步行动 | 已经决定、可以直接执行的物理动作 | “推进项目”“研究一下”等模糊事项 |
| 等待 | 别人负责、自己仍需追踪的结果和行动 | 已经完全移交且无须再关注的事情 |
| 议事日程 | 下次与某人或某团队沟通的内容 | 需要立即单独联系对方的紧急事项 |
| 将来／也许 | 目前不承诺、以后可能启动的事情 | 已经决定必须完成的项目 |
| 项目辅助资料 | 当前项目的计划、草稿和研究材料 | 唯一的项目提醒或唯一的下一步行动 |
| 参考资料 | 不需要行动、以后可能查询的信息 | 藏着尚未明确行动的邮件和会议记录 |

#### 项目清单检查

每个项目都用完成时的结果来写：

- [ ] “网站改版完成并上线”
- [ ] “父母体检安排完成”
- [ ] “新合同双方签署完成”
- [ ] “书房照明完成更换”

避免只写：

- “网站”
- “父母体检”
- “合同”
- “书房”

每周回顾时，对每个项目追问：

- [ ] 这个结果仍然需要吗？
- [ ] 当前状态是什么？
- [ ] 是否至少有一个下一步行动？
- [ ] 下一步行动在日程表、行动清单还是等待清单上？
- [ ] 项目辅助资料是否需要更新？

### 六、每日运行清单

> **来源：《搞定Ⅰ》第 8～9 章、《搞定Ⅱ》第五部分、《搞定Ⅲ》第 8 章和第 18 章。**

#### 开始一天

- [ ] 查看日程表，确认今天不能移动的“硬质景观”。
- [ ] 查看未来一两天的安排，确认是否需要提前准备。
- [ ] 确认今天可用的时间、地点和精力。
- [ ] 查看当前情境下的下一步行动。
- [ ] 选定当前要做的一项，开始行动。

日程表决定边界，行动清单提供选择。不要把行动清单中的所有内容都抄到今天的日程表里。

#### 工作过程中

日常工作会在三种状态之间切换：

1. **执行预先确定的工作**：完成日程表和行动清单中的事项；
2. **处理突然出现的工作**：应对真正需要改变计划的新情况；
3. **定义工作**：收集、明确、组织和更新系统。

每次切换时检查：

- [ ] 我是在有意识地改选，还是被最新消息拖走？
- [ ] 新事项是否真的比当前工作更重要？
- [ ] 如果暂时不处理，我是否已经把它捕捉下来？
- [ ] 当前选择是否符合地点、时间和精力条件？
- [ ] 当前行动是否仍服务于有效项目和目标？

#### 选择下一项行动

按顺序排除和判断：

1. **情境**：现在能使用哪些工具？能联系哪些人？身处哪里？
2. **时间**：距离下一项固定安排还有多久？
3. **精力**：当前适合深度思考，还是适合机械性工作？
4. **相对重要性**：剩余选项中，哪一项最值得现在投入？

#### 结束一天

- [ ] 收集桌面、纸条和临时记录。
- [ ] 把新承诺和新想法放入工作篮。
- [ ] 更新已经完成的行动。
- [ ] 记录今天新产生的等待事项。
- [ ] 查看明天日程表。
- [ ] 确认重要材料已经放在明天能找到的位置。
- [ ] 如果工作篮尚未清空，知道何时会处理。

《搞定Ⅲ》给出的维护目标，是让邮件、便条、语音留言等捕捉入口每隔 **24～48 小时**回到清零状态。偶尔积压可以接受，长期积压会让大脑重新接管提醒工作。

### 七、每周回顾清单

> **来源：《搞定Ⅰ》第 8 章、《搞定Ⅱ》第五部分“每周回顾指南”、《搞定Ⅲ》第 9 章和第 18 章。**

每周回顾不是总结得失，而是把系统重新校准到现实。原书建议初期预留一段不受打扰的连续时间，《搞定Ⅲ》给出的参考是 **两小时**。

#### 第一阶段：保持清爽

##### 收集零散材料

- [ ] 收集桌面上的纸片、名片、收据和文件。
- [ ] 收集钱包、背包和衣袋中的待处理物。
- [ ] 汇总会议记录和手写笔记。
- [ ] 汇总临时电子笔记和语音记录。
- [ ] 查看下载目录、电脑桌面和浏览器标签。

##### 清空工作篮

- [ ] 处理纸质工作篮。
- [ ] 处理主电子邮箱。
- [ ] 处理语音留言。
- [ ] 处理聊天工具中已经承诺的事项。
- [ ] 对每一项明确结果和下一步行动。

##### 清空大脑

- [ ] 写下尚未进入系统的新项目。
- [ ] 写下尚未记录的行动。
- [ ] 写下需要等待别人完成的事项。
- [ ] 写下可能放进将来／也许的想法。
- [ ] 写下正在担心但还没有明确的问题。

#### 第二阶段：保持最新

##### 回顾日程表

- [ ] 查看过去的日程，找出遗留行动、决定和参考信息。
- [ ] 查看未来几周，发现需要提前准备的事项。
- [ ] 检查截止日期是否发生冲突。
- [ ] 确认日程表中没有混入可以随意移动的普通任务。

##### 回顾行动清单

- [ ] 勾掉已完成行动。
- [ ] 删除已经失效的行动。
- [ ] 把仍然模糊的事项改写成具体动作。
- [ ] 检查情境分类是否仍然好用。
- [ ] 确认重要行动没有只藏在邮件或项目资料中。

##### 回顾等待清单

- [ ] 标记已经收到的结果。
- [ ] 确认每项等待事务由谁负责。
- [ ] 检查委派日期和约定日期。
- [ ] 决定是否需要催办、询问或重新协商。
- [ ] 把需要跟进的动作加入行动清单或日程表。

##### 回顾项目清单

- [ ] 逐项确认项目仍然有效。
- [ ] 逐项确认项目描述的是完成结果。
- [ ] 逐项确认至少存在一个下一步行动。
- [ ] 查看需要关注的项目计划和辅助资料。
- [ ] 补入本周新产生但尚未登记的项目。
- [ ] 完成、取消或移出已经失效的项目。

##### 回顾其他清单

- [ ] 议事日程
- [ ] 将来／也许
- [ ] 阅读／回顾
- [ ] 定期维护清单
- [ ] 岗位职责和责任范围
- [ ] 旅行、活动和重要日期提示

#### 第三阶段：发挥创造性

- [ ] 现在有什么新项目值得启动？
- [ ] 哪个项目可以暂停或取消？
- [ ] 有什么事情可以交给别人？
- [ ] 哪个反复出现的问题需要建立核查清单？
- [ ] 哪个流程、工具或工作空间需要改进？
- [ ] 近期出现了什么机会？
- [ ] “将来／也许”中有什么内容现在可以转成项目？

#### 每周回顾完成标准

- [ ] 工作篮已处理到自己重新信任的程度。
- [ ] 日程表准确反映未来硬边界。
- [ ] 项目清单完整、清楚、最新。
- [ ] 每个活跃项目都有下一步行动。
- [ ] 等待事项知道由谁负责、何时跟进。
- [ ] 当前情境下可以直接从行动清单中选择工作。
- [ ] 脑中没有因为担心遗漏而必须继续记住的事情。

### 八、自然式项目计划清单

> **来源：《搞定Ⅰ》第 3 章、《搞定Ⅱ》第五部分“自然式计划模式”、《搞定Ⅲ》附录 2。**

并不是每个项目都要写完整计划。只有当项目仍然模糊、停滞、多人协作或风险较高时，才继续往下思考。

#### 1. 宗旨

- [ ] 为什么要做？
- [ ] 如果不做，会发生什么？
- [ ] 这件事服务于哪个更高层面的结果？
- [ ] 是否值得继续投入？

#### 2. 指导原则

- [ ] 哪些边界不能突破？
- [ ] 哪些质量标准必须满足？
- [ ] 时间、预算和资源限制是什么？
- [ ] 谁拥有最终决定权？
- [ ] 哪些利益相关方必须被考虑？

#### 3. 成功结果

- [ ] 大功告成时，看起来是什么样？
- [ ] 哪些事实能够证明项目已经完成？
- [ ] 相关人员会看到、听到或感受到什么？
- [ ] 完成结果能否用一句话写清楚？

#### 4. 头脑风暴

- [ ] 已知条件是什么？
- [ ] 还不知道什么？
- [ ] 有哪些可能路径？
- [ ] 有哪些风险？
- [ ] 需要哪些人、工具、资料和场地？
- [ ] 最坏结果是什么？
- [ ] 最好结果是什么？
- [ ] 先记录想法，不立即评判。

#### 5. 组织整理

- [ ] 找出主要组成部分。
- [ ] 区分可以并行和必须按顺序完成的部分。
- [ ] 标出关键节点和外部依赖。
- [ ] 确定责任人。
- [ ] 确定需要进入日程表的硬日期。

#### 6. 下一步行动

- [ ] 当前可以推进项目的具体动作是什么？
- [ ] 由谁执行？
- [ ] 在什么情境下执行？
- [ ] 放入日程表、行动清单还是等待清单？

#### 可复制的项目卡

```text
项目名称：
完成结果：
为什么要做：
必须遵守的原则：
当前状态：
主要组成部分：
下一步行动：
责任人：
等待事项：
硬日期：
辅助资料位置：
下次检查时间：
```

### 九、会议实践清单

> **来源：《搞定Ⅰ》第 12 章“确定下一步行动”、《搞定Ⅱ》第 35～36 章。**

#### 会前

- [ ] 这次会议想得到什么结果？
- [ ] 哪些问题必须在会上决定？
- [ ] 哪些内容只需要提前发送，不必占用会议时间？
- [ ] 谁必须参加？
- [ ] 需要哪些材料和数据？
- [ ] 是否已经查看与参会人的议事日程清单？

#### 会中

- [ ] 把新问题和新想法写下来。
- [ ] 区分讨论、决定、参考信息和行动。
- [ ] 对每项决定追问下一步行动。
- [ ] 明确一个责任人。
- [ ] 明确日期或检查节点。
- [ ] 对尚未决定的事项说明下一步怎样继续。

#### 会后

- [ ] 自己负责的动作进入行动清单或日程表。
- [ ] 别人负责的动作进入等待清单。
- [ ] 多步骤结果进入项目清单。
- [ ] 以后再议的内容进入议事日程或指定日期提醒。
- [ ] 参考信息进入参考系统。
- [ ] 会议记录中不再藏着没有处理的承诺。

#### 可复制的会议结果

```text
会议主题：
预期结果：
作出的决定：

行动：
- 谁／做什么／什么时候

等待：
- 等谁／等什么／委派日期／跟进日期

新项目：

以后再议：

参考资料位置：
```

### 十、委派与等待清单

> **来源：《搞定Ⅰ》第 2、7 章，《搞定Ⅲ》第 6 章。**

委派不是把事情从自己的世界中删除，而是改变下一步行动的责任人。

#### 委派时

- [ ] 想得到的结果已经说清楚。
- [ ] 对方知道自己负责什么。
- [ ] 对方确认已经收到。
- [ ] 质量标准和边界已经说明。
- [ ] 约定日期或检查节点已经说明。
- [ ] 相关材料已经交付。
- [ ] 自己的系统中已经留下等待提示。

#### 等待清单的写法

```text
责任人｜等待的结果或行动｜委派日期｜约定日期｜下次跟进
```

例如：

```text
李明｜确认合同修改意见｜9 月 16 日｜9 月 18 日｜9 月 18 日上午
```

#### 回顾等待事项

- [ ] 已经完成了吗？
- [ ] 对方仍然是合适的责任人吗？
- [ ] 是否需要提供更多信息？
- [ ] 是否需要重新商定日期？
- [ ] 是否已经影响其他项目？
- [ ] 我的下一步是继续等待、催办、改派还是自己接回？

### 十一、六个视角的检查表

> **来源：《搞定Ⅰ》第 2 章“六层次法”、《搞定Ⅲ》第 10～16 章。**

| 高度 | 检查内容 | 建议查看时机 |
| --- | --- | --- |
| 跑道 | 当前可以执行的下一步行动 | 每天及情境允许时 |
| 1 万英尺 | 需要多个步骤完成的项目 | 每周 |
| 2 万英尺 | 工作和生活中的责任、角色和兴趣范围 | 大约每月，或职责变化时 |
| 3 万英尺 | 未来一两年希望实现的目标 | 至少每年，必要时按月或季度 |
| 4 万英尺 | 两年以上的愿景、生活方式和长期方向 | 每年、每两三年或重大变化时 |
| 5 万英尺 | 宗旨、原则和价值观 | 重大启动、分歧、取舍和人生转折时 |

#### 跑道：行动

- [ ] 行动是否具体？
- [ ] 行动能否直接开始？
- [ ] 行动是否放在正确情境清单中？
- [ ] 日程表中的硬日期是否准确？

#### 1 万英尺：项目

- [ ] 我承诺完成的结果有哪些？
- [ ] 是否有遗漏的个人项目？
- [ ] 每个项目是否至少有一个下一步行动？
- [ ] 是否有应当完成、取消、暂停或移入将来／也许的项目？

#### 2 万英尺：责任范围

- [ ] 工作职责是否说得清楚？
- [ ] 家庭、健康、财务、学习和关系是否得到适当维护？
- [ ] 哪个责任范围正在失去平衡？
- [ ] 是否需要与老板、伙伴或家人重新明确边界？

#### 3 万英尺：一两年目标

- [ ] 今后一两年必须实现什么？
- [ ] 哪些变化已经可以预见？
- [ ] 当前项目是否支持这些目标？
- [ ] 哪个目标还没有对应项目？

#### 4 万英尺：愿景

- [ ] 两年以上希望过怎样的生活？
- [ ] 工作、家庭、居住和健康的理想状态是什么？
- [ ] 如果进展顺利，未来会看到什么？
- [ ] 当前目标是否把自己带向这幅图景？

#### 5 万英尺：宗旨和原则

- [ ] 为什么要做现在这些事情？
- [ ] 哪些价值不能为了短期结果而牺牲？
- [ ] 发生分歧时，用什么原则作决定？
- [ ] 当前生活方式是否与这些原则一致？

#### 从哪里开始

逻辑上，宗旨决定愿景，愿景决定目标，目标决定责任、项目和行动。实际整理时，可以从最吸引注意力的层面开始：

- 被邮件、杂务和临近事项压住时，从跑道和项目开始；
- 工作职责变化时，从责任范围开始；
- 年度方向不清时，从目标和愿景开始；
- 面临重大取舍时，从宗旨和原则开始。

### 十二、失控时的恢复清单

> **来源：《搞定Ⅲ》第 18 章“如果你自觉应接不暇”。**

#### 先处理真实的紧急情况

- [ ] 是否有人身、财务、法律或业务上的立即风险？
- [ ] 是否存在今天必须完成的硬日期事项？
- [ ] 是否需要先通知相关人员计划已经变化？
- [ ] 是否需要重新商定已经无法兑现的承诺？

处理完真实紧急事项，再恢复系统。

#### 恢复掌控

1. [ ] 拿出一个可靠的捕捉工具。
2. [ ] 写下所有正在吸引注意力的事项。
3. [ ] 收集桌面、邮件和临时记录。
4. [ ] 逐项决定结果和下一步行动。
5. [ ] 把项目、行动、等待和日程重新归位。
6. [ ] 查看未来几天的日程表。
7. [ ] 选择一项当前可以完成的行动。
8. [ ] 安排一次完整的每周回顾。

如果只有很短时间，先做最小恢复：

- [ ] 写下脑中全部事项；
- [ ] 圈出一个必须最先面对的问题；
- [ ] 写出它的成功结果；
- [ ] 写出下一步具体行动；
- [ ] 立即完成，或放进可信位置。

#### 判断系统最薄弱的一环

- [ ] **捕捉弱**：脑中仍有大量没有写下的事项。
- [ ] **明确弱**：清单里充满“处理、推进、研究”等模糊任务。
- [ ] **组织弱**：知道要做什么，却经常找不到记录。
- [ ] **回顾弱**：清单已经过期，因此不愿再看。
- [ ] **参与弱**：持续整理和计划，却很少真正执行。
- [ ] **视角弱**：行动很多，但不知道这些项目为什么还要继续。

先修复最薄弱的一环，不必同时重建所有东西。

### 十三、系统健康检查

每月或系统明显变得难用时检查一次。

#### 捕捉

- [ ] 捕捉入口数量仍然可控。
- [ ] 没有被遗忘的笔记本、应用或邮箱。
- [ ] 新想法可以在几秒内记下。
- [ ] 所有入口都会在 24～48 小时内得到处理。

#### 明确

- [ ] 工作篮中的材料会被逐项决定。
- [ ] 项目有完成结果。
- [ ] 行动以动词开头，能够直接执行。
- [ ] 不需要行动的资料没有混在行动清单里。

#### 组织

- [ ] 日程表只保留硬日期。
- [ ] 项目、行动和辅助资料没有混为一类。
- [ ] 等待事项包含责任人和时间信息。
- [ ] 参考资料能够快速找到。
- [ ] 分类数量没有超过实际需要。

#### 回顾

- [ ] 每周回顾有固定时间。
- [ ] 项目清单保持完整。
- [ ] 行动清单和现实同步。
- [ ] 将来／也许会被定期查看。
- [ ] 责任、目标和愿景有自己的检查节奏。

#### 参与

- [ ] 可以根据情境、时间、精力和重要性选择行动。
- [ ] 面对新情况时，会使用系统而不是放弃系统。
- [ ] 工具和分类没有占用过多注意力。
- [ ] 行动时可以专注于一件事。
- [ ] 系统帮助自己行动，而不是成为新的拖延方式。

### 十四、常见问题对照表

| 表现 | 实际问题 | 修正动作 |
| --- | --- | --- |
| 写了很多清单，仍然焦虑 | 只收集，没有明确和组织 | 逐项处理工作篮，写出结果和下一步行动 |
| 每天都在改日程 | 把普通任务当成硬日期 | 普通任务移回行动清单 |
| 项目长期不动 | 把项目名称当成行动 | 写出当前可执行的物理动作 |
| 一直忙于小事 | 没有完整项目和责任地图 | 做每周回顾，再检查六层视角 |
| 频繁更换软件 | 系统本身占据注意力 | 固定简单工具，先连续运行一段时间 |
| 委派后仍然担心 | 没有可靠的等待清单 | 记录责任人、结果、日期和跟进动作 |
| 邮箱反复爆满 | 捕捉入口没有被处理 | 安排固定整理时间，24～48 小时清零 |
| 每周回顾总被跳过 | 没有给回顾留下硬时间 | 放进日程表，预留连续时间 |
| 长期项目没有进展 | 用“长期”回避当前行动 | 现在就确定一个下一步行动 |
| 计划得很细却没有结果 | 过度控制 | 回到完成结果和真正需要推进的动作 |
| 想法一出现就被否定 | 捕捉和评判同时进行 | 先完整头脑风暴，再组织和筛选 |
| 压力一大就不用系统 | 方法尚未成为习惯 | 先恢复捕捉和每周回顾两个环节 |

### 十五、从零启动顺序

> **来源：《搞定Ⅲ》第 18 章“运用工具和窍门——启动系统”。**

如果还没有完整系统，按下面顺序开始：

1. [ ] 准备方便好用的捕捉工具。
2. [ ] 建立日程表和下一步行动清单。
3. [ ] 建立项目、等待、议事日程和将来／也许清单。
4. [ ] 建立可以快速归档和查找的参考系统。
5. [ ] 在办公室、家里和移动途中准备工作台。
6. [ ] 做一次完整的大脑清扫。
7. [ ] 逐项清空工作篮。
8. [ ] 确认每个项目都有下一步行动。
9. [ ] 把每周回顾放进日程表，初期预留连续两小时。
10. [ ] 为责任、目标、愿景和宗旨安排单独的思考时间。
11. [ ] 在真实使用中调整分类和工具。
12. [ ] 压力增大时回到系统，先找出最薄弱的一环。

不需要等系统设计完美才开始。先让一个真实事项经过捕捉、明确、组织、回顾和执行的完整循环，再继续处理下一项。

## 高效程序员的45个习惯

- URL: https://blog.no-claw.com/8f11a70d/
- 日期: 2026-08-04
- 分类: 读书有感
- 标签: 效率

《高效程序员的45个习惯》，整本书压缩成一句话大概是：

> 对结果负责，用小步行动快速获得反馈，再持续修正。

后面这些是顺着这个思路往生活上套，**下面的清单和表格是 GPT 帮着列的，我做了删改和批注**。

### 能搬到生活里的十条

#### 1. 关注结果，不沉迷忙碌

每天问一句“我真正想推进什么”，而不是数今天划掉了几项。（清单划得越干净越可疑，因为容易的都在上面

#### 2. 小步迭代

别等完美计划。健身先坚持一周，学习先做一个小项目，然后看效果调整。

#### 3. 尽早获得反馈

想法尽早给人看，问题尽早查。反馈越晚，纠错越贵——这条和代码 review 是一回事，拖到最后才发现方向错了，前面全是白干。

#### 4. 一次改变少一点

同时立十个习惯基本都会失败。每次改一两个关键行为。

#### 5. 自动化重复事务

自动记账、定时提醒、固定购物清单、模板化周计划。把脑力留给判断。

#### 6. 保持简单

能用日历和清单解决的，就别搭复杂的“人生管理系统”。**工具不是成果**，折腾工具的快感和事情本身推进了多少，是两码事。

#### 7. 定期复盘

每周就三个问题：什么有效？什么没用？下周改什么？

#### 8. 学会放弃旧方法

已经投入很多，不代表必须继续。不合适就“卸载”。（沉没成本，说起来容易

#### 9. 对事不对人

讨论具体行为和后果，别升级成人格评价。对家里尤其重要。

#### 10. 建立稳定节奏

可持续的每天 30 分钟，通常胜过偶尔拼命五小时。

所以整个循环就是：**确定一个结果 → 采取最小行动 → 尽快看反馈 → 保留有效的 → 每周调整。**

核心不是把生活管成机器，是让自己有持续纠偏的能力。

### 比普通时间管理有意思的那些

#### 执行与决策

- **限制并行任务（WIP）**：同时推进的重大事项不超过 2～3 个。
- **YAGNI**：不要为“也许以后需要”提前建复杂系统。（生活里最典型的 YAGNI 就是买了用不上的设备
- **先做原型**：买设备、转行、搬家前，先做低成本体验。
- **功能开关**：新习惯先试运行，随时能暂停，不必宣布永久改变。（这条比“立志”实用，因为没有毁约的心理负担
- **根据历史估时**：参考过去实际耗时，别按理想状态排日程。
- **定义完成标准**：“学英语”不是任务，“完成并订正一套听力题”才是。

#### 排错与改进

- **橡皮鸭调试**：把问题完整讲给别人，或者写下来，答案经常自己就浮现了。
- **最小复现**：复杂问题先缩范围，找出哪个条件真正导致问题。
- **五个为什么**：迟到未必是起床晚，也可能是睡眠、路线或者出门前的准备流程。
- **一次只改一个变量**：否则不知道到底哪项改变有效。
- **无责复盘**：先修系统和环境，少用“我就是自制力差”解释问题。这句话什么都解释不了，还顺手把改进的路堵死。
- **让失败可见**：扣款失败、睡眠不足、支出超标，都该主动提醒你。

#### 协作与关系

- **代码审查**：重要合同、邮件、决定，让可信的人看一遍。
- **结对工作**：找搭档一起健身、学习或者处理难搞的事。
- **接口清晰**：约定谁负责什么、什么时候交、用什么方式沟通。
- **减少隐式依赖**：家里的重要事务别只有一个人知道怎么处理。（这条其实是单点故障

#### 系统设计

- **松耦合**：收入、社交、数据、身份，不要全压在一个平台或一个单位上。
- **优雅降级**：忙的时候不要求完整健身，改做最低版本的十分钟。
- **默认值**：固定早餐、采购日、运动时间，减少重复决策。
- **DRY**：重复的东西做成模板，周报、旅行清单、报销流程。
- **删除废弃代码**：取消不再需要的订阅、承诺、物品和目标。
- **依赖管理**：定期检查证件期限、药品、设备、订阅和关键联系人。
- **个人 README**：记下自己的工作偏好、边界、恢复方式和压力信号。
- **运行手册**：生病、电脑坏了、紧急出差，提前写好处理步骤。
- **变更日志**：什么时候改了什么，方便判断这个改变到底有没有用。

这里面最实用的一条思路：

> 不要要求自己永远处于最佳状态，而要让生活系统在状态不好的时候仍然能运行。

### 第一册：《搞定Ⅰ：无压工作的艺术》

> **提炼范围**：戴维·艾伦《搞定Ⅰ：无压工作的艺术（最新版）》。正文按原书三部分展开；原书中解释原理、因果和适用方式的内容按原意润色保留，关键句继续以引文标出。

《搞定Ⅰ》负责把 GTD 的整套方法搭起来：先用横向流程管理全部事务，再用纵向方法推进单个项目，最后把这些动作变成稳定习惯。

#### 第一部分：搞定——通向从容之道

##### 第 1 章：新情况，新做法

本书中的这套方法，完全基于三个主要目的：

1. 收集所有需要处理或者对你有用的事情（现在的、以后的、某一时间的；大的、小的、不大不小的），把它们统统置入一个脱离大脑意识的、条理分明的、可靠的系统中；
2. 指导自己在获取任何“输入信息”（也就是接手任何任务）的前期就进行分析和决策，以确保随时拥有一套可以执行或重新协调的“下一步行动”可行清单；
3. 管理、协调所有相关内容，履行你在任何时间点对自己和他人做出的各种承诺。

> 只要有足够的信息，几乎每件事情都可以做得更好。而在当今的世界，你可以获取的信息是无穷无尽的。
>
> 你发挥能量的能力与你的放松能力成正比。
>
> 如果你的大脑空空如也，总是处于一切就绪的状态，那么它就会向一切事情敞开大门。
>
> 行动源于思考。

知识工作没有清楚的完成线。方案可以继续改，资料可以继续找，责任也会不断变化，而能够获取的信息几乎没有上限。传统时间管理缺少一套能在真实工作中持续运转的系统。

这套系统必须同时满足几个条件：

- 从大局着眼，也能从具体行动入手，并把两者连接起来；
- 能管理行动、项目、责任、目标和愿景等多个层面；
- 能持续接住每天出现的新事务，避免遗漏；
- 容易维护，整理系统本身不能消耗过多时间和精力；
- 把复杂事务转成可以判断、可以追踪的结果和行动。

###### 管理承诺时的基本要求

**第一**，只要一件未完成的事仍由大脑负责提醒，它就会反复占用注意力。所有未完成的承诺都要进入一个客观、可靠、会被定期查看和清理的外部系统。

**第二**，仅仅知道“有这件事”还不够。每项承诺都要明确工作究竟是什么、想得到什么结果，以及需要采取什么行动来推动它。

**第三**，作出决定以后，结果和行动的提示必须放进一个会被反复查阅的系统。否则，大脑仍会继续承担记忆和提醒工作。

###### 为什么有些事情总是萦绕在你的心头

- 还没有明确认定预期结果是什么；
- 还没有确定下一步要采取的具体行动；
- 结果和行动的提示还没有进入一个真正信任、还会回来查看的系统。

> 我们需要把收集和积累的所有“材料”都转化成包含重要行动、项目和有用信息的明确清单。

收集到的“材料”不能一直保持原样，它们要被转成项目、行动和有用信息。就推进工作而言，最终需要看清两类内容：

1. **想要得到的结果**；
2. **推动结果的行动**。

###### 对行动的横向管理和纵向管理

**横向控制**把工作和生活中所有正在关注的行动纳入同一个系统，保证没有事务被遗忘，并能在合适的情境中看到可执行选项。

**纵向控制**针对某个具体主题或项目继续向下思考，协调目的、结果、想法、计划和下一步，并持续跟踪进展。

> 任何仅存在于内心的“将会、可能或应该”性质的承诺，都会造成非理性和无法排解的全天候压力。
>
> 对一件事情不需要进行两次相同的思考，除非你喜欢重复思考。

##### 第 2 章：横向管理工作流程的 5 个步骤

1. 收集引起注意的事务和信息；
2. 理清每个项目的意义和相关措施；
3. 组织整理结果，提出选项；
4. 进行思考回顾；
5. 选择行动。

这五步构成横向管理系统。新的事务可以随时进入，但每一项都要经过同样的判断，不能只收集、不处理，也不能把尚未明确的材料直接塞进待办清单。

> 问问你自己：“我需要以何种方式在何时将想法付诸行动？”你建立管理系统是为了让它发挥作用，而不是单纯为了拥有它。

###### 收集

所有等待处理、需要改进或者持续吸引注意的未竟之事，不分大小、轻重和缓急，都先收集起来。收集的目的不是立刻完成，而是停止让大脑同时保存和处理这些内容。

> 悬而未决的事务存在两个地方，即任务所处的实际位置和你的大脑。

1. 把一切赶出你的大脑
2. 尽量减少收集工具的数量
3. 定期清空收集工具

> 出错好过模棱两可。

###### 理清：立即执行、指派他人，或者延迟处理

一旦你决定了下一步行动，紧接着，你就会面临以下三种选择：

1. **立即执行**——如果行动能在两分钟内完成，那么你就应该立刻执行。
2. **指派他人**——如果处理这件事情需要花费的时间不止两分钟，那么，你应该问一问自己是不是解决这个问题的最佳人选。如果回答是否定的，那就委托给一个合适的人员去办理。
3. **延迟处理**——如果预计花费的时间超过两分钟，而你又恰恰是最佳人选，那么这时，你就不得不推迟行动，把它记录在“下一步行动”清单上，等以后再来完成。

###### 组织整理

**项目清单的内容范例：**如果某项工作不能一步完成的话，那么，你就需要建立某种机制来提醒自己还有事情尚未处理。

**项目的辅助性资料：**一旦你把项目的辅助性资料按照主题或者题目分类组织整理时，拥有一个运行良好的参考文件归档系统。

**下一步行动的归类——日程表：**

- 需要在指定时间执行的行动
- 需要在指定日期执行的行动
- 需要在指定日期获取的信息
- 不再需要“每日工作清单”

**比较典型的“将来／也许”清单（备忘录）：**是你不愿意去做的事情，或者需要在未来某个指定时间之前持续收到提醒的事情。

**参考资料：**

1. 按特定主题或特定领域分类存储的系统
2. 一般性参考资料归档系统

需要每隔一段时间，全面回顾自己的总体生活和工作情况，并对拟采取的具体行动进行详细检查。

###### 回顾的内容和时机

成功的关键因素：**每周回顾**。

所有悬而未决的事务——“项目”清单（包括现行项目规划）、“下一步行动”、“议事日程”、“等待处理”，甚至“将来／也许”清单，都应该每周回顾一次。

事务都经过了收集、处理、组织整理和回顾这几大步骤。

需要回答的问题：

- 回顾应该要关注哪部分的内容？安排在何时进行？
- 回顾应该怎样进行？每隔多久进行一次才能确保整个系统持续运转，并解放你的大脑，使之能够从事更高层次的思考和组织整理活动？

###### 确定某一时刻具体行动的“四标准法”

1. **情境**——大多数事情都只能在特定的地点完成（在家或办公室）
2. **有多少时间**
3. **有多少精力**
4. **重要性**（ROI）

> 事情总是多得做不完，你可以每次只做一件事。无论是否已经采取行动，关键在于使自己保持良好的状态。

###### 确认每日工作的“三分类法”

- 执行事先安排好的工作
- 处理突发事件
- 安排自己的工作

###### 总体检视工作的“六层次法”

- **5 楼视野**：目的和原则
- **4 楼视野**：愿景
- **3 楼视野**：目标
- **2 楼视野**：关注点及责任范围
- **1 楼视野**：当前项目
- **跑道视野**：当前可以执行的下一步行动

##### 第 3 章：纵向管理项目的 5 个阶段

**自然计划模式**——自然计划法不一定就是常规做法：

1. 定义目标和原则
2. 展望结果
3. 头脑风暴／集思广益
4. 组织整理
5. 明确下一步的行动方案

> 当你发现自己身陷一个黑洞时，就应该立刻停手，绝不要再继续挖了。
>
> 不要仅仅忙着做事情，而是要站在旁边静静想一想。

###### 组织整理的基本要点

组织整理的关键步骤如下：

- 明确事件的重要组成部分
- 整理分类（按照下面一个或多个标准）
  - 构成因素
  - 先后顺序
  - 重要程度
- 足够详细的描述

> 任何人都不可能多任务并行，都是一次只能做一件事。

在现实生活中，干扰和打断原本就是难以避免的。当你能够熟练地、快速地分析处理突发事件，并学会利用各种零碎时间来完成行动的时候，你就可以在不同的任务之间敏捷地切换了。这种切换的过程务必要保证整个管理系统的平衡。研究已经证明，你无法真正做到多重任务化，也就是说，你无法在同一时间有意识地专注于一件以上事情；如果你试图那么做，它会显著削弱你的执行能力。

> 你要做的是发现你的世界，然后全身心地投入其中。
>
> 采用这种自下而上的工作方式的首要原因就是，这种方式能够让你清除内心的烦扰、释放受困的心灵，让你有精力去关注那些更有意义、更重要的方面。
>
> 处理你的关注事项，然后你会发现真正吸引你的东西。
>
> 让我们把超前的焦虑变成超前的思考和规划。

关键在于你要学会思考，运用思考的结果进行合理的管理。要培养一个好习惯：在考虑问题的时候高度集中精力，有预见性地发现问题、解决问题，而不是等到迫不得已时才行动。

#### 第二部分：远离压力，提高效率

##### 第 4 章：准备工作——确定时间、空间和工具

完整启动一次 GTD，需要一段不受打扰的时间、一个可以集中处理材料的工作区，以及一套足够简单的工具。基本配置包括工作篮、纸笔、日程表、行动清单、文件夹和参考资料归档系统。

工具的作用是降低捕捉和归档的阻力。数量太多、入口太散、查找太慢，都会让大脑重新承担提醒工作。

##### 第 5 章：收集阶段——归拢材料

收集分成两部分：

1. **外部收集**：把桌面、抽屉、文件柜、背包和其他空间里尚未处理的材料集中到工作篮；
2. **内部收集**：通过“大脑清扫”写下所有引起注意的承诺、担忧、想法和可能性。

这一阶段只负责收齐，不急着分类和决定优先级。明显的垃圾、确定需要归档的资料和两分钟内可以顺手完成的小事可以直接处理，其余内容先进入统一入口。

##### 第 6 章：理清阶段——清空工作篮

从工作篮最上面一项开始，一次只处理一件，不把拿出来的材料原样放回去。判断顺序是：

1. 这是什么？
2. 需要行动吗？
3. 想得到什么结果？
4. 下一步行动是什么？

不需要行动的内容进入垃圾、参考资料或“将来／也许”。需要行动的内容按两分钟法则、委派或延迟三种方式处理；需要多个步骤才能完成的结果同时进入项目清单。

##### 第 7 章：组织整理——建立好清单

理清后的结果进入不同容器：

- **项目清单**：需要多个行动才能完成的结果；
- **日程表**：必须在指定日期或时间发生的行动和信息；
- **下一步行动清单**：可以尽快执行的具体动作；
- **等待清单**：已经交给别人、仍需追踪的事项；
- **将来／也许**：尚未承诺，但以后可能启动的内容；
- **参考资料**：不需要行动、以后可能查阅的信息。

日程表只保存真正受日期约束的“硬质景观”。普通任务如果都塞进日程表，反复延期后，日程表本身也会失去可信度。

##### 第 8 章：回顾阶段——保障系统的有效运行

日常回顾先看日程表，再看当前情境下的行动清单。每周还要做一次完整回顾：

- 收集散落材料，清空工作篮和记录；
- 检查过去和未来的日程；
- 更新行动、等待和项目清单；
- 查看“将来／也许”和相关核查清单；
- 补充回顾过程中出现的新想法。

回顾的目的，是让系统重新和现实同步。只有相信清单完整、内容最新，大脑才会停止反复提醒。

##### 第 9 章：执行阶段——选择最合适的行动

面对多项可执行行动时，依次考虑四个条件：当前情境、可用时间、可用精力和重要性。

每天的工作又分成三类：

1. 执行已经安排好的工作；
2. 处理突然出现的工作；
3. 重新整理和明确自己的工作。

第三类工作不会直接推进某个项目，却决定系统能否继续提供可靠选择。

##### 第 10 章：学会控制项目

项目不能被直接执行，能执行的只有下一步行动。每个活跃项目至少要有一个可以继续推进的动作，并在每周回顾中确认它是否仍然有效。

复杂项目可以保留计划、资料和头脑风暴结果，但项目辅助资料不能代替项目清单和行动提示。自然计划法负责思考项目，项目清单负责提醒结果，行动清单负责推动现实进展。

#### 第三部分：三个关键原则

##### 第 11 章：原则一——养成收集的习惯

压力并不只由事情的数量造成，也来自对结果的标准和已经做出的承诺。最直接的减压办法当然是降低要求：如果不再关心子女教育、团队状态、教学制度或代码质量，相应的关注事项会立刻减少。但只要仍然在意这些结果，就需要承认它们已经构成了承诺，并把它们纳入系统。

消极情绪往往不是来自工作本身，而是来自没有履行自己答应过的事。处理承诺只有三种办法：

1. 一开始就不作出承诺；
2. 完成承诺；
3. 重新商定承诺。

第三种办法要求先把承诺找出来。一个只存在于脑中的模糊协议，既无法完成，也无法重新商定。完整收集还有一个直接作用：看清已经承担的全部工作以后，才有依据拒绝新的任务。

在团队里，收集和兑现承诺同样决定信任。成员知道任务会被记录、追踪和重新协商，沟通就不必依赖反复催促。

##### 第 12 章：原则二——确定“下一步行动”

> 如果你不知道具体的下一步行动，那么在现实和目标之间就留下了一个潜在的、巨大的断层。

越聪明、越敏感、越有想象力的人，通常也越容易看到问题、机会和未完成的可能性，因此清单上的未解决事项往往更多。人的神经系统不会严格区分眼前真实发生的事和头脑中反复想象的事；一个含糊的结果，只要不断被想起，身体就可能持续对它作出压力反应。

想象力本身不是问题。问题在于，这些想法没有被转成清楚的结果和行动，于是大脑只能一遍遍重新提醒。

> 越是才智过人的人，越敏感，也越容易被自己的想象所感染。

“下一步行动是什么”把抽象事项变成可以观察的现实动作，也会暴露责任是否明确。会议中的“推进一下”“继续跟进”都不是行动；只有说清由谁打电话、查询、起草或确认，决定才真正进入执行阶段。

下一步行动不一定完成项目，它只需要消除当前的不确定性。对复杂事项来说，第一步甚至可以只是“查明有哪些选择”或“约某人讨论”。

##### 第 13 章：原则三——学会关注结果

只确定行动还不够。下一步行动解决从哪里开始，预期结果决定往哪里走。两者必须同时存在：只有动作会陷入琐事，只有愿景会停在想象里。

书中把工作和生活中卡住的情形压缩成两类：

1. 已经知道目标，但不知道如何达成；
2. 还不知道目标到底是什么。

对应的解决方向也是两个：还不知道目标时，先定义想要的结果；已经知道目标却不知如何推进时，确定下一步行动。

当“预想结果”和“确定下一步行动”变成日常习惯，问题会更快从模糊压力转化为可以处理的结果和动作。人会持续经历同一个循环：发现问题、定义结果、找到行动、完成结果，再发现新的问题和目标。书中所说的效率提升，来自这个循环越来越自然，而不是把清单一次性清空。

> 人生的最大乐趣莫过于克服困难、坚定脚步，目睹自己将目标一一实现。
>
> 你的大脑是用来获得想法的，而不是用来保存想法。

##### 第 14 章：GTD 和认知科学

新版增加这一章，是为了说明 GTD 的效果不只来自经验。书中对应了几组认知研究：

- **分布式认知**：日程表、清单和参考系统构成“外脑”，让大脑把资源用于判断和创造；
- **未解决事项的认知负荷**：没有可信计划的未完成事项会反复侵入注意力，明确结果和行动后，干扰会减弱；
- **执行意向**：提前决定在什么情境采取什么行动，更容易把意图转成行为；
- **自我领导和心理资本**：持续兑现、拒绝或重新商定承诺，会提高掌控感和信心；
- **沉浸状态**：目标清楚、反馈及时、对下一步有把握时，更容易进入专注状态。

###### 沉浸理论

沉浸通常伴随对特定任务的全身心关注，而且你通常会有掌控感，感到目标清晰。处于沉浸状态的个人通常明白接下来会发生什么事情，并能在执行整个任务的过程中得到及时反馈。他们还能体验到行动和意识的融合，并在此过程中丧失其自我意识和时间感。

##### 第 15 章：GTD 精进之路

书中把熟练程度分成三个层次：

1. 采用最基本的工作流程管理；
2. 执行一个较为高级和综合的全方位生活管理系统；
3. 利用技能创造明确的空间，完成任务，并且使你的表现越来越得体。

第一个层次建立工作篮、行动、等待、日程和每周回顾。第二个层次以完整项目清单和责任范围管理整个生活。第三个层次把释放出来的注意力用于方向、创造力和更有意义的选择。

一个明显的分界点是：压力增加时，是放弃系统，还是更主动地使用系统。真正熟练以后，新问题会触发收集、明确和重新校准，而不是把所有事情重新塞回脑中。

###### 日常实践清单

- 基于“待执行事项”决定下一步行动
- 充分利用“等待”类型清单，以便能在适当的时机保存他人交付的预期可交付项目，并审查其后续状况
- 利用“日程”清单收集与他人的沟通信息，并加以管理
- 维护一个简单、易于访问的归档和参考系统
- 将日历表作为纯粹的“硬质景观”加以保存，不要让不相干的新事务破坏其可信度
- 进行“每周回顾”，以保证某个系统的功能正常化，且持续更新

###### 成熟系统的标志

- 一个完整、最新、清晰的项目清单
- 一张角色、职责、兴趣（个人和职业）的地图
- 一个集成化的全面生活管理系统，这个系统是基于某人的当前需求和发展方向定制的，用于动态监控日常工作以外的行为
- 面临的挑战和意外状况将驱使你采用（而不是弃用）这个方法

###### 落地动作

- 建立起用于个人组织整理的设施
- 安排整理你的工作区
- 准备几个工作篮
- 创建一个可行和易于访问的个人参考系统（工作和家用）
- 准备一个好用的计划手册，上面应该有完整的管理项目的清单
- 允许自己做出旨在改善工作环境的任何改变。挂图片，买钢笔，扔东西，重新安排你的工作区。为你重新启程提供支持
- 预留出一些时间，让你可以整理办公室中某一个完整的区域，然后是家中的各个角落。把收集到的一切纳入你的系统当中，并采用本书介绍的方法进行处理
- 同别人分享你从书中获得的知识、你的实践经验以及感受（这是最快的学习方法）
- 3～6 个月后，再回顾本书的内容

### 第二册：《搞定Ⅱ：提升工作与生活效率的 52 项原则》

> **提炼范围**：戴维·艾伦《搞定Ⅱ：提升工作与生活效率的 52 项原则（最新版）》。前四部分是 52 章正文，第五部分是 GTD 基本方法的核查清单；各项原则保留原书的论证和例子，只压缩重复内容并润顺译文。

《搞定Ⅱ》不是重新讲一遍操作步骤。它把 GTD 背后的原则拆成 52 篇短文，集中讨论四件事：清理未竟之事、调整关注焦点、建立可靠结构、放松并采取行动。

##### 52 项原则的四个方向

正文分成四组，每组 13 章。

###### 第一部分（第 1～13 章）：理清头绪，发挥创造力

- **第 1 章　理清思路，确立新方向。**未来一定会出现今天无法预料的变化。与其猜测变化是什么，不如先清理眼前最明显的积压：工作篮、邮件、抽屉、旧项目和过期承诺。清出的空间，会成为应对新情况的余量；随身可用的捕捉工具，则负责接住在意外时刻出现的新想法。
- **第 2 章　知道哪些事情自己尚未做，你才会为之心安。**压力来自没有履行的约定，处理办法只有三种：不再承担、完成它，或者重新商定。前提是先知道自己到底答应过什么。收集、处理、组织、回顾和执行是五种不同工作，试图在列清单时一次完成，往往只会得到短暂的整齐。
- **第 3 章　理清承担的任务，可以更好地选择新任务。**不了解已有承诺，就无法诚实判断还能不能接新任务。把散落各处的待读材料集中起来，数量一目了然以后，才可能决定读什么、放弃什么。清楚的边界并不限制自由，它使专注和拒绝都有依据。
- **第 4 章　要实现未来的目标，首先明确当前的位置。**地图只有在知道当前位置时才有用。除了当前行动和项目，还要盘点责任范围、一两年的目标、较长期愿景以及人生宗旨。接受真实现状，才能判断下一步是左转还是右转。
- **第 5 章　以有限的可能，去利用无限的机遇。**机会可以无限增加，时间、精力和注意力却始终有限。管理工作流程的意义不是把所有事情都做完，而是完整收集输入、作出决定并保留可信的选择，使有限资源投入当前真正要做的事。
- **第 6 章　一心二用带来压力与失败。**大脑无法同时专注于眼前工作，又替所有未完成承诺担任提醒器。把开放回路从头脑中移出，明确其结果和行动，是一种主动应对；只有地面层的杂务得到控制，注意力才不会在两个世界之间拉扯。
- **第 7 章　有意识地权衡轻重缓急。**判断优先级之前，必须先看见全部承诺。被忽视的“次重要”项目并不会一直安静，轮胎、账单和关系问题都可能从可从容处理的小事，拖成不得不立即处理的危机。很多人把这种糟糕的管理误叫作命运。
- **第 8 章　完成未竟之事，释放自身能量。**未完成事务会持续占用心理资源，结束、取消或重新决定，都能把这部分能量释放出来。清理抽屉、归还借物、回复一封旧邮件看似平凡，却常常是恢复创造力和行动感的入口。
- **第 9 章　如果你一直想着某件事，很可能是还没有搞定。**一件事反复回到脑中，通常不是因为它最重要，而是因为还没有明确成功结果、下一步行动，或者没有把提醒放进可信系统。把这三件事处理好，大脑才会停止重复报警。
- **第 10 章　只要有空间，创造力就会展现。**创造力不一定要用力催生。积压、模糊承诺和无处安放的材料被清走以后，空出来的注意力会自然发现联系、机会和新想法。系统的作用，是为这种自发出现留出空间。
- **第 11 章　渠深流畅。**能承接多大挑战，取决于个人系统能容纳多大流量。渠道越深、越干净，新的信息和责任越不容易造成泛滥。项目清单、行动清单和定期回顾，不只是整理方法，也是扩大处理能力的基础设施。
- **第 12 章　担忧无益。**担忧是问题在头脑中循环，却没有转化为决定和行动。该思考时把问题想清楚，该行动时执行，暂时无法处理时把它放进会再次看到的系统；反复挂念本身不会改善结果。
- **第 13 章　你不是你的工作。**把工作完整地放进清单，反而更容易把自己与工作分开。清单不是身份，也不是债务记录，它只是客观地图。地图可信以后，人可以全心投入清单上的一项，也可以安心去做清单之外突然出现、真正值得做的事。

> 处理自己关注的事情的目的，在于你可以做自己真正喜欢做的事情。

###### 第二部分（第 14～26 章）：高效关注

- **第 14 章　想看得更清楚，请从更高处着眼。**下一步行动看不清时，向上检查项目计划、预期结果和目的；目标空泛时，再向下追问眼前能做什么。改变观察高度，常常比继续盯着同一个问题更快恢复清晰。
- **第 15 章　只有身体力行，你才会知道如何去做。**清楚地想象结果，会让大脑开始识别相关信息；真正动手以后，新的方法和条件才会出现。很多工作无法等到完全知道怎么做再开始，行动本身就是认识过程的一部分。
- **第 16 章　工作足够努力是不可能的。**知识工作的边界不会自动出现，总有更多邮件、想法和改进空间。单纯延长时间无法完成无限的工作，必须先决定什么值得做，再对选中的事情投入完整注意力。
- **第 17 章　精力随心思而动。**注意力落在哪里，那里就会获得更多信息、情绪和行动能量。持续盯着问题，会不断强化问题；把注意力转向想得到的结果和可以采取的行动，大脑便开始寻找通道。
- **第 18 章　目标越明确，实现目标的途径越多。**模糊愿望只能产生模糊反应。目的、成功结果和限制条件越具体，大脑越容易发现原先看不见的资源与路径。明确目标不是缩小可能性，而是给创造力一个可以工作的方向。
- **第 19 章　精益求精。**精益求精不是等待一个永远不会到来的完美状态，而是在当下条件中把手头工作做到自己能做到的最好。标准、能力和环境会继续变化，卓越是一种持续校正的动态过程。
- **第 20 章　关注重心的变化等于结果的变化。**调整关注点，会改变被看见的信息，也会改变随后的选择。开始留意客户体验、身体状态或团队协作后，过去被过滤掉的信号会进入视野，结果便从关注改变的那一刻开始变化。
- **第 21 章　视角是地球上最贵重的商品。**同一项行动放在不同背景中，意义会完全不同。提高视角不是逃离细节，而是重新理解细节服务于什么。能够为当前工作换一个更准确的背景，本身就是高价值的管理能力。
- **第 22 章　多加思考。**效率不会自动发生。许多看似复杂的事务，只需要十几秒钟认真追问预期结果和下一步行动，就能从心理负担变成可执行事项。缺的往往不是时间，而是愿不愿意在前端作出决定。
- **第 23 章　思考有度。**工作需要被想清楚，却不必被无限分析。结果和下一步行动已经明确，提醒也放进可靠位置，就可以停止思考并去做；继续反刍只会让思考取代行动。
- **第 24 章　效率是改善工作的唯一机会。**目标和标准明确以后，越轻松地实现它，越能释放时间、精力和其他资源。提高效率不是为了尽快逃离工作，而是为了把资源留给更有价值的体验和创造。
- **第 25 章　关注一件事才能“全神贯注”。**意识总会落在某处，真正的全神贯注来自同一时刻只需要处理一件事。其他承诺被可靠系统托住以后，工作和休息都可以成为当下最重要的事，不必一边做一边担心别处。
- **第 26 章　未来目标的价值，在于它当前培育的变化。**愿景最直接的价值，不在未来某日兑现，而在它立刻改变今天看见什么、选择什么、拒绝什么。行动与自我提升并不冲突，真正要问的是：此刻哪一种行动最符合想成为的人。

###### 第三部分（第 27～39 章）：建立有效的制约机制

- **第 27 章　稳定带来创造力。**当某个层面失衡，它会不断抽走其他工作的注意力；基本结构稳定以后，创造力才有持续流动的空间。画家整理颜料、钓手收好钓具，并非因为缺乏创造力，而是因为他们重视要完成的事。
- **第 28 章　形式与功能必须符合效率最高的原则。**结构是支持还是限制，取决于它是否服务结果。原书把人的工作状态分成“幻想者”和“实干者”：前者自由产生想法，后者判断下一步并推进。工作篮、项目清单、行动清单和每周回顾，让两种角色可以分时合作。
- **第 29 章　优化系统，放飞思想。**大脑知道行动决定是否可信，也知道清单是否会被重新查看。外部系统只有内容完整、持续更新，才能像可靠的助理一样接管提醒工作；每周回顾是让这种清醒从偶然体验变成稳定状态的关键。
- **第 30 章　反应能力提升生存能力。**竞争优势来自更早看见变化、缩短反应时间，并避免反应不足或反应过激。堆积的邮件和未决事项会像麻醉剂一样降低敏感度；清理积压，则让个人和团队重新接触真实情况。
- **第 31 章　系统的强弱取决于最薄弱的环节。**一个系统必须在疲惫、生病和任务激增时仍然好用，才算真正可靠。团队中长期不回应的一环，也会迫使其他人提高音量、制造虚假紧急。最薄弱的沟通和执行环节决定整体压力。
- **第 32 章　系统的效率与你的感知度成反比。**高效系统平时应当退到背景，像汽车的换挡、温控和通风一样安静运行。若做事时还要不断操心工具、分类和流程，说明系统仍在占用本该用于工作的注意力。
- **第 33 章　功能取决于形式。**环境和结构会持续提示行为。物品放在哪里、清单如何呈现、工作台是否顺手，都会决定一项行动是自然发生还是不断遭到回避。改变行为时，也要检查承载行为的形式。
- **第 34 章　目标明确才能赢得胜利。**游戏必须有可以判断的目标，工作也是如此。没有明确结果，思考和行动之间就会变成沼泽；说清“完成是什么样”，才可能看见差距、决定下一步并判断是否已经结束。
- **第 35 章　多人负责等于无人负责。**讨论可以集体完成，责任却必须落到具体的人。会议结束后，如果没有一个人明确承诺结果或下一步，所有人都可能以为别人会处理，事情便留在组织的缝隙中。
- **第 36 章　确定原则，而不是监管制度。**共同原则说清以后，人可以在边界内自行判断；原则含糊或缺乏信任时，组织才会不断增加规则和检查。清楚的原则减少微观管理，也保留了对变化作出反应的空间。
- **第 37 章　利用大脑来思考工作，而不是单纯关注工作。**大脑擅长发现关系、产生想法和作出判断，不擅长在正确时间提醒所有承诺。把项目与行动放进外部系统，才能让大脑从“记住工作”回到“思考工作”。
- **第 38 章　思考的价值超乎想象。**创造阶段需要允许未经评判的想法大量出现，管理阶段再明确意义并组织结果。把捕捉、判断和整理挤在同一刻，刚冒出的想法会被过早批评；给自由和形式各自的位置，二者才能互相支持。
- **第 39 章　资源越是有限，规划越有必要。**如果时间、金钱和精力无限，很多事情无须计划。限制越真实，越要明确目标、比较路径并决定资源放在哪里。规划正是人用有限条件接近想要结果的方式。

###### 第四部分（第 40～52 章）：放松自我，开始工作

- **第 40 章　对自己做的事情承担起责任。**外界会施加条件，但接受、拒绝、协商和行动仍包含自己的选择。承认这一点不是自责，而是重新取得主动权：对已经接受的承诺负责，也对没有去做的事情负责。
- **第 41 章　过度控制等于失去控制。**球拍握得太紧，动作反而失去灵活。分类、标签、软件和流程只有在服务结果时才有价值；如果整理系统本身变成主要工作，控制就成了回避行动的新形式。
- **第 42 章　进展越好，状态越好。**真实进展会带来能量和信心，使人有能力接受更大的挑战。推进不一定是完成大块工作，也可以是明确一个结果、清掉一个障碍或作出一个拖延已久的决定。
- **第 43 章　相信自己的行动选择，需要多层面的自我管理。**上午 9 点 45 分该做什么，没有一个简单公式可以自动回答。情境、时间、精力、轻重缓急，以及项目、责任、目标和价值观都会参与判断；系统负责呈现可信选项，人负责作出选择。
- **第 44 章　你的力量取决于你的放松能力。**放松不是松懈，而是减少不必要的内在对抗，让力量准确地落在需要之处。运动、沟通和决策都一样：越能卸下无关紧张，越能感知变化并自由回应。
- **第 45 章　预料之内的意外算不上意外。**干扰、延误和计划变化本来就是工作环境的一部分。能消除的提前消除，不能消除的预留空间、设置缓冲并纳入计划；拒绝承认变化，只会让同一件事同时造成事实困难和心理挫败。
- **第 46 章　目光越长远，进展越顺畅。**时间视野越长，可选路径越多，眼前的偏差也越容易校正。只盯最近一步，任何变化都像障碍；看见较远的结果和节奏，便能更从容地调整当前动作。
- **第 47 章　放慢速度以提升速度。**连续行动会让视野变窄，也可能把人带到错误方向。暂停、休息、整理和重新聚焦，为大脑恢复判断力；这段看似没有推进的时间，常常避免了更大的返工。
- **第 48 章　你没有时间做任何项目。**项目是想得到的结果，不能被直接执行。能做的只有打电话、搜索、起草、确认等动作。所谓长期项目同样需要当前行动；如果现在不准备推进，就应诚实地放进“将来／也许”。
- **第 49 章　坚持做好小事，就能产生重大影响。**储蓄、锻炼、沟通和反思的单次效果都很小，长期重复却会改变整个状态。正面变化和负面后果都常由少量、持续发生的行为累积而成。
- **第 50 章　亲力亲为才能了解事物。**知识必须经得起行动检验。开始做以后，真实条件、阻力和方法才会显现。真正采用效率方法的人，通常已经有把事情做得更好的内在动力，因此愿意承认流程和习惯仍可改进。
- **第 51 章　动中求变更容易。**静止时启动最费力，已经行动以后，改变方向反而容易。感觉失控时，先回答想得到什么结果、下一步是什么，哪怕只处理桌面上的一份材料，也能重新回到掌舵位置。
- **第 52 章　最伟大的成功源自最惨重的失败。**火箭靠途中不断修正偏差到达目标，人也只有参加游戏才会犯错。衡量进步，不必要求每次都正确，可以看一段时间内“更佳选择”所占的比例是否提高；一次失手不应成为退出的理由。

##### 几条容易被一句话带过的原则

###### 第 4 章：有些东西，你越是抵制越难以摆脱

地图只有在知道当前位置时才有用。要改变工作或生活，先要客观承认现在到底承担了什么、哪些事情尚未完成。拒绝整理完整清单，并不会让这些承诺消失，只会让它们以模糊压力的方式继续存在。

###### 第 7 章：很多人把糟糕的管理与命运混为一谈

项目清单上的事项不一定同样紧急，但都需要被同等认真地判断：是否已经承诺、下一步是什么、何时再看。很多危机并非突然发生，而是在事情还只是“需要处理”时长期无人负责，最后被拖成“必须马上处理”。

轮胎需要更换时，下一步原本只是打电话询价；拖到爆胎以后，下一步就变成了求援。前者是管理，后者看起来才像命运。

###### 第 32 章：系统的效率与你的感知度成反比

如果做事时还要不断操心系统怎么用，注意力就被管理工具占走了。系统安装、调整和升级的目标，是让人尽快不再考虑系统本身，把精力放回工作、思考和创造。

好的系统像汽车的换挡、温控和通风：平时安静运行，只有失效时才会引起注意。

###### 第 36 章：确定原则，而不是监管制度

规则通常出现在原则没有说清楚，或者彼此不信任原则会被遵守的时候。如果团队对目标、边界和不能妥协的标准已经形成共识，成员就可以自行判断和行动；缺少这种共识，只能依靠更多规则和微观管理维持秩序。

###### 第 39 章：资源越有限，规划越有必要

如果时间、金钱和精力无限，很多事情根本不需要管理。正因为资源有限，才必须明确目标、比较取舍，把资源放到真正想得到的结果上。愿景和现实之间的距离越大，越需要规划。

###### 第 41 章：过度控制等于失去控制

网球拍握得太紧，反而会影响击球。工作也是一样：细节只有在服务结果时才值得管理。把大量时间花在分类、标签、软件和流程上，却没有推动任何结果，只是把“组织有序”变成了另一种拖延。

###### 第 45 章：预料之内的意外算不上意外

计划时如果已经承认干扰一定会出现，就可以预留空间并继续推进。拒绝接受现实会变化，只会增加对抗和挫败。能够消除的干扰就消除，不能消除的就把它作为工作的一部分纳入计划。

###### 第 47 章：放慢速度以提升速度

长期只盯着行动层面，视野会越来越窄，精力也会过早耗尽。定期停下来整理、休息和重新集中精神，才能看见目标、方法、进度和资源是否还匹配。放慢不是停止推进，而是避免在错误方向上越跑越快。

###### 第 48 章：你没有时间做任何项目

项目只是想得到的结果，真正能做的只有一个个动作。结清税款、出售公司或准备生日聚会，都不能一步完成，只能通过查询、打电话、起草、确认等行动逐渐实现。

所谓“没有时间做项目”，往往是没有把项目拆到下一步。即使是长期项目，当前通常也能找到一个几分钟内可以启动的动作。

列出行动和项目清单并不只是为了完成工作，然后无所事事。处理自己关注的事情的目的，在于你可以做自己真正喜欢做的事情，集中精力和创造力全身心地投入其中。

每周回顾既要更新已有清单，也要捕捉可能为工作和生活增加价值的新想法。

整套方法最后落在两件事上：

1. 思考目前从事的工作；
2. 为思考的内容采取行动。

##### 第五部分：注意基本要素

> **以下“工作流程的 5 个阶段”“自然式计划模式”和“每周回顾指南”，均出自《搞定Ⅱ》第五部分。它们是对 GTD 基本方法的集中核查，不属于前面的 52 章正文。**

##### 工作流程的 5 个阶段

这是实现**横向控制**的操作指南——怎样掌握、认识并处理好自己的全部任务。第 2 阶段和第 3 阶段将在“处理与组织整理流程图”中得到进一步说明。在真正成为习惯之前，“处理与组织整理流程图”是你案头非常有效的一种工具。

###### 1. 收集

- 捕获吸引注意力的一切外部事务（工作篮、电子邮件、笔记本、语音邮件等），并将其从大脑的短期记忆中清空。
- 根据需要尽量减少收集工具的数量。
- 通过处理和组织整理（参考下文）定期清空收集工具。

###### 2. 处理

- 处理收集到的项目（决定如何处理收集到的材料）。
- 如果**不需要**采取行动，可以抛开，也可以“存入备忘录”留待日后处理，或者将其归档备查。
- 如果**需要**采取行动，那就确定随后采取的具体行动，要么亲自处理（如果两分钟内可以完成），要么委托他人，要么延迟处理。

###### 3. 组织整理

把收集到的输入信息结果分成恰当的可检索、可检查的类别。4 种主要的行动类别分别是：

- **项目**——决定实施的项目
- **日程表**——具体某一天或某个时刻需要采取的行动
- **下一步行动**——需要尽早采取的行动
- **等待**——其他人承担的项目和采取的行动，但你要加以关注

在此之上：

- 增加有利于工作的次级类别清单（例如“电话”清单、“杂事”清单、“家”清单、“电脑”清单等）。
- 添加对你有影响的长远目标和价值清单。
- 添加需要时可能有用的核查清单（工作职责、“引子”清单、组织结构图等）。
- 针对无须采取行动但需要能检索的信息和材料，建立一般性参考资料归档系统。
- 针对以后可能采取行动的“引子”，建立一种存储系统（“将来／也许”清单、日程表、备忘录）。
- 必要时，为项目建立辅助信息文件。

###### 4. 回顾

- 每天查看日程表和“下一步行动”清单，确保当下的选择有据可依。
- 每周对整个系统做一次完整回顾，让所有清单重新变得可信（详见下文“每周回顾指南”）。
- 定期从更高层面检视目标、责任范围与长远方向。

###### 5. 执行

- 用情境、时间、精力、重要性这四个标准，决定此刻做什么。
- 在事先安排好的工作、突发事件、安排自己的工作这三类之间做出取舍。
- 相信系统给出的选项，然后专注地做那一件事。

##### 自然式计划模式

这一模式是参照大脑自然计划各项事务的模式建立起来的。它提供的是**纵向控制**，例如考虑单个具体项目或情境的最有效方式。明确所有项目之后，要轻松自然地加以驾驭，每个项目可能都需要你在一个或多个层面投入更多关注。

###### 1. 目的／指导原则

- 为什么要做这件事？“有目的”究竟是什么意思？
- 为项目做出决策、采取行动时，我们应该遵循哪些关键标准？遵守哪些规则？
- 目的和原则是项目决策的指导性标准。

###### 2. 使命／愿景／目标／成功的结果

- 如果事情大获成功，将会是什么情况？我怎么知道这种情况？
- 利益相关方会如何看待和感受那种成功呢？

###### 3. 头脑风暴

- 关于这件事情，我有哪些想法？现实情况如何？
- 先把所有念头倒出来，不做评判、不分优劣，数量优先于质量。

###### 4. 组织整理

- 从倒出来的想法中辨认出关键的组成部分、先后顺序和轻重缓急。
- 该分层的分层，该排序的排序，让结构自己浮现出来。

###### 5. 明确下一步的行动方案

- 这个项目当前能推进的具体物理动作是什么？
- 由谁在什么情境下完成？把它放进对应的清单。

> 如果你已经把项目从头脑中抛开，那说明计划很充分。如果项目还在你头脑中萦绕，那就坚持继续使用这种模式，直到项目变得明朗。

##### 每周回顾指南

第一项挑战是按照这些模式开展工作，第二项挑战则是让这些模式充满活力、始终发挥作用。本指南将为你实现更轻松、更富效力、持续始终的生活及工作方式提供一把万能钥匙。这个流程如果发挥作用，将有助于提升管理指挥中心的思考能力和信心。**如果能做到每隔 7 天运作一次，它将发挥出最大的效力。**

###### 散落的纸片

- 搜罗各种零碎纸片、名片、收据和各类文件，放进工作篮等候处理。

###### 整理笔记

- 回顾一下日志／笔记本上的记录、会议记录和笔记本活页纸上潦草写下的各种笔记，分门别类地记录任务、项目、待处理事项等。

###### 清空大脑

- （按照合适的类别）写下还没有掌握的所有新项目、任务、待处理事项、将来／也许会处理的事项等。

###### 回顾“行动”清单

- 标出完成的行动，查看将要执行的行动的提示信息。

###### 回顾“等待”清单

- 记录为后续措施采取的适当行动，检查标出最近收到的反馈。

###### 回顾“项目（及更重大的结果）”清单

- 依次评估项目、目标和结果的当前情况，确保对每一项都采取了行动。浏览工作进度辅助材料，构想新的行动、要完成的任务和待处理工作等。

###### 回顾以往的日程表

- 仔细查看以往的日程表，搜寻未完成的工作、有用的参考数据等，将其纳入当前系统中。

###### 回顾将来的日程表

- 浏览一下将来的日程安排——包括长期和短期安排，记住需要采取的行动。

###### 回顾相关的核查清单

- 以此作为采取新行动的引子。

###### 回顾“将来／也许”清单

- 查看一下哪些项目现在或许可以开展了，将其转移到项目清单上。

### 第三册：《搞定Ⅲ：平衡工作与生活的艺术》

> **提炼范围**：戴维·艾伦《搞定Ⅲ：平衡工作与生活的艺术》。正文保留这一本新增的掌控与视角矩阵、五个掌控步骤、六个视角高度和实际运用方法；原理段落按原意润色，不改成只有结论的提纲。

《搞定Ⅲ》把前两本的内容重新收成两个维度：

- **掌控**：把引起注意的事务捕捉下来，明确意义，放进可靠系统，并持续更新；
- **视角**：从行动、项目、责任、目标、愿景和宗旨六个高度判断方向。

书中把工作比作一场可以认真投入的游戏。只要目标、边界、内容和规则足够清楚，行动就不再只是被任务推动，而是在一个可以判断输赢、调整策略的系统中推进。

书中把 GTD 的掌握程度概括为三种状态：

1. 了解几个术语，以为自己已经掌握；
2. 理解了基本方法，但系统还没有发挥完整作用；
3. 把方法变成习惯，能够同时维持掌控和视角。

手边常备一个可以随时记录的工具，是进入系统的第一步。哪怕一时没有写下任何内容，知道有一个可靠入口，也会降低大脑继续抓住想法的冲动。不过，随手记录只是起点，真正起作用的是后续的明确、组织、深思和参与。

##### GTD 模型的内在逻辑

**力量＝精力集中**

精力集中才能让行动真正产生效果。弹钢琴、练习空手道、训练宠物、学习语言，或者完成一次重要谈话，都要求注意力落在同一件事上。注意力被切散以后，即使投入了时间，实际效果也会明显下降。

**精力集中＝不分心**

分心既可能来自噪声、临时闯入、电脑故障等外部打断，也可能来自尚未处理的想法和承诺。人即使独自待在安静的房间里，思绪仍可能不断跳到别处。外部环境安静，不代表大脑已经安静。

书中把这条关系继续向下推了一步：很多内在分心并不是注意力天生不足，而是事务尚未得到恰当处置。大脑不知道某项承诺意味着什么、由谁负责、何时再看，只能持续把它送回意识。

**分心＝事务处置不当**

###### 如何释放承诺未兑现时的压力

减轻未兑现承诺带来的压力，需要同时做到两件事：

- 捕捉所有引起注意的事务，明确它们在行动、项目和更高层面上的意义，再按意义组织整理；
- 在需要的时候查看系统，追踪进展，让大脑相信这些承诺不会被遗忘。

##### 全局视角

《搞定Ⅲ》提出一种看法：把生活当成需要经营的事业，把工作当成一场有目标、边界、内容和规则的游戏。视角决定当前行动放在什么背景中理解，也决定一件紧急事务究竟值不值得投入。

日程表可能是最典型的外脑：人不必记住未来某一天要发生的事情，只要相信日程表会在正确时间重新呈现它。项目清单、行动清单和参考系统也承担同样的作用。

注意力集中在一个边界明确的问题上时，大脑可以把事情做得很漂亮，也可以处理很高的复杂度；几个没有明确边界的问题纠缠在一起时，判断和创造力都会下降。因此，“有条理”并不只是把东西排列整齐，而是先弄清每样东西的意义和边界。

“有条理”的概念应该变成“掌握主动权”，因为组织整理只是解决问题的一小步，而且也不是第一步。同样，“明确优先级别”的内涵要扩展，变成“在适当层面明确目标”，这比单纯制订战略计划要更深刻。

> 关注吸引你注意力的事情。
>
> “有条理”究竟意味着什么——意义先于条理。

##### 掌控与视角的矩阵

> **本节来源：《搞定Ⅲ》第 3 章“自我管理的基本内容”。**

《搞定Ⅲ》把自我管理放在“掌控”和“视角”两个维度中考察：

|  | 视角较低 | 视角较高 |
| --- | --- | --- |
| **掌控较低** | 受害者；积极的一面是回应者 | 空想家；积极的一面是梦想家 |
| **掌控较高** | 微观管理者；积极的一面是执行者 | 舰长和指挥官 |

这不是给人贴固定标签。同一个人可能把财务管理得很清楚，却不知道事业往哪里走；也可能对工作方向很有把握，家里的事务却乱成一团。项目推进到不同阶段，也会在四个象限之间移动。

- 掌控和视角都低，容易被最新、最紧急的事情推着走；
- 掌控高、视角低，容易过度关注结构、流程和细节；
- 视角高、掌控低，想法和承诺很多，实际推进很少；
- 两边都比较高，才是书里所说的“舰长和指挥官”。

##### 处理与组织整理流程图

材料进入“工作篮”之后，只需反复问两个问题：**这是什么？****需要采取行动吗？**

```mermaid
flowchart TD
    IN[材料] --> BOX[工作篮]
    BOX --> Q1{这是什么？}
    Q1 --> Q2{需要采取行动吗？}

    Q2 -- 不需要 --> TRASH[垃圾／回收物]
    Q2 -- 不需要 --> SOMEDAY[将来／也许清单<br/>备忘文件夹]
    Q2 -- 不需要 --> REF[参考资料<br/>纸质／电子清单]

    Q2 -- 需要 --> NEXT{下一步需要<br/>采取什么行动？}
    NEXT -- 需要多步骤行动的任务 --> PROJ[项目]
    PROJ --> PLAN[项目计划]
    PLAN -.行动时备查.-> NEXT

    NEXT --> DO[立即执行<br/>两分钟之内能完成]
    NEXT --> DELEGATE[委派别人]
    NEXT --> DEFER[延迟]

    DELEGATE -- 需要跟踪进度 --> WAIT[等待清单／文件夹]
    DEFER -- 指定时间自己完成 --> CAL[日程表]
    DEFER -- 需要尽快完成的行动 --> NA[下一步行动<br/>行动提示清单]
```

对应的三种处置方式：

1. 马上执行；
2. 交给别人执行；
3. 把它暂时搁置，提醒自己及时追踪查看。

如果可以行动，想清楚具体的下一步行动：**执行**（如果不超过两分钟）、**委派别人**（在“等待”清单上追踪）或者**延后**（列入行动提示清单或收入行动文件夹）。如果某个行动不能一步完成，那么，把它的承诺视为项目，列入项目提示清单。

##### 组织整理：四大行动类别

把整理结果进行分类，以便及时查看追踪。行动可分为四大类：

- **项目**——你承诺要完成的事
- **日程表**——必须在指定日期或时间进行的行动
- **下一步行动**——要尽早做的事
- **等待事务**——应由别人执行的项目和行动

在此之上：

- 把这些清单再做细分，使之方便好用（电话、跑腿活、家里、电脑等）。
- 在清单上添加长远目标和对你具有影响的价值观。
- 必要时添加有用的对照表（岗位描述、事务提示清单、组织结构图等）。
- 把无须采取行动、但可能回访的资料归入参考系统。

###### 按情境细分的清单

- **“电话”清单**——列出你要打的所有电话，你可以在任何地方用任何电话拨打。
- **“电脑”清单**——列有必须用电脑来完成的活动：收发电子邮件、起草一份文件、网上搜索资料等。
- **“办公室”清单**——列有必须在办公室才能完成的工作，比如重新整理文档、打印、审阅一份长文件。
- **“家”清单**——列有你需要在家里和家附近完成的事情，比如修理电灯开关、整理工具箱、修剪苹果树等。
- **“任何地方”清单**——列有不受情境限制的事情，比如审阅一份长文件。你可以把它装在公文包里随身携带，随时可以打开翻看，直到看完为止。
- **“外出事宜”清单**——列有你需要外出时顺路处理的事情。

###### “等待”清单

这个细分项下的内容不少，它像 GTD 的其他层面一样，可能使人们大大减轻心理压力。它包括你所等待的、其他来源的一切事务，包括你委派别人去完成的任务、订购而尚未送到的商品、出借物品、老板或潜在客户已经认可的事务等。某件事接下来的行动往往不由你决定，它由别人负责。你的任务是追踪谁是责任人，确保他们收到了任务指令，并适时掌握事务的进度。

###### 将来／也许

第一类是你想要定期总结的事务。它们应该被列成清单或者投入工作篮里，必要时你可以定期查看。比如，你一直在考虑近期学一学西班牙语（但不是本周），你也许希望经常想起这件事。

##### 五个动作

> **本节来源：《搞定Ⅲ》第 4～8 章。**

这五个动作不是一张待办事项清单，而是一条完整的控制链。任何一环太弱，都会让事务重新回到脑中：没有捕捉，就会担心遗漏；没有明确意义，工作篮只是换了地方的杂物堆；没有组织整理，决定过的事情仍然找不到；没有深思，清单会过期；没有参与，系统就失去实际用途。

###### 1. 捕捉

捕捉的对象，是所有正在吸引注意力的事情。它可能是坏掉的打印机、迟迟没回复的邮件，也可能是一个项目、工作职责、未来目标或人生方向。第一步只负责把异常和心事从环境与大脑中分离出来，暂时不判断它是否重要，也不急着解决。

工具可以是纸笔、工作篮、白板、录音或电子清单，关键是随时可用，并且数量尽量少。一次完整的大脑清扫，还要扫描办公桌、书柜、抽屉、公文包、电子邮箱和脑中尚未写下的承诺。捕捉不完整，大脑便知道系统之外仍有遗漏，仍会自行承担提醒工作。

团队也需要共同捕捉。会议中没有写出来的问题、建议和隐忧，并不会因为无人提起而消失；它们只会继续占用集体注意力。

###### 2. 明确意义

明确意义就是逐项清空工作篮。拿起一项材料，先问“这是什么”，再问“需要采取行动吗”。不需要行动的内容，分别进入垃圾、将来／也许或参考资料；需要行动的内容，则继续明确两个问题：

1. 想得到的结果是什么？
2. 可以推进这项结果的下一步具体行动是什么？

“研究一下”“处理预算”“推进合作”还不是足够明确的行动。如果研究本身需要多个步骤，它就是一个项目；眼下真正能做的，可能是“搜索三家供应商的报价”“给财务打电话确认口径”或“起草合作邮件”。这一步并不要求立刻把所有事情做完，而是消除它们的模糊性。

###### 3. 组织整理

组织整理不是先建许多文件夹，而是把已经明确意义的内容放进与其性质相符的位置。固定日期发生的事进入日程表，尽快完成的动作进入按情境划分的行动清单，交给别人的事项进入“等待”，多步骤结果进入项目清单，暂不承诺的想法进入“将来／也许”。

意义先于条理。会议记录、便条和电子邮件只是材料来源，并不是最终类别。一页会议笔记里可能同时藏着自己的下一步行动、等待同事回复的事项、一个新项目和几条参考信息，必须拆开后各归其位。

###### 4. 深思

系统只有在被持续查看时才可信。深思有两个作用：一是更新内容，删除已经完成的事项，补入新项目和新行动；二是提供视角，把眼前行动放回项目、责任和目标中判断。

日程表和行动清单需要在每天及相应情境中查看；项目和整个系统至少每周完整回顾一次。回顾并不是重新把所有工作做一遍，而是把已经发生的变化纳入地图，使自己再次知道现在有哪些选择、哪些承诺需要推进。

###### 5. 参与

参与是实际采取行动。系统的作用不是替人自动排出唯一正确的顺序，而是提供一组经过思考、可以信任的选项。到了行动现场，再根据情境、可用时间、精力和相对重要性选择一项，专心去做。

日常工作通常在三种状态之间切换：完成预先确定的工作，处理突然出现的事务，以及停下来定义新的工作。只执行清单而不接住现实，会变得僵硬；只应付突发事务，会失去方向；一直整理和规划而不行动，也不会产生结果。所谓掌控，是知道自己此刻处于哪一种状态，并有意识地作出选择。

##### 高度图：六个视角层次

“工作”至少要在 6 个层面被定义和管理，它们分别对应视角的不同高度，涵盖了从根本意图（对一件事、一项事业、一种生活的意义和价值的理解）直至日常琐事（由意义和价值观引发、推动事务发展的具体下一步行动）。如果你能对自己在多个层面参与社会生活的行为做出评价，妥善地分辨、捕捉和执行各种承诺和事务，就能做到心思澄明，减少精力的无谓消耗。多个层面的和谐可以使办事效率达到最高水平。

优先级自上而下排列，也就是说，你的宗旨和价值观决定你的愿景，构想导出具体目标，具体目标构成关注和职责范围。它们共同引出项目，项目要求通过行动来完成。明确、顺利执行各个关注层面的事务是同等重要的，但是，你在各个层面的思考内容和承诺却有所区别。

> **本节来源：《搞定Ⅲ》第 11～16 章。**

| 高度 | 看的是什么 | 原书建议的检查节奏 |
| --- | --- | --- |
| 跑道 | 当前可以执行的下一步行动 | 每天以及情境允许时查看 |
| 1 万英尺 | 需要多个步骤、通常一年内完成的项目 | 至少每周检查 |
| 2 万英尺 | 工作和生活中需要长期维持的责任、角色和兴趣范围 | 大约每月，或职责发生变化时 |
| 3 万英尺 | 未来一两年希望完成的目标 | 至少每年，必要时按月或季度校准 |
| 4 万英尺 | 两年以上的愿景、生活方式和长期方向 | 每年、每两三年，或重大变化发生时 |
| 5 万英尺 | 宗旨和原则 | 启动重要事项、出现分歧、资源取舍或人生转折时 |

**4 万英尺——愿景。**顺利落实的感觉如何，看起来、听上去是什么样？长远结局和理想图景。

- **格式**：与合伙人、董事会、团队、家庭召开外出会议；对即将启动的项目、会议、整个企业的初步讨论；人生规划；每年重新思考企业的方向；提出理想情景；个人藏宝图
- **频率**：有必要进一步明确和指明方向、协调努力、激发动力的时候

##### 自下而上还是自上而下

从逻辑上看，六个层次应当自上而下统一：宗旨和原则形成愿景，愿景导出目标，目标决定责任与项目，项目再落实为行动。判断先回复哪封邮件，最终也应当能够追溯到更高层面的方向。

实际整理时，书中却更常建议自下而上。人的注意力往往先被未回复的邮件、要买的猫粮、坏掉的设备和临近的约会占据。只要这些事情还模糊地堵在眼前，直接讨论使命和愿景就很难落地。先把跑道上的事务处理清楚，再检查项目、责任和目标，视野通常会自然打开。

自上而下也有适用的时候。企业合并后需要先统一价值观和文化，人生出现重大选择时需要先重新确认原则，新项目启动时需要先说清目的。原书并没有规定唯一顺序，它给出的判断标准是：**从最吸引你注意力、最需要恢复清晰度的层面入手。**

##### 自然式计划模式

###### 1. 宗旨／指导原则

- 为什么要做这件事？“符合宗旨”究竟是什么意思？
- 做出决策和执行该项目的重要标准是什么？要遵守什么原则？
- 原则和宗旨是项目决策的指导性标准。

###### 2. 使命／愿景／目标／成功的结果

- 大功告成是什么样？怎么知道已经大功告成？
- 各利益相关方对圆满的结果有何看法，感觉如何？

###### 3. 头脑风暴

- 这件事在我身上体现为哪些情况？现状如何？我知道什么？不知道什么？我该考虑哪些问题？我没有考虑哪些问题？
- 要全面，要坦诚接纳，不做评判，克制批评性的分析。
- 从多个角度考虑。

###### 4. 组织整理

- 指出构成因素（项目细分）、先后或重要性排序。

###### 5. 明确下一步行动

- 找出当前真正能推进项目的具体物理动作；
- 明确由谁负责，在什么情境下完成；
- 把行动放进日程表、“下一步行动”或“等待”等相应位置。

如果做完这五步以后，项目仍反复萦绕在脑中，通常说明某个层面还不够清楚：目的有冲突、成功结果不具体、想法没有倒完、结构尚未理顺，或者还没决定下一步。

##### 项目规划提示清单

**客户／社区／法律**

- 问题是什么？
- 有哪些规章制度？

**空间／公共设施／设备**

- 什么需要占地方？怎么找地方？
- 要用什么工具？什么时候？
- 电话／电脑

**调查了解**

- 你也许要了解什么情况？

**公关**

- 让别人知道，对事情好不好？怎么做？

**风险**

- 可能发生什么情况？你能处理吗？

**创意思考**

- 谁关心项目的成功？
- 他们会说什么话、提什么问题、给出什么意见是你尚未执行的？
- 这件事你能想到的最坏结果是什么？（反过来，最好的结果是什么？）

##### 执行：如何、何时

行动是系统的前线，但“紧急”不能替代判断。执行时，先排除当前情境、时间和精力无法支持的事项，再比较剩余行动的相对重要性。更高层面的宗旨和目标会影响选择，眼前的现实条件也同样构成边界。

日程表只放必须在特定日期或时间完成的硬边界，不能塞满所有希望做的事情。其余行动保留在情境清单中，给变化和判断留下余地。新的紧急事项出现时，可以有意识地改选，而不是假装原计划仍未受到影响。

##### 把系统真正启动起来

> **本节来源：《搞定Ⅲ》第 18 章“实际运用”。**

原书给出的启动顺序很具体：

1. 准备随手可用的捕捉工具，让办公桌、家中、通勤和出差途中都有可靠入口；
2. 建立可信的日程表、行动清单、“等待”清单和专项事务清单；
3. 建立方便归档和检索的纸质、电子参考系统；
4. 在办公室、家中和移动途中准备能直接进入工作状态的工作台；
5. 做一次完整的大脑清扫，把环境和脑中的未完成事务全部倒入系统；
6. 逐项明确结果与下一步行动，用真实项目不断修正系统。

系统建立后还需要固定维护。工作篮的用途不是存放，而是周转；邮件、便条、语音留言等捕捉入口，目标是每隔 **24～48 小时**处理到清零。事情偶尔积压并不代表失败，但积压不能变成默认状态。

每天的新输入本身就需要整理时间，不能期待它在开会或完成高强度工作的同时自动消失。每周再留出一段不受打扰的时间做完整回顾，原书建议初期预留连续两小时。2 万到 5 万英尺的责任、目标、愿景和宗旨也需要专门安排时间思考，不能只等它们偶然浮现。

##### 每周回顾

回顾系统有两个同等重要的目的：

1. 更新内容；
2. 提供可靠的视角。

###### 保持清爽

**收集零散的文件和材料**

- 把积累的名片、收据和庞杂的纸质材料收集起来，放入工作篮。

**清空工作篮**

- 把待处理的纸质材料、日志、会议记录、语音信箱、献辞和电子邮件等彻底清理。

**清空大脑**

- 写下并处理一切未捕捉的新的“项目”、“行动”、“等待”、“将来／也许”清单。

###### 保持最新

**查看行动清单**

- 把已完成的项目勾掉。查看下一步行动的提示信息并做记录。

**查看翻过去的日程表事务**

- 寻找遗留的行动和参考资料等，把它们转移到日程表新的一页。

**查看即将发生的日程表事务**

- 查看长远和短期的日程安排，捕捉它们所引发的行动。

**查看“等待”清单**

- 记录后续措施，检查最近收到的反馈。

- 日期: 2026-06-18
- 分类: 读书有感

> **版本说明**：这是对照原书补齐的独立提炼版。[查看线上原稿](/88750187/) · [查看三部曲合集](/6220a80a/) · [查看实践清单手册](/f009420a/)

> **提炼范围**：戴维·艾伦《搞定Ⅲ：平衡工作与生活的艺术》。正文保留这一本新增的掌控与视角矩阵、五个掌控步骤、六个视角高度和实际运用方法；原理段落按原意润色，不改成只有结论的提纲。

《搞定Ⅲ》把前两本的内容重新收成两个维度：

- **掌控**：把引起注意的事务捕捉下来，明确意义，放进可靠系统，并持续更新；
- **视角**：从行动、项目、责任、目标、愿景和宗旨六个高度判断方向。

书中把工作比作一场可以认真投入的游戏。只要目标、边界、内容和规则足够清楚，行动就不再只是被任务推动，而是在一个可以判断输赢、调整策略的系统中推进。

书中把 GTD 的掌握程度概括为三种状态：

1. 了解几个术语，以为自己已经掌握；
2. 理解了基本方法，但系统还没有发挥完整作用；
3. 把方法变成习惯，能够同时维持掌控和视角。

手边常备一个可以随时记录的工具，是进入系统的第一步。哪怕一时没有写下任何内容，知道有一个可靠入口，也会降低大脑继续抓住想法的冲动。不过，随手记录只是起点，真正起作用的是后续的明确、组织、深思和参与。

### GTD 模型的内在逻辑

**力量＝精力集中**

精力集中才能让行动真正产生效果。弹钢琴、练习空手道、训练宠物、学习语言，或者完成一次重要谈话，都要求注意力落在同一件事上。注意力被切散以后，即使投入了时间，实际效果也会明显下降。

**精力集中＝不分心**

分心既可能来自噪声、临时闯入、电脑故障等外部打断，也可能来自尚未处理的想法和承诺。人即使独自待在安静的房间里，思绪仍可能不断跳到别处。外部环境安静，不代表大脑已经安静。

书中把这条关系继续向下推了一步：很多内在分心并不是注意力天生不足，而是事务尚未得到恰当处置。大脑不知道某项承诺意味着什么、由谁负责、何时再看，只能持续把它送回意识。

**分心＝事务处置不当**

#### 如何释放承诺未兑现时的压力

减轻未兑现承诺带来的压力，需要同时做到两件事：

- 捕捉所有引起注意的事务，明确它们在行动、项目和更高层面上的意义，再按意义组织整理；
- 在需要的时候查看系统，追踪进展，让大脑相信这些承诺不会被遗忘。

### 全局视角

《搞定Ⅲ》提出一种看法：把生活当成需要经营的事业，把工作当成一场有目标、边界、内容和规则的游戏。视角决定当前行动放在什么背景中理解，也决定一件紧急事务究竟值不值得投入。

日程表可能是最典型的外脑：人不必记住未来某一天要发生的事情，只要相信日程表会在正确时间重新呈现它。项目清单、行动清单和参考系统也承担同样的作用。

注意力集中在一个边界明确的问题上时，大脑可以把事情做得很漂亮，也可以处理很高的复杂度；几个没有明确边界的问题纠缠在一起时，判断和创造力都会下降。因此，“有条理”并不只是把东西排列整齐，而是先弄清每样东西的意义和边界。

“有条理”的概念应该变成“掌握主动权”，因为组织整理只是解决问题的一小步，而且也不是第一步。同样，“明确优先级别”的内涵要扩展，变成“在适当层面明确目标”，这比单纯制订战略计划要更深刻。

> 关注吸引你注意力的事情。
>
> “有条理”究竟意味着什么——意义先于条理。

### 掌控与视角的矩阵

> **本节来源：《搞定Ⅲ》第 3 章“自我管理的基本内容”。**

《搞定Ⅲ》把自我管理放在“掌控”和“视角”两个维度中考察：

|  | 视角较低 | 视角较高 |
| --- | --- | --- |
| **掌控较低** | 受害者；积极的一面是回应者 | 空想家；积极的一面是梦想家 |
| **掌控较高** | 微观管理者；积极的一面是执行者 | 舰长和指挥官 |

这不是给人贴固定标签。同一个人可能把财务管理得很清楚，却不知道事业往哪里走；也可能对工作方向很有把握，家里的事务却乱成一团。项目推进到不同阶段，也会在四个象限之间移动。

- 掌控和视角都低，容易被最新、最紧急的事情推着走；
- 掌控高、视角低，容易过度关注结构、流程和细节；
- 视角高、掌控低，想法和承诺很多，实际推进很少；
- 两边都比较高，才是书里所说的“舰长和指挥官”。

### 处理与组织整理流程图

材料进入“工作篮”之后，只需反复问两个问题：**这是什么？****需要采取行动吗？**

```mermaid
flowchart TD
    IN[材料] --> BOX[工作篮]
    BOX --> Q1{这是什么？}
    Q1 --> Q2{需要采取行动吗？}

    Q2 -- 不需要 --> TRASH[垃圾／回收物]
    Q2 -- 不需要 --> SOMEDAY[将来／也许清单<br/>备忘文件夹]
    Q2 -- 不需要 --> REF[参考资料<br/>纸质／电子清单]

    Q2 -- 需要 --> NEXT{下一步需要<br/>采取什么行动？}
    NEXT -- 需要多步骤行动的任务 --> PROJ[项目]
    PROJ --> PLAN[项目计划]
    PLAN -.行动时备查.-> NEXT

    NEXT --> DO[立即执行<br/>两分钟之内能完成]
    NEXT --> DELEGATE[委派别人]
    NEXT --> DEFER[延迟]

    DELEGATE -- 需要跟踪进度 --> WAIT[等待清单／文件夹]
    DEFER -- 指定时间自己完成 --> CAL[日程表]
    DEFER -- 需要尽快完成的行动 --> NA[下一步行动<br/>行动提示清单]
```

对应的三种处置方式：

1. 马上执行；
2. 交给别人执行；
3. 把它暂时搁置，提醒自己及时追踪查看。

如果可以行动，想清楚具体的下一步行动：**执行**（如果不超过两分钟）、**委派别人**（在“等待”清单上追踪）或者**延后**（列入行动提示清单或收入行动文件夹）。如果某个行动不能一步完成，那么，把它的承诺视为项目，列入项目提示清单。

### 组织整理：四大行动类别

把整理结果进行分类，以便及时查看追踪。行动可分为四大类：

- **项目**——你承诺要完成的事
- **日程表**——必须在指定日期或时间进行的行动
- **下一步行动**——要尽早做的事
- **等待事务**——应由别人执行的项目和行动

在此之上：

- 把这些清单再做细分，使之方便好用（电话、跑腿活、家里、电脑等）。
- 在清单上添加长远目标和对你具有影响的价值观。
- 必要时添加有用的对照表（岗位描述、事务提示清单、组织结构图等）。
- 把无须采取行动、但可能回访的资料归入参考系统。

#### 按情境细分的清单

- **“电话”清单**——列出你要打的所有电话，你可以在任何地方用任何电话拨打。
- **“电脑”清单**——列有必须用电脑来完成的活动：收发电子邮件、起草一份文件、网上搜索资料等。
- **“办公室”清单**——列有必须在办公室才能完成的工作，比如重新整理文档、打印、审阅一份长文件。
- **“家”清单**——列有你需要在家里和家附近完成的事情，比如修理电灯开关、整理工具箱、修剪苹果树等。
- **“任何地方”清单**——列有不受情境限制的事情，比如审阅一份长文件。你可以把它装在公文包里随身携带，随时可以打开翻看，直到看完为止。
- **“外出事宜”清单**——列有你需要外出时顺路处理的事情。

#### “等待”清单

这个细分项下的内容不少，它像 GTD 的其他层面一样，可能使人们大大减轻心理压力。它包括你所等待的、其他来源的一切事务，包括你委派别人去完成的任务、订购而尚未送到的商品、出借物品、老板或潜在客户已经认可的事务等。某件事接下来的行动往往不由你决定，它由别人负责。你的任务是追踪谁是责任人，确保他们收到了任务指令，并适时掌握事务的进度。

#### 将来／也许

第一类是你想要定期总结的事务。它们应该被列成清单或者投入工作篮里，必要时你可以定期查看。比如，你一直在考虑近期学一学西班牙语（但不是本周），你也许希望经常想起这件事。

### 五个动作

> **本节来源：《搞定Ⅲ》第 4～8 章。**

这五个动作不是一张待办事项清单，而是一条完整的控制链。任何一环太弱，都会让事务重新回到脑中：没有捕捉，就会担心遗漏；没有明确意义，工作篮只是换了地方的杂物堆；没有组织整理，决定过的事情仍然找不到；没有深思，清单会过期；没有参与，系统就失去实际用途。

#### 1. 捕捉

捕捉的对象，是所有正在吸引注意力的事情。它可能是坏掉的打印机、迟迟没回复的邮件，也可能是一个项目、工作职责、未来目标或人生方向。第一步只负责把异常和心事从环境与大脑中分离出来，暂时不判断它是否重要，也不急着解决。

工具可以是纸笔、工作篮、白板、录音或电子清单，关键是随时可用，并且数量尽量少。一次完整的大脑清扫，还要扫描办公桌、书柜、抽屉、公文包、电子邮箱和脑中尚未写下的承诺。捕捉不完整，大脑便知道系统之外仍有遗漏，仍会自行承担提醒工作。

团队也需要共同捕捉。会议中没有写出来的问题、建议和隐忧，并不会因为无人提起而消失；它们只会继续占用集体注意力。

#### 2. 明确意义

明确意义就是逐项清空工作篮。拿起一项材料，先问“这是什么”，再问“需要采取行动吗”。不需要行动的内容，分别进入垃圾、将来／也许或参考资料；需要行动的内容，则继续明确两个问题：

1. 想得到的结果是什么？
2. 可以推进这项结果的下一步具体行动是什么？

“研究一下”“处理预算”“推进合作”还不是足够明确的行动。如果研究本身需要多个步骤，它就是一个项目；眼下真正能做的，可能是“搜索三家供应商的报价”“给财务打电话确认口径”或“起草合作邮件”。这一步并不要求立刻把所有事情做完，而是消除它们的模糊性。

#### 3. 组织整理

组织整理不是先建许多文件夹，而是把已经明确意义的内容放进与其性质相符的位置。固定日期发生的事进入日程表，尽快完成的动作进入按情境划分的行动清单，交给别人的事项进入“等待”，多步骤结果进入项目清单，暂不承诺的想法进入“将来／也许”。

意义先于条理。会议记录、便条和电子邮件只是材料来源，并不是最终类别。一页会议笔记里可能同时藏着自己的下一步行动、等待同事回复的事项、一个新项目和几条参考信息，必须拆开后各归其位。

#### 4. 深思

系统只有在被持续查看时才可信。深思有两个作用：一是更新内容，删除已经完成的事项，补入新项目和新行动；二是提供视角，把眼前行动放回项目、责任和目标中判断。

日程表和行动清单需要在每天及相应情境中查看；项目和整个系统至少每周完整回顾一次。回顾并不是重新把所有工作做一遍，而是把已经发生的变化纳入地图，使自己再次知道现在有哪些选择、哪些承诺需要推进。

#### 5. 参与

参与是实际采取行动。系统的作用不是替人自动排出唯一正确的顺序，而是提供一组经过思考、可以信任的选项。到了行动现场，再根据情境、可用时间、精力和相对重要性选择一项，专心去做。

日常工作通常在三种状态之间切换：完成预先确定的工作，处理突然出现的事务，以及停下来定义新的工作。只执行清单而不接住现实，会变得僵硬；只应付突发事务，会失去方向；一直整理和规划而不行动，也不会产生结果。所谓掌控，是知道自己此刻处于哪一种状态，并有意识地作出选择。

### 高度图：六个视角层次

“工作”至少要在 6 个层面被定义和管理，它们分别对应视角的不同高度，涵盖了从根本意图（对一件事、一项事业、一种生活的意义和价值的理解）直至日常琐事（由意义和价值观引发、推动事务发展的具体下一步行动）。如果你能对自己在多个层面参与社会生活的行为做出评价，妥善地分辨、捕捉和执行各种承诺和事务，就能做到心思澄明，减少精力的无谓消耗。多个层面的和谐可以使办事效率达到最高水平。

优先级自上而下排列，也就是说，你的宗旨和价值观决定你的愿景，构想导出具体目标，具体目标构成关注和职责范围。它们共同引出项目，项目要求通过行动来完成。明确、顺利执行各个关注层面的事务是同等重要的，但是，你在各个层面的思考内容和承诺却有所区别。

> **本节来源：《搞定Ⅲ》第 11～16 章。**

| 高度 | 看的是什么 | 原书建议的检查节奏 |
| --- | --- | --- |
| 跑道 | 当前可以执行的下一步行动 | 每天以及情境允许时查看 |
| 1 万英尺 | 需要多个步骤、通常一年内完成的项目 | 至少每周检查 |
| 2 万英尺 | 工作和生活中需要长期维持的责任、角色和兴趣范围 | 大约每月，或职责发生变化时 |
| 3 万英尺 | 未来一两年希望完成的目标 | 至少每年，必要时按月或季度校准 |
| 4 万英尺 | 两年以上的愿景、生活方式和长期方向 | 每年、每两三年，或重大变化发生时 |
| 5 万英尺 | 宗旨和原则 | 启动重要事项、出现分歧、资源取舍或人生转折时 |

**4 万英尺——愿景。**顺利落实的感觉如何，看起来、听上去是什么样？长远结局和理想图景。

- **格式**：与合伙人、董事会、团队、家庭召开外出会议；对即将启动的项目、会议、整个企业的初步讨论；人生规划；每年重新思考企业的方向；提出理想情景；个人藏宝图
- **频率**：有必要进一步明确和指明方向、协调努力、激发动力的时候

### 自下而上还是自上而下

从逻辑上看，六个层次应当自上而下统一：宗旨和原则形成愿景，愿景导出目标，目标决定责任与项目，项目再落实为行动。判断先回复哪封邮件，最终也应当能够追溯到更高层面的方向。

实际整理时，书中却更常建议自下而上。人的注意力往往先被未回复的邮件、要买的猫粮、坏掉的设备和临近的约会占据。只要这些事情还模糊地堵在眼前，直接讨论使命和愿景就很难落地。先把跑道上的事务处理清楚，再检查项目、责任和目标，视野通常会自然打开。

自上而下也有适用的时候。企业合并后需要先统一价值观和文化，人生出现重大选择时需要先重新确认原则，新项目启动时需要先说清目的。原书并没有规定唯一顺序，它给出的判断标准是：**从最吸引你注意力、最需要恢复清晰度的层面入手。**

### 自然式计划模式

#### 1. 宗旨／指导原则

- 为什么要做这件事？“符合宗旨”究竟是什么意思？
- 做出决策和执行该项目的重要标准是什么？要遵守什么原则？
- 原则和宗旨是项目决策的指导性标准。

#### 2. 使命／愿景／目标／成功的结果

- 大功告成是什么样？怎么知道已经大功告成？
- 各利益相关方对圆满的结果有何看法，感觉如何？

#### 3. 头脑风暴

- 这件事在我身上体现为哪些情况？现状如何？我知道什么？不知道什么？我该考虑哪些问题？我没有考虑哪些问题？
- 要全面，要坦诚接纳，不做评判，克制批评性的分析。
- 从多个角度考虑。

#### 4. 组织整理

- 指出构成因素（项目细分）、先后或重要性排序。

#### 5. 明确下一步行动

- 找出当前真正能推进项目的具体物理动作；
- 明确由谁负责，在什么情境下完成；
- 把行动放进日程表、“下一步行动”或“等待”等相应位置。

如果做完这五步以后，项目仍反复萦绕在脑中，通常说明某个层面还不够清楚：目的有冲突、成功结果不具体、想法没有倒完、结构尚未理顺，或者还没决定下一步。

### 项目规划提示清单

**客户／社区／法律**

- 问题是什么？
- 有哪些规章制度？

**空间／公共设施／设备**

- 什么需要占地方？怎么找地方？
- 要用什么工具？什么时候？
- 电话／电脑

**调查了解**

- 你也许要了解什么情况？

**公关**

- 让别人知道，对事情好不好？怎么做？

**风险**

- 可能发生什么情况？你能处理吗？

**创意思考**

- 谁关心项目的成功？
- 他们会说什么话、提什么问题、给出什么意见是你尚未执行的？
- 这件事你能想到的最坏结果是什么？（反过来，最好的结果是什么？）

### 执行：如何、何时

行动是系统的前线，但“紧急”不能替代判断。执行时，先排除当前情境、时间和精力无法支持的事项，再比较剩余行动的相对重要性。更高层面的宗旨和目标会影响选择，眼前的现实条件也同样构成边界。

日程表只放必须在特定日期或时间完成的硬边界，不能塞满所有希望做的事情。其余行动保留在情境清单中，给变化和判断留下余地。新的紧急事项出现时，可以有意识地改选，而不是假装原计划仍未受到影响。

### 把系统真正启动起来

> **本节来源：《搞定Ⅲ》第 18 章“实际运用”。**

原书给出的启动顺序很具体：

1. 准备随手可用的捕捉工具，让办公桌、家中、通勤和出差途中都有可靠入口；
2. 建立可信的日程表、行动清单、“等待”清单和专项事务清单；
3. 建立方便归档和检索的纸质、电子参考系统；
4. 在办公室、家中和移动途中准备能直接进入工作状态的工作台；
5. 做一次完整的大脑清扫，把环境和脑中的未完成事务全部倒入系统；
6. 逐项明确结果与下一步行动，用真实项目不断修正系统。

系统建立后还需要固定维护。工作篮的用途不是存放，而是周转；邮件、便条、语音留言等捕捉入口，目标是每隔 **24～48 小时**处理到清零。事情偶尔积压并不代表失败，但积压不能变成默认状态。

每天的新输入本身就需要整理时间，不能期待它在开会或完成高强度工作的同时自动消失。每周再留出一段不受打扰的时间做完整回顾，原书建议初期预留连续两小时。2 万到 5 万英尺的责任、目标、愿景和宗旨也需要专门安排时间思考，不能只等它们偶然浮现。

### 每周回顾

回顾系统有两个同等重要的目的：

1. 更新内容；
2. 提供可靠的视角。

#### 保持清爽

**收集零散的文件和材料**

- 把积累的名片、收据和庞杂的纸质材料收集起来，放入工作篮。

**清空工作篮**

- 把待处理的纸质材料、日志、会议记录、语音信箱、献辞和电子邮件等彻底清理。

**清空大脑**

- 写下并处理一切未捕捉的新的“项目”、“行动”、“等待”、“将来／也许”清单。

#### 保持最新

**查看行动清单**

- 把已完成的项目勾掉。查看下一步行动的提示信息并做记录。

**查看翻过去的日程表事务**

- 寻找遗留的行动和参考资料等，把它们转移到日程表新的一页。

**查看即将发生的日程表事务**

- 查看长远和短期的日程安排，捕捉它们所引发的行动。

**查看“等待”清单**

- 记录后续措施，检查最近收到的反馈。

开头识别了几种拖延的典型场景的解法：
**结构性拖延**：要事第一（吃掉那只青蛙） 小事可以随手做，不要先做
**完美主义拖延：** 先做，用外力倒逼自己输出
**资源松懈型拖延**：用兴趣投入战胜生态性拖延（比如在同城里没好好旅游过这种） 

以上这些是以上会变成习惯性拖延或者习惯性无助的来源。

**四种状态**

1. 习得性无助
2. 我事没做，但我人还行
3. 虽然我现在没做，但总有一天  我还是会做的
4. 既然我还是没做，就说明这事不重要，等足够重要的时候我就做了

>焦虑的反面是专注和具体。
>具有摧毁性的原因：外界干扰的控制时长和边界，目标模糊。

**山洞四律**，是以下四种朴素的行动。

**写下**：每天有固定时间用于“写下来”的练习，需要使用纸和笔进行传统书写。

**具身**：每天有固定时间用于肢体上的活动，在练习时使用身体去完成和获得练习体验。  (回到身体，觉察，因为大脑被电子产品长久侵蚀后，早已发生了器质性的变化。 所以通过八段锦和冥想？)

**戒屏**：每天有一段时间，不观看电子屏幕，不向任何电子屏幕投放注意力。  （注意力回到自身）

**做事**：全身心投入做人生本阶段最重要或最具意义的事。 （专注，心流）

> 积极解读是成熟的人和思虑深远的人才能掌握的技能

> 多数人都是在忙忙碌碌地承担选择的后果，而不是花时间去研究什么是最好的选择。

> Minimun Viable Action = action

外事外物对人的意义在于人对事物的定义。普通人关注事实结果，高手注重起心动念，高手研习如何引导和调整自己的感受。外在世界终究是由内在显化而来，心中的觉知才是真相。

有明确的时间期限，有超常的工作量，  要面对高标准的检验。你很清楚，要想完成它，需要大幅改变往常的时间表，阻断干扰，一鼓作气，让大脑进入深度沉浸的状态。你也清楚，这是你长久以来渴望完成的项目，渴望拥有的自我状态。你尤其知道，这个人生项目的完成，会推动你人生发展的进程。

## 《搞定Ⅱ：提升工作与生活效率的 52 项原则》全书提炼

- URL: https://blog.no-claw.com/6a72b0c5/
- 日期: 2026-05-13
- 分类: 读书有感
- 标签: 效率, 搞定三部曲

> **版本说明**：这是对照原书补齐的独立提炼版。[查看线上原稿](/ff723111/) · [查看三部曲合集](/6220a80a/) · [查看实践清单手册](/f009420a/)

> **提炼范围**：戴维·艾伦《搞定Ⅱ：提升工作与生活效率的 52 项原则（最新版）》。前四部分是 52 章正文，第五部分是 GTD 基本方法的核查清单；各项原则保留原书的论证和例子，只压缩重复内容并润顺译文。

《搞定Ⅱ》不是重新讲一遍操作步骤。它把 GTD 背后的原则拆成 52 篇短文，集中讨论四件事：清理未竟之事、调整关注焦点、建立可靠结构、放松并采取行动。

### 52 项原则的四个方向

正文分成四组，每组 13 章。

#### 第一部分（第 1～13 章）：理清头绪，发挥创造力

- **第 1 章　理清思路，确立新方向。**未来一定会出现今天无法预料的变化。与其猜测变化是什么，不如先清理眼前最明显的积压：工作篮、邮件、抽屉、旧项目和过期承诺。清出的空间，会成为应对新情况的余量；随身可用的捕捉工具，则负责接住在意外时刻出现的新想法。
- **第 2 章　知道哪些事情自己尚未做，你才会为之心安。**压力来自没有履行的约定，处理办法只有三种：不再承担、完成它，或者重新商定。前提是先知道自己到底答应过什么。收集、处理、组织、回顾和执行是五种不同工作，试图在列清单时一次完成，往往只会得到短暂的整齐。
- **第 3 章　理清承担的任务，可以更好地选择新任务。**不了解已有承诺，就无法诚实判断还能不能接新任务。把散落各处的待读材料集中起来，数量一目了然以后，才可能决定读什么、放弃什么。清楚的边界并不限制自由，它使专注和拒绝都有依据。
- **第 4 章　要实现未来的目标，首先明确当前的位置。**地图只有在知道当前位置时才有用。除了当前行动和项目，还要盘点责任范围、一两年的目标、较长期愿景以及人生宗旨。接受真实现状，才能判断下一步是左转还是右转。
- **第 5 章　以有限的可能，去利用无限的机遇。**机会可以无限增加，时间、精力和注意力却始终有限。管理工作流程的意义不是把所有事情都做完，而是完整收集输入、作出决定并保留可信的选择，使有限资源投入当前真正要做的事。
- **第 6 章　一心二用带来压力与失败。**大脑无法同时专注于眼前工作，又替所有未完成承诺担任提醒器。把开放回路从头脑中移出，明确其结果和行动，是一种主动应对；只有地面层的杂务得到控制，注意力才不会在两个世界之间拉扯。
- **第 7 章　有意识地权衡轻重缓急。**判断优先级之前，必须先看见全部承诺。被忽视的“次重要”项目并不会一直安静，轮胎、账单和关系问题都可能从可从容处理的小事，拖成不得不立即处理的危机。很多人把这种糟糕的管理误叫作命运。
- **第 8 章　完成未竟之事，释放自身能量。**未完成事务会持续占用心理资源，结束、取消或重新决定，都能把这部分能量释放出来。清理抽屉、归还借物、回复一封旧邮件看似平凡，却常常是恢复创造力和行动感的入口。
- **第 9 章　如果你一直想着某件事，很可能是还没有搞定。**一件事反复回到脑中，通常不是因为它最重要，而是因为还没有明确成功结果、下一步行动，或者没有把提醒放进可信系统。把这三件事处理好，大脑才会停止重复报警。
- **第 10 章　只要有空间，创造力就会展现。**创造力不一定要用力催生。积压、模糊承诺和无处安放的材料被清走以后，空出来的注意力会自然发现联系、机会和新想法。系统的作用，是为这种自发出现留出空间。
- **第 11 章　渠深流畅。**能承接多大挑战，取决于个人系统能容纳多大流量。渠道越深、越干净，新的信息和责任越不容易造成泛滥。项目清单、行动清单和定期回顾，不只是整理方法，也是扩大处理能力的基础设施。
- **第 12 章　担忧无益。**担忧是问题在头脑中循环，却没有转化为决定和行动。该思考时把问题想清楚，该行动时执行，暂时无法处理时把它放进会再次看到的系统；反复挂念本身不会改善结果。
- **第 13 章　你不是你的工作。**把工作完整地放进清单，反而更容易把自己与工作分开。清单不是身份，也不是债务记录，它只是客观地图。地图可信以后，人可以全心投入清单上的一项，也可以安心去做清单之外突然出现、真正值得做的事。

> 处理自己关注的事情的目的，在于你可以做自己真正喜欢做的事情。

#### 第二部分（第 14～26 章）：高效关注

- **第 14 章　想看得更清楚，请从更高处着眼。**下一步行动看不清时，向上检查项目计划、预期结果和目的；目标空泛时，再向下追问眼前能做什么。改变观察高度，常常比继续盯着同一个问题更快恢复清晰。
- **第 15 章　只有身体力行，你才会知道如何去做。**清楚地想象结果，会让大脑开始识别相关信息；真正动手以后，新的方法和条件才会出现。很多工作无法等到完全知道怎么做再开始，行动本身就是认识过程的一部分。
- **第 16 章　工作足够努力是不可能的。**知识工作的边界不会自动出现，总有更多邮件、想法和改进空间。单纯延长时间无法完成无限的工作，必须先决定什么值得做，再对选中的事情投入完整注意力。
- **第 17 章　精力随心思而动。**注意力落在哪里，那里就会获得更多信息、情绪和行动能量。持续盯着问题，会不断强化问题；把注意力转向想得到的结果和可以采取的行动，大脑便开始寻找通道。
- **第 18 章　目标越明确，实现目标的途径越多。**模糊愿望只能产生模糊反应。目的、成功结果和限制条件越具体，大脑越容易发现原先看不见的资源与路径。明确目标不是缩小可能性，而是给创造力一个可以工作的方向。
- **第 19 章　精益求精。**精益求精不是等待一个永远不会到来的完美状态，而是在当下条件中把手头工作做到自己能做到的最好。标准、能力和环境会继续变化，卓越是一种持续校正的动态过程。
- **第 20 章　关注重心的变化等于结果的变化。**调整关注点，会改变被看见的信息，也会改变随后的选择。开始留意客户体验、身体状态或团队协作后，过去被过滤掉的信号会进入视野，结果便从关注改变的那一刻开始变化。
- **第 21 章　视角是地球上最贵重的商品。**同一项行动放在不同背景中，意义会完全不同。提高视角不是逃离细节，而是重新理解细节服务于什么。能够为当前工作换一个更准确的背景，本身就是高价值的管理能力。
- **第 22 章　多加思考。**效率不会自动发生。许多看似复杂的事务，只需要十几秒钟认真追问预期结果和下一步行动，就能从心理负担变成可执行事项。缺的往往不是时间，而是愿不愿意在前端作出决定。
- **第 23 章　思考有度。**工作需要被想清楚，却不必被无限分析。结果和下一步行动已经明确，提醒也放进可靠位置，就可以停止思考并去做；继续反刍只会让思考取代行动。
- **第 24 章　效率是改善工作的唯一机会。**目标和标准明确以后，越轻松地实现它，越能释放时间、精力和其他资源。提高效率不是为了尽快逃离工作，而是为了把资源留给更有价值的体验和创造。
- **第 25 章　关注一件事才能“全神贯注”。**意识总会落在某处，真正的全神贯注来自同一时刻只需要处理一件事。其他承诺被可靠系统托住以后，工作和休息都可以成为当下最重要的事，不必一边做一边担心别处。
- **第 26 章　未来目标的价值，在于它当前培育的变化。**愿景最直接的价值，不在未来某日兑现，而在它立刻改变今天看见什么、选择什么、拒绝什么。行动与自我提升并不冲突，真正要问的是：此刻哪一种行动最符合想成为的人。

#### 第三部分（第 27～39 章）：建立有效的制约机制

- **第 27 章　稳定带来创造力。**当某个层面失衡，它会不断抽走其他工作的注意力；基本结构稳定以后，创造力才有持续流动的空间。画家整理颜料、钓手收好钓具，并非因为缺乏创造力，而是因为他们重视要完成的事。
- **第 28 章　形式与功能必须符合效率最高的原则。**结构是支持还是限制，取决于它是否服务结果。原书把人的工作状态分成“幻想者”和“实干者”：前者自由产生想法，后者判断下一步并推进。工作篮、项目清单、行动清单和每周回顾，让两种角色可以分时合作。
- **第 29 章　优化系统，放飞思想。**大脑知道行动决定是否可信，也知道清单是否会被重新查看。外部系统只有内容完整、持续更新，才能像可靠的助理一样接管提醒工作；每周回顾是让这种清醒从偶然体验变成稳定状态的关键。
- **第 30 章　反应能力提升生存能力。**竞争优势来自更早看见变化、缩短反应时间，并避免反应不足或反应过激。堆积的邮件和未决事项会像麻醉剂一样降低敏感度；清理积压，则让个人和团队重新接触真实情况。
- **第 31 章　系统的强弱取决于最薄弱的环节。**一个系统必须在疲惫、生病和任务激增时仍然好用，才算真正可靠。团队中长期不回应的一环，也会迫使其他人提高音量、制造虚假紧急。最薄弱的沟通和执行环节决定整体压力。
- **第 32 章　系统的效率与你的感知度成反比。**高效系统平时应当退到背景，像汽车的换挡、温控和通风一样安静运行。若做事时还要不断操心工具、分类和流程，说明系统仍在占用本该用于工作的注意力。
- **第 33 章　功能取决于形式。**环境和结构会持续提示行为。物品放在哪里、清单如何呈现、工作台是否顺手，都会决定一项行动是自然发生还是不断遭到回避。改变行为时，也要检查承载行为的形式。
- **第 34 章　目标明确才能赢得胜利。**游戏必须有可以判断的目标，工作也是如此。没有明确结果，思考和行动之间就会变成沼泽；说清“完成是什么样”，才可能看见差距、决定下一步并判断是否已经结束。
- **第 35 章　多人负责等于无人负责。**讨论可以集体完成，责任却必须落到具体的人。会议结束后，如果没有一个人明确承诺结果或下一步，所有人都可能以为别人会处理，事情便留在组织的缝隙中。
- **第 36 章　确定原则，而不是监管制度。**共同原则说清以后，人可以在边界内自行判断；原则含糊或缺乏信任时，组织才会不断增加规则和检查。清楚的原则减少微观管理，也保留了对变化作出反应的空间。
- **第 37 章　利用大脑来思考工作，而不是单纯关注工作。**大脑擅长发现关系、产生想法和作出判断，不擅长在正确时间提醒所有承诺。把项目与行动放进外部系统，才能让大脑从“记住工作”回到“思考工作”。
- **第 38 章　思考的价值超乎想象。**创造阶段需要允许未经评判的想法大量出现，管理阶段再明确意义并组织结果。把捕捉、判断和整理挤在同一刻，刚冒出的想法会被过早批评；给自由和形式各自的位置，二者才能互相支持。
- **第 39 章　资源越是有限，规划越有必要。**如果时间、金钱和精力无限，很多事情无须计划。限制越真实，越要明确目标、比较路径并决定资源放在哪里。规划正是人用有限条件接近想要结果的方式。

#### 第四部分（第 40～52 章）：放松自我，开始工作

- **第 40 章　对自己做的事情承担起责任。**外界会施加条件，但接受、拒绝、协商和行动仍包含自己的选择。承认这一点不是自责，而是重新取得主动权：对已经接受的承诺负责，也对没有去做的事情负责。
- **第 41 章　过度控制等于失去控制。**球拍握得太紧，动作反而失去灵活。分类、标签、软件和流程只有在服务结果时才有价值；如果整理系统本身变成主要工作，控制就成了回避行动的新形式。
- **第 42 章　进展越好，状态越好。**真实进展会带来能量和信心，使人有能力接受更大的挑战。推进不一定是完成大块工作，也可以是明确一个结果、清掉一个障碍或作出一个拖延已久的决定。
- **第 43 章　相信自己的行动选择，需要多层面的自我管理。**上午 9 点 45 分该做什么，没有一个简单公式可以自动回答。情境、时间、精力、轻重缓急，以及项目、责任、目标和价值观都会参与判断；系统负责呈现可信选项，人负责作出选择。
- **第 44 章　你的力量取决于你的放松能力。**放松不是松懈，而是减少不必要的内在对抗，让力量准确地落在需要之处。运动、沟通和决策都一样：越能卸下无关紧张，越能感知变化并自由回应。
- **第 45 章　预料之内的意外算不上意外。**干扰、延误和计划变化本来就是工作环境的一部分。能消除的提前消除，不能消除的预留空间、设置缓冲并纳入计划；拒绝承认变化，只会让同一件事同时造成事实困难和心理挫败。
- **第 46 章　目光越长远，进展越顺畅。**时间视野越长，可选路径越多，眼前的偏差也越容易校正。只盯最近一步，任何变化都像障碍；看见较远的结果和节奏，便能更从容地调整当前动作。
- **第 47 章　放慢速度以提升速度。**连续行动会让视野变窄，也可能把人带到错误方向。暂停、休息、整理和重新聚焦，为大脑恢复判断力；这段看似没有推进的时间，常常避免了更大的返工。
- **第 48 章　你没有时间做任何项目。**项目是想得到的结果，不能被直接执行。能做的只有打电话、搜索、起草、确认等动作。所谓长期项目同样需要当前行动；如果现在不准备推进，就应诚实地放进“将来／也许”。
- **第 49 章　坚持做好小事，就能产生重大影响。**储蓄、锻炼、沟通和反思的单次效果都很小，长期重复却会改变整个状态。正面变化和负面后果都常由少量、持续发生的行为累积而成。
- **第 50 章　亲力亲为才能了解事物。**知识必须经得起行动检验。开始做以后，真实条件、阻力和方法才会显现。真正采用效率方法的人，通常已经有把事情做得更好的内在动力，因此愿意承认流程和习惯仍可改进。
- **第 51 章　动中求变更容易。**静止时启动最费力，已经行动以后，改变方向反而容易。感觉失控时，先回答想得到什么结果、下一步是什么，哪怕只处理桌面上的一份材料，也能重新回到掌舵位置。
- **第 52 章　最伟大的成功源自最惨重的失败。**火箭靠途中不断修正偏差到达目标，人也只有参加游戏才会犯错。衡量进步，不必要求每次都正确，可以看一段时间内“更佳选择”所占的比例是否提高；一次失手不应成为退出的理由。

### 几条容易被一句话带过的原则

#### 第 4 章：有些东西，你越是抵制越难以摆脱

地图只有在知道当前位置时才有用。要改变工作或生活，先要客观承认现在到底承担了什么、哪些事情尚未完成。拒绝整理完整清单，并不会让这些承诺消失，只会让它们以模糊压力的方式继续存在。

#### 第 7 章：很多人把糟糕的管理与命运混为一谈

项目清单上的事项不一定同样紧急，但都需要被同等认真地判断：是否已经承诺、下一步是什么、何时再看。很多危机并非突然发生，而是在事情还只是“需要处理”时长期无人负责，最后被拖成“必须马上处理”。

轮胎需要更换时，下一步原本只是打电话询价；拖到爆胎以后，下一步就变成了求援。前者是管理，后者看起来才像命运。

#### 第 32 章：系统的效率与你的感知度成反比

如果做事时还要不断操心系统怎么用，注意力就被管理工具占走了。系统安装、调整和升级的目标，是让人尽快不再考虑系统本身，把精力放回工作、思考和创造。

好的系统像汽车的换挡、温控和通风：平时安静运行，只有失效时才会引起注意。

#### 第 36 章：确定原则，而不是监管制度

规则通常出现在原则没有说清楚，或者彼此不信任原则会被遵守的时候。如果团队对目标、边界和不能妥协的标准已经形成共识，成员就可以自行判断和行动；缺少这种共识，只能依靠更多规则和微观管理维持秩序。

#### 第 39 章：资源越有限，规划越有必要

如果时间、金钱和精力无限，很多事情根本不需要管理。正因为资源有限，才必须明确目标、比较取舍，把资源放到真正想得到的结果上。愿景和现实之间的距离越大，越需要规划。

#### 第 41 章：过度控制等于失去控制

网球拍握得太紧，反而会影响击球。工作也是一样：细节只有在服务结果时才值得管理。把大量时间花在分类、标签、软件和流程上，却没有推动任何结果，只是把“组织有序”变成了另一种拖延。

#### 第 45 章：预料之内的意外算不上意外

计划时如果已经承认干扰一定会出现，就可以预留空间并继续推进。拒绝接受现实会变化，只会增加对抗和挫败。能够消除的干扰就消除，不能消除的就把它作为工作的一部分纳入计划。

#### 第 47 章：放慢速度以提升速度

长期只盯着行动层面，视野会越来越窄，精力也会过早耗尽。定期停下来整理、休息和重新集中精神，才能看见目标、方法、进度和资源是否还匹配。放慢不是停止推进，而是避免在错误方向上越跑越快。

#### 第 48 章：你没有时间做任何项目

项目只是想得到的结果，真正能做的只有一个个动作。结清税款、出售公司或准备生日聚会，都不能一步完成，只能通过查询、打电话、起草、确认等行动逐渐实现。

所谓“没有时间做项目”，往往是没有把项目拆到下一步。即使是长期项目，当前通常也能找到一个几分钟内可以启动的动作。

列出行动和项目清单并不只是为了完成工作，然后无所事事。处理自己关注的事情的目的，在于你可以做自己真正喜欢做的事情，集中精力和创造力全身心地投入其中。

每周回顾既要更新已有清单，也要捕捉可能为工作和生活增加价值的新想法。

整套方法最后落在两件事上：

1. 思考目前从事的工作；
2. 为思考的内容采取行动。

### 第五部分：注意基本要素

> **以下“工作流程的 5 个阶段”“自然式计划模式”和“每周回顾指南”，均出自《搞定Ⅱ》第五部分。它们是对 GTD 基本方法的集中核查，不属于前面的 52 章正文。**

### 工作流程的 5 个阶段

这是实现**横向控制**的操作指南——怎样掌握、认识并处理好自己的全部任务。第 2 阶段和第 3 阶段将在“处理与组织整理流程图”中得到进一步说明。在真正成为习惯之前，“处理与组织整理流程图”是你案头非常有效的一种工具。

#### 1. 收集

- 捕获吸引注意力的一切外部事务（工作篮、电子邮件、笔记本、语音邮件等），并将其从大脑的短期记忆中清空。
- 根据需要尽量减少收集工具的数量。
- 通过处理和组织整理（参考下文）定期清空收集工具。

#### 2. 处理

- 处理收集到的项目（决定如何处理收集到的材料）。
- 如果**不需要**采取行动，可以抛开，也可以“存入备忘录”留待日后处理，或者将其归档备查。
- 如果**需要**采取行动，那就确定随后采取的具体行动，要么亲自处理（如果两分钟内可以完成），要么委托他人，要么延迟处理。

#### 3. 组织整理

把收集到的输入信息结果分成恰当的可检索、可检查的类别。4 种主要的行动类别分别是：

- **项目**——决定实施的项目
- **日程表**——具体某一天或某个时刻需要采取的行动
- **下一步行动**——需要尽早采取的行动
- **等待**——其他人承担的项目和采取的行动，但你要加以关注

在此之上：

- 增加有利于工作的次级类别清单（例如“电话”清单、“杂事”清单、“家”清单、“电脑”清单等）。
- 添加对你有影响的长远目标和价值清单。
- 添加需要时可能有用的核查清单（工作职责、“引子”清单、组织结构图等）。
- 针对无须采取行动但需要能检索的信息和材料，建立一般性参考资料归档系统。
- 针对以后可能采取行动的“引子”，建立一种存储系统（“将来／也许”清单、日程表、备忘录）。
- 必要时，为项目建立辅助信息文件。

#### 4. 回顾

- 每天查看日程表和“下一步行动”清单，确保当下的选择有据可依。
- 每周对整个系统做一次完整回顾，让所有清单重新变得可信（详见下文“每周回顾指南”）。
- 定期从更高层面检视目标、责任范围与长远方向。

#### 5. 执行

- 用情境、时间、精力、重要性这四个标准，决定此刻做什么。
- 在事先安排好的工作、突发事件、安排自己的工作这三类之间做出取舍。
- 相信系统给出的选项，然后专注地做那一件事。

### 自然式计划模式

这一模式是参照大脑自然计划各项事务的模式建立起来的。它提供的是**纵向控制**，例如考虑单个具体项目或情境的最有效方式。明确所有项目之后，要轻松自然地加以驾驭，每个项目可能都需要你在一个或多个层面投入更多关注。

#### 1. 目的／指导原则

- 为什么要做这件事？“有目的”究竟是什么意思？
- 为项目做出决策、采取行动时，我们应该遵循哪些关键标准？遵守哪些规则？
- 目的和原则是项目决策的指导性标准。

#### 2. 使命／愿景／目标／成功的结果

- 如果事情大获成功，将会是什么情况？我怎么知道这种情况？
- 利益相关方会如何看待和感受那种成功呢？

#### 3. 头脑风暴

- 关于这件事情，我有哪些想法？现实情况如何？
- 先把所有念头倒出来，不做评判、不分优劣，数量优先于质量。

#### 4. 组织整理

- 从倒出来的想法中辨认出关键的组成部分、先后顺序和轻重缓急。
- 该分层的分层，该排序的排序，让结构自己浮现出来。

#### 5. 明确下一步的行动方案

- 这个项目当前能推进的具体物理动作是什么？
- 由谁在什么情境下完成？把它放进对应的清单。

> 如果你已经把项目从头脑中抛开，那说明计划很充分。如果项目还在你头脑中萦绕，那就坚持继续使用这种模式，直到项目变得明朗。

### 每周回顾指南

第一项挑战是按照这些模式开展工作，第二项挑战则是让这些模式充满活力、始终发挥作用。本指南将为你实现更轻松、更富效力、持续始终的生活及工作方式提供一把万能钥匙。这个流程如果发挥作用，将有助于提升管理指挥中心的思考能力和信心。**如果能做到每隔 7 天运作一次，它将发挥出最大的效力。**

##### 散落的纸片

- 搜罗各种零碎纸片、名片、收据和各类文件，放进工作篮等候处理。

##### 整理笔记

- 回顾一下日志／笔记本上的记录、会议记录和笔记本活页纸上潦草写下的各种笔记，分门别类地记录任务、项目、待处理事项等。

##### 清空大脑

- （按照合适的类别）写下还没有掌握的所有新项目、任务、待处理事项、将来／也许会处理的事项等。

##### 回顾“行动”清单

- 标出完成的行动，查看将要执行的行动的提示信息。

##### 回顾“等待”清单

- 记录为后续措施采取的适当行动，检查标出最近收到的反馈。

##### 回顾“项目（及更重大的结果）”清单

- 依次评估项目、目标和结果的当前情况，确保对每一项都采取了行动。浏览工作进度辅助材料，构想新的行动、要完成的任务和待处理工作等。

##### 回顾以往的日程表

- 仔细查看以往的日程表，搜寻未完成的工作、有用的参考数据等，将其纳入当前系统中。

##### 回顾将来的日程表

- 浏览一下将来的日程安排——包括长期和短期安排，记住需要采取的行动。

##### 回顾相关的核查清单

- 以此作为采取新行动的引子。

##### 回顾“将来／也许”清单

- 查看一下哪些项目现在或许可以开展了，将其转移到项目清单上。

## 《搞定Ⅰ：无压工作的艺术》全书提炼

- URL: https://blog.no-claw.com/b3483798/

> **版本说明**：这是对照原书补齐的独立提炼版。[查看线上原稿](/723111cd/) · [查看三部曲合集](/6220a80a/) · [查看实践清单手册](/f009420a/)

> **提炼范围**：戴维·艾伦《搞定Ⅰ：无压工作的艺术（最新版）》。正文按原书三部分展开；原书中解释原理、因果和适用方式的内容按原意润色保留，关键句继续以引文标出。

《搞定Ⅰ》负责把 GTD 的整套方法搭起来：先用横向流程管理全部事务，再用纵向方法推进单个项目，最后把这些动作变成稳定习惯。

### 第一部分：搞定——通向从容之道

#### 第 1 章：新情况，新做法

本书中的这套方法，完全基于三个主要目的：

1. 收集所有需要处理或者对你有用的事情（现在的、以后的、某一时间的；大的、小的、不大不小的），把它们统统置入一个脱离大脑意识的、条理分明的、可靠的系统中；
2. 指导自己在获取任何“输入信息”（也就是接手任何任务）的前期就进行分析和决策，以确保随时拥有一套可以执行或重新协调的“下一步行动”可行清单；
3. 管理、协调所有相关内容，履行你在任何时间点对自己和他人做出的各种承诺。

> 只要有足够的信息，几乎每件事情都可以做得更好。而在当今的世界，你可以获取的信息是无穷无尽的。
>
> 你发挥能量的能力与你的放松能力成正比。
>
> 如果你的大脑空空如也，总是处于一切就绪的状态，那么它就会向一切事情敞开大门。
>
> 行动源于思考。

知识工作没有清楚的完成线。方案可以继续改，资料可以继续找，责任也会不断变化，而能够获取的信息几乎没有上限。传统时间管理缺少一套能在真实工作中持续运转的系统。

这套系统必须同时满足几个条件：

- 从大局着眼，也能从具体行动入手，并把两者连接起来；
- 能管理行动、项目、责任、目标和愿景等多个层面；
- 能持续接住每天出现的新事务，避免遗漏；
- 容易维护，整理系统本身不能消耗过多时间和精力；
- 把复杂事务转成可以判断、可以追踪的结果和行动。

##### 管理承诺时的基本要求

**第一**，只要一件未完成的事仍由大脑负责提醒，它就会反复占用注意力。所有未完成的承诺都要进入一个客观、可靠、会被定期查看和清理的外部系统。

**第二**，仅仅知道“有这件事”还不够。每项承诺都要明确工作究竟是什么、想得到什么结果，以及需要采取什么行动来推动它。

**第三**，作出决定以后，结果和行动的提示必须放进一个会被反复查阅的系统。否则，大脑仍会继续承担记忆和提醒工作。

##### 为什么有些事情总是萦绕在你的心头

- 还没有明确认定预期结果是什么；
- 还没有确定下一步要采取的具体行动；
- 结果和行动的提示还没有进入一个真正信任、还会回来查看的系统。

> 我们需要把收集和积累的所有“材料”都转化成包含重要行动、项目和有用信息的明确清单。

收集到的“材料”不能一直保持原样，它们要被转成项目、行动和有用信息。就推进工作而言，最终需要看清两类内容：

1. **想要得到的结果**；
2. **推动结果的行动**。

##### 对行动的横向管理和纵向管理

**横向控制**把工作和生活中所有正在关注的行动纳入同一个系统，保证没有事务被遗忘，并能在合适的情境中看到可执行选项。

**纵向控制**针对某个具体主题或项目继续向下思考，协调目的、结果、想法、计划和下一步，并持续跟踪进展。

> 任何仅存在于内心的“将会、可能或应该”性质的承诺，都会造成非理性和无法排解的全天候压力。
>
> 对一件事情不需要进行两次相同的思考，除非你喜欢重复思考。

#### 第 2 章：横向管理工作流程的 5 个步骤

1. 收集引起注意的事务和信息；
2. 理清每个项目的意义和相关措施；
3. 组织整理结果，提出选项；
4. 进行思考回顾；
5. 选择行动。

这五步构成横向管理系统。新的事务可以随时进入，但每一项都要经过同样的判断，不能只收集、不处理，也不能把尚未明确的材料直接塞进待办清单。

> 问问你自己：“我需要以何种方式在何时将想法付诸行动？”你建立管理系统是为了让它发挥作用，而不是单纯为了拥有它。

##### 收集

所有等待处理、需要改进或者持续吸引注意的未竟之事，不分大小、轻重和缓急，都先收集起来。收集的目的不是立刻完成，而是停止让大脑同时保存和处理这些内容。

> 悬而未决的事务存在两个地方，即任务所处的实际位置和你的大脑。

1. 把一切赶出你的大脑
2. 尽量减少收集工具的数量
3. 定期清空收集工具

> 出错好过模棱两可。

##### 理清：立即执行、指派他人，或者延迟处理

一旦你决定了下一步行动，紧接着，你就会面临以下三种选择：

1. **立即执行**——如果行动能在两分钟内完成，那么你就应该立刻执行。
2. **指派他人**——如果处理这件事情需要花费的时间不止两分钟，那么，你应该问一问自己是不是解决这个问题的最佳人选。如果回答是否定的，那就委托给一个合适的人员去办理。
3. **延迟处理**——如果预计花费的时间超过两分钟，而你又恰恰是最佳人选，那么这时，你就不得不推迟行动，把它记录在“下一步行动”清单上，等以后再来完成。

##### 组织整理

**项目清单的内容范例：**如果某项工作不能一步完成的话，那么，你就需要建立某种机制来提醒自己还有事情尚未处理。

**项目的辅助性资料：**一旦你把项目的辅助性资料按照主题或者题目分类组织整理时，拥有一个运行良好的参考文件归档系统。

**下一步行动的归类——日程表：**

- 需要在指定时间执行的行动
- 需要在指定日期执行的行动
- 需要在指定日期获取的信息
- 不再需要“每日工作清单”

**比较典型的“将来／也许”清单（备忘录）：**是你不愿意去做的事情，或者需要在未来某个指定时间之前持续收到提醒的事情。

**参考资料：**

1. 按特定主题或特定领域分类存储的系统
2. 一般性参考资料归档系统

需要每隔一段时间，全面回顾自己的总体生活和工作情况，并对拟采取的具体行动进行详细检查。

##### 回顾的内容和时机

成功的关键因素：**每周回顾**。

所有悬而未决的事务——“项目”清单（包括现行项目规划）、“下一步行动”、“议事日程”、“等待处理”，甚至“将来／也许”清单，都应该每周回顾一次。

事务都经过了收集、处理、组织整理和回顾这几大步骤。

需要回答的问题：

- 回顾应该要关注哪部分的内容？安排在何时进行？
- 回顾应该怎样进行？每隔多久进行一次才能确保整个系统持续运转，并解放你的大脑，使之能够从事更高层次的思考和组织整理活动？

##### 确定某一时刻具体行动的“四标准法”

1. **情境**——大多数事情都只能在特定的地点完成（在家或办公室）
2. **有多少时间**
3. **有多少精力**
4. **重要性**（ROI）

> 事情总是多得做不完，你可以每次只做一件事。无论是否已经采取行动，关键在于使自己保持良好的状态。

##### 确认每日工作的“三分类法”

- 执行事先安排好的工作
- 处理突发事件
- 安排自己的工作

##### 总体检视工作的“六层次法”

- **5 楼视野**：目的和原则
- **4 楼视野**：愿景
- **3 楼视野**：目标
- **2 楼视野**：关注点及责任范围
- **1 楼视野**：当前项目
- **跑道视野**：当前可以执行的下一步行动

#### 第 3 章：纵向管理项目的 5 个阶段

**自然计划模式**——自然计划法不一定就是常规做法：

1. 定义目标和原则
2. 展望结果
3. 头脑风暴／集思广益
4. 组织整理
5. 明确下一步的行动方案

> 当你发现自己身陷一个黑洞时，就应该立刻停手，绝不要再继续挖了。
>
> 不要仅仅忙着做事情，而是要站在旁边静静想一想。

##### 组织整理的基本要点

组织整理的关键步骤如下：

- 明确事件的重要组成部分
- 整理分类（按照下面一个或多个标准）
  - 构成因素
  - 先后顺序
  - 重要程度
- 足够详细的描述

> 任何人都不可能多任务并行，都是一次只能做一件事。

在现实生活中，干扰和打断原本就是难以避免的。当你能够熟练地、快速地分析处理突发事件，并学会利用各种零碎时间来完成行动的时候，你就可以在不同的任务之间敏捷地切换了。这种切换的过程务必要保证整个管理系统的平衡。研究已经证明，你无法真正做到多重任务化，也就是说，你无法在同一时间有意识地专注于一件以上事情；如果你试图那么做，它会显著削弱你的执行能力。

> 你要做的是发现你的世界，然后全身心地投入其中。
>
> 采用这种自下而上的工作方式的首要原因就是，这种方式能够让你清除内心的烦扰、释放受困的心灵，让你有精力去关注那些更有意义、更重要的方面。
>
> 处理你的关注事项，然后你会发现真正吸引你的东西。
>
> 让我们把超前的焦虑变成超前的思考和规划。

关键在于你要学会思考，运用思考的结果进行合理的管理。要培养一个好习惯：在考虑问题的时候高度集中精力，有预见性地发现问题、解决问题，而不是等到迫不得已时才行动。

### 第二部分：远离压力，提高效率

#### 第 4 章：准备工作——确定时间、空间和工具

完整启动一次 GTD，需要一段不受打扰的时间、一个可以集中处理材料的工作区，以及一套足够简单的工具。基本配置包括工作篮、纸笔、日程表、行动清单、文件夹和参考资料归档系统。

工具的作用是降低捕捉和归档的阻力。数量太多、入口太散、查找太慢，都会让大脑重新承担提醒工作。

#### 第 5 章：收集阶段——归拢材料

收集分成两部分：

1. **外部收集**：把桌面、抽屉、文件柜、背包和其他空间里尚未处理的材料集中到工作篮；
2. **内部收集**：通过“大脑清扫”写下所有引起注意的承诺、担忧、想法和可能性。

这一阶段只负责收齐，不急着分类和决定优先级。明显的垃圾、确定需要归档的资料和两分钟内可以顺手完成的小事可以直接处理，其余内容先进入统一入口。

#### 第 6 章：理清阶段——清空工作篮

从工作篮最上面一项开始，一次只处理一件，不把拿出来的材料原样放回去。判断顺序是：

1. 这是什么？
2. 需要行动吗？
3. 想得到什么结果？
4. 下一步行动是什么？

不需要行动的内容进入垃圾、参考资料或“将来／也许”。需要行动的内容按两分钟法则、委派或延迟三种方式处理；需要多个步骤才能完成的结果同时进入项目清单。

#### 第 7 章：组织整理——建立好清单

理清后的结果进入不同容器：

- **项目清单**：需要多个行动才能完成的结果；
- **日程表**：必须在指定日期或时间发生的行动和信息；
- **下一步行动清单**：可以尽快执行的具体动作；
- **等待清单**：已经交给别人、仍需追踪的事项；
- **将来／也许**：尚未承诺，但以后可能启动的内容；
- **参考资料**：不需要行动、以后可能查阅的信息。

日程表只保存真正受日期约束的“硬质景观”。普通任务如果都塞进日程表，反复延期后，日程表本身也会失去可信度。

#### 第 8 章：回顾阶段——保障系统的有效运行

日常回顾先看日程表，再看当前情境下的行动清单。每周还要做一次完整回顾：

- 收集散落材料，清空工作篮和记录；
- 检查过去和未来的日程；
- 更新行动、等待和项目清单；
- 查看“将来／也许”和相关核查清单；
- 补充回顾过程中出现的新想法。

回顾的目的，是让系统重新和现实同步。只有相信清单完整、内容最新，大脑才会停止反复提醒。

#### 第 9 章：执行阶段——选择最合适的行动

面对多项可执行行动时，依次考虑四个条件：当前情境、可用时间、可用精力和重要性。

每天的工作又分成三类：

1. 执行已经安排好的工作；
2. 处理突然出现的工作；
3. 重新整理和明确自己的工作。

第三类工作不会直接推进某个项目，却决定系统能否继续提供可靠选择。

#### 第 10 章：学会控制项目

项目不能被直接执行，能执行的只有下一步行动。每个活跃项目至少要有一个可以继续推进的动作，并在每周回顾中确认它是否仍然有效。

复杂项目可以保留计划、资料和头脑风暴结果，但项目辅助资料不能代替项目清单和行动提示。自然计划法负责思考项目，项目清单负责提醒结果，行动清单负责推动现实进展。

### 第三部分：三个关键原则

#### 第 11 章：原则一——养成收集的习惯

压力并不只由事情的数量造成，也来自对结果的标准和已经做出的承诺。最直接的减压办法当然是降低要求：如果不再关心子女教育、团队状态、教学制度或代码质量，相应的关注事项会立刻减少。但只要仍然在意这些结果，就需要承认它们已经构成了承诺，并把它们纳入系统。

消极情绪往往不是来自工作本身，而是来自没有履行自己答应过的事。处理承诺只有三种办法：

1. 一开始就不作出承诺；
2. 完成承诺；
3. 重新商定承诺。

第三种办法要求先把承诺找出来。一个只存在于脑中的模糊协议，既无法完成，也无法重新商定。完整收集还有一个直接作用：看清已经承担的全部工作以后，才有依据拒绝新的任务。

在团队里，收集和兑现承诺同样决定信任。成员知道任务会被记录、追踪和重新协商，沟通就不必依赖反复催促。

#### 第 12 章：原则二——确定“下一步行动”

> 如果你不知道具体的下一步行动，那么在现实和目标之间就留下了一个潜在的、巨大的断层。

越聪明、越敏感、越有想象力的人，通常也越容易看到问题、机会和未完成的可能性，因此清单上的未解决事项往往更多。人的神经系统不会严格区分眼前真实发生的事和头脑中反复想象的事；一个含糊的结果，只要不断被想起，身体就可能持续对它作出压力反应。

想象力本身不是问题。问题在于，这些想法没有被转成清楚的结果和行动，于是大脑只能一遍遍重新提醒。

> 越是才智过人的人，越敏感，也越容易被自己的想象所感染。

“下一步行动是什么”把抽象事项变成可以观察的现实动作，也会暴露责任是否明确。会议中的“推进一下”“继续跟进”都不是行动；只有说清由谁打电话、查询、起草或确认，决定才真正进入执行阶段。

下一步行动不一定完成项目，它只需要消除当前的不确定性。对复杂事项来说，第一步甚至可以只是“查明有哪些选择”或“约某人讨论”。

#### 第 13 章：原则三——学会关注结果

只确定行动还不够。下一步行动解决从哪里开始，预期结果决定往哪里走。两者必须同时存在：只有动作会陷入琐事，只有愿景会停在想象里。

书中把工作和生活中卡住的情形压缩成两类：

1. 已经知道目标，但不知道如何达成；
2. 还不知道目标到底是什么。

对应的解决方向也是两个：还不知道目标时，先定义想要的结果；已经知道目标却不知如何推进时，确定下一步行动。

当“预想结果”和“确定下一步行动”变成日常习惯，问题会更快从模糊压力转化为可以处理的结果和动作。人会持续经历同一个循环：发现问题、定义结果、找到行动、完成结果，再发现新的问题和目标。书中所说的效率提升，来自这个循环越来越自然，而不是把清单一次性清空。

> 人生的最大乐趣莫过于克服困难、坚定脚步，目睹自己将目标一一实现。
>
> 你的大脑是用来获得想法的，而不是用来保存想法。

#### 第 14 章：GTD 和认知科学

新版增加这一章，是为了说明 GTD 的效果不只来自经验。书中对应了几组认知研究：

- **分布式认知**：日程表、清单和参考系统构成“外脑”，让大脑把资源用于判断和创造；
- **未解决事项的认知负荷**：没有可信计划的未完成事项会反复侵入注意力，明确结果和行动后，干扰会减弱；
- **执行意向**：提前决定在什么情境采取什么行动，更容易把意图转成行为；
- **自我领导和心理资本**：持续兑现、拒绝或重新商定承诺，会提高掌控感和信心；
- **沉浸状态**：目标清楚、反馈及时、对下一步有把握时，更容易进入专注状态。

##### 沉浸理论

沉浸通常伴随对特定任务的全身心关注，而且你通常会有掌控感，感到目标清晰。处于沉浸状态的个人通常明白接下来会发生什么事情，并能在执行整个任务的过程中得到及时反馈。他们还能体验到行动和意识的融合，并在此过程中丧失其自我意识和时间感。

#### 第 15 章：GTD 精进之路

书中把熟练程度分成三个层次：

1. 采用最基本的工作流程管理；
2. 执行一个较为高级和综合的全方位生活管理系统；
3. 利用技能创造明确的空间，完成任务，并且使你的表现越来越得体。

第一个层次建立工作篮、行动、等待、日程和每周回顾。第二个层次以完整项目清单和责任范围管理整个生活。第三个层次把释放出来的注意力用于方向、创造力和更有意义的选择。

一个明显的分界点是：压力增加时，是放弃系统，还是更主动地使用系统。真正熟练以后，新问题会触发收集、明确和重新校准，而不是把所有事情重新塞回脑中。

##### 日常实践清单

- 基于“待执行事项”决定下一步行动
- 充分利用“等待”类型清单，以便能在适当的时机保存他人交付的预期可交付项目，并审查其后续状况
- 利用“日程”清单收集与他人的沟通信息，并加以管理
- 维护一个简单、易于访问的归档和参考系统
- 将日历表作为纯粹的“硬质景观”加以保存，不要让不相干的新事务破坏其可信度
- 进行“每周回顾”，以保证某个系统的功能正常化，且持续更新

##### 成熟系统的标志

- 一个完整、最新、清晰的项目清单
- 一张角色、职责、兴趣（个人和职业）的地图
- 一个集成化的全面生活管理系统，这个系统是基于某人的当前需求和发展方向定制的，用于动态监控日常工作以外的行为
- 面临的挑战和意外状况将驱使你采用（而不是弃用）这个方法

##### 落地动作

- 建立起用于个人组织整理的设施
- 安排整理你的工作区
- 准备几个工作篮
- 创建一个可行和易于访问的个人参考系统（工作和家用）
- 准备一个好用的计划手册，上面应该有完整的管理项目的清单
- 允许自己做出旨在改善工作环境的任何改变。挂图片，买钢笔，扔东西，重新安排你的工作区。为你重新启程提供支持
- 预留出一些时间，让你可以整理办公室中某一个完整的区域，然后是家中的各个角落。把收集到的一切纳入你的系统当中，并采用本书介绍的方法进行处理
- 同别人分享你从书中获得的知识、你的实践经验以及感受（这是最快的学习方法）
- 3～6 个月后，再回顾本书的内容

#### 帕雷托原则

> 帕雷托原则，也可称为二八法则，由意大利经济学家帕雷托提出，意思是让20%的投入产生80%的效益

我们在每天的工作中，总会有精力充沛的时候，也会有大脑疲劳不堪的时候。因此我们要把握一天中精力最充沛的时间去集中精力做重要的事情。在疲惫时，我们则可以停下重要的工作，去做一些琐碎的事情，比如处理邮件等。

#### “吃青蛙”定律

>   “吃青蛙”定律来自博恩·崔西的《吃掉那只青蛙》。

“青蛙”是指最艰巨、最重要的任务。坚持三个原则：

1. 每天早上做最难的那件事，那么，一天之内就没有比这更糟糕的事情了；

2. 面对两件重要的事，要优先做更重要的那一件；

3. 对于重要的事，要立即行动，说做就做，否则考虑得再周全而不行动也无济于事。

**时间管理小贴士**

| 1.拒绝拖延症                     | 2.赢得时间                                                   |

| 抑制完美主义                     | 学会授权，对于烦琐的服务性工作可以借助他人之手（授权外包）   |

##### 制定周计划

1. 任务清单，明确如下：

● 具体的任务：要做什么？

● 任务的产出：如何判断完成了任务？

● 任务的完成时间：什么时候完成？

2. 在制定任务清单注意要点：

● 每个任务，完成的时间不超过1天。

● 每个任务，都应有完成标志。

● 任务的完成信息，能够共享和同步。

3. 制作周计划任务可视化看板。可视化看板包含三要素：

● To Do：本周计划要完成的任务项。

● Doing：今天将要做的任务项。

● Done：本周已经完成的任务项。

##### 深度工作

>  每次深度工作可以设定在45分钟到1.5小时之间。

> 根据注意力恢复理论，我们的注意力是有限的，只能在一段有限的时间内专注于一项任务，直到它变得让人筋疲力尽。

至于一项任务是否属于深度工作，可以参考以下问题：

● 该任务是否需要集中注意力？

● 任务需要有专门的知识技能吗？

● 任务很难重复吗？

● 该任务会创造新的价值吗？

保持不间断的专注，你需要创造一个无干扰的环境。这意味着要屏蔽无关的和破坏性的打扰——聊天信息、电子邮件、会议、电话、社交媒体及其他杂音。非常需要注意的一点是，要与你的团队和上级达成一致：允许你不及时回复消息。

由于这个原因，许多人强制执行严格的“隔离措施”：

● 将手机设置为“免打扰”模式；

● 将邮箱设置为自动回复消息；

● 将“深度工作”时间分享给同事。

每周回顾：花时间反思过去一周进展顺利和失败的原因，并计划下一周的工作。

>  这是检视目标，并确保自己每天所做的工作能够帮助自己实现目标的机会

在回顾的时候，我们可以参考以下问题清单：

● 我本周总体感觉如何？

● 是什么让我在本周达到目标？

● 有什么事情阻止我本周实现目标？

● 我本周采取了哪些行动来推动我实现长期目标？

● 下周我该如何改善？

● 下周我该怎么办，以使我实现长期目标？

> 营造环境、明确目标、深度工作和每周回顾，这是使在家工作更高效的四步法。
>
> 但是，至关重要的是：寻找初心。
>
> 初心，是指自己感兴趣的事，能发挥自己优势的事，可以实现自己价值的事。
>
>  拥有初心，你就具备最大能量，就会取得更多成果。”

## 关键20小时

- URL: https://blog.no-claw.com/614ff5d2/
- 日期: 2021-01-22
- 分类: 读书有感
- 标签: 效率

#### 快速学习

●分解步骤——把技能做最大程度的细分，分成若干小步骤。

●充分学习——对每个小步骤进行充分学习，以便进行灵活的练
习，并在练习中自我纠正。

●克服困难——克服在练习中出现的生理、心理或者情绪上的障
碍。

●集中练习——至少用20小时集中学习最重要的小步骤。

#### 技能习得

##### 1.早期认知。

了解你即将学习的技能是什么，探索研究，想想整
个过程，把技能细分为几个可以控制的小步骤。

##### 2.中期联想。

训练、注意环境反馈，根据反馈调整方法。

##### 3.后期自主训练。

不用怎么有意识地注意方法步骤就可以很自如地开展技能训练

#### 速习得技能的10个方法

##### 1.选择方向；

如果你优先学习你感兴趣的事，那么你肯定花不了多少时间就能学成。

##### 2.集中精力；

“集中精力，只学一门”对快速习得技能的重要性是不言而喻的。
当然，这并不意味着你把其他技能拒之门外，只是你暂时将之搁
置，等待未来重拾。

##### 3.制定目标；

你的目标制定得越轻松，掌握相关技能的速度就越快。快速习得技能的目的并不是要尽善尽美，成为世界级大师，而是要在兼顾能力和效率的同时，快速提高
技能。

##### 4.分解技能；

我们学习的大部分技能都需要细化步骤。当定下想学习的技能后，就该把这项技能细化为若干步骤。学会对步骤进行筛选。把关键的步骤先找出来，再集中时间和精力去学习。

##### 5.获得工具；

对于某些技能而言，只有获得了必备工具，我们才可能最大限度地利用时间充分学习。

##### 6.扫除障碍；

●训练前的准备工作。例如，训练前找不到工具放哪儿了；训练前
还没有选到合适的工具；忽略训练的必要条件。
●使用临时训练工具。例如，借别人的装备，也就是说，你使用的
器材是有时间限制的，随时会被要求归还。
●环境干扰。例如，开着的电视；突然响起的电话；刚刚收到的电
子邮件。
●情绪障碍。例如，害怕；怀疑；害羞。

##### 7.腾出时间；

腾出时间,建议你下决心保证20小时的训练量。一旦训练开始，就别停下来。如果中途卡住了，一定要坚持住，直到达到20小时这个初级训练目标。如果你没有毅力投入20小时，那么请你放弃。

##### 8.及时反馈；

快速反馈有助于快速习得技能。如果反馈及时或只有一点点延迟，我们会更容易把实际操作情况和目前所获得的结果联系起来加以分析，再做出适当的调整

##### 9.计时训练；

初学一门新技能时，往往容易过分估计实际投入训练的时间。特别是当你状态不佳时，你会发现训练时间过得像蜗牛爬一样，慢慢吞吞。事实上，你实际训练的时间远没有自我感觉的时间那么长。你只需遵守一个规则：一旦计时开始，中途一定不能停下来。记住：在你练得有点泄气时，这个方法会让你更加轻松地完成更为持久的训练。
持续训练的时间越长，技能习得就越快。每天腾出时间做3~5次这样的分段计时训练，短时间内就会看到明显步。

##### 10.数量速度。

刚开始习得新技能时，人们往往希望做得尽善尽美，但力求完美很容易让人产生挫败感。因为我们永远都不可能做到百分之百的完美。别去设想有完美的表现，保持良好状态的同时，保证训练量和训练速度才是最应该考虑的。练就一门技能必须用心，必须坚持。刚开始学习时，不要盲目追求质量，相反，必要的训练量和训练速度才是制胜法宝。练得多，练得快，才能学得快。

## 搞定

- URL: https://blog.no-claw.com/723111cd/
- 日期: 2021-01-22
- 分类: 读书有感
- 标签: 效率, 搞定三部曲

### Part 1

#### CH1 新情况，新做法

本书中的这套方法，完全基于三个主要目的：

1. 收集所有需要处理或者对你有用的事情（现在的、以后的、某一时间的；大的、小的、不大不小的），把它们统统置入一个脱离大脑意识的、条理分明的、可靠的系统中；
2. 指导自己在获取任何“输入信息”（也就是接手任何任务）的前期就进行分析和决策，以确保随时拥有一套可以执行或重新协调的“下一步行动”可行清单；
3. 管理、协调所有相关内容，履行你在任何时间点对自己和他人做出的各种承诺。

> 只要有足够的信息，几乎每件事情都可以做得更好。而在当今的世界，你可以获取的信息是无穷无尽的。
>
> 你发挥能量的能力与你的放松能力成正比。
>
> 如果你的大脑空空如也，总是处于一切就绪的状态，那么它就会向一切事情敞开大门。
>
> 行动源于思考。

长期以来，在“知识工作”的新文化中存在着一种缺陷：缺少一套连贯一致并能够在实实在在的工作中发挥卓越功效的系统和工具。这套系统必须能够从大局着眼，从小处入手，并且使二者有机地融合在一起；必须能够管理多个层面；必须能够坚持不懈地对每天衍生的众多新生事物进行控制；必须易于维护，能节省更多的时间和精力；必须化繁为简。

##### 管理承诺时的基本要求

**第一**，如果这件事总占据着你的头脑，你的思维就会受阻。任何一件你认为还没有完成的事情，都必须被置于一个客观、可靠的体系中，或者是我称为“文件夹”的工具之中——必须经常回访并予以清理。

**第二**，在明白你的工作到底是什么后，你还必须做出判断：需要采取什么行动来推动工作进程。

**第三**，一旦决定了需要采取的行动方案，你必须在某一个你会经常查阅的系统中保存好与这些行动相关的提示信息。

##### 为什么有些事情总是萦绕在你的心头

- 你还没有明确地认定它们的预期结果是什么。
- 你还没有确定你下一步的具体行动到底是什么。
- 你还没有把关于预期结果和即将采取行动的提示信息存入你所依赖的系统中去。

> 我们需要把收集和积累的所有“材料”都转化成包含重要行动、项目和有用信息的明确清单。

清除大脑中的全部事务。搞定事项分为两类：

1. **已做好**（结果）
2. **正在做**（行动）

##### 对行动的横向管理和纵向管理

**横向控制**是把你涉及的所有行动都管理起来，保证毫无遗漏地加以执行。

**纵向控制**则是对每个具体主题或项目进行思考和协调，并跟踪其进展情况。

> 任何仅存在于内心的“将会、可能或应该”性质的承诺，都会造成非理性和无法排解的全天候压力。
>
> 对一件事情不需要进行两次相同的思考，除非你喜欢重复思考。

#### CH2 横向管理工作流程的 5 个步骤

1. 收集引起我们注意的事务和信息；
2. 理清每个项目的意义和相关措施；
3. 组织整理结果，提出选项；
4. 进行思考回顾；
5. 选择行动。

这些阶段共同构成了我们生活中的横向管理系统，而且我们还可以随时向其中添加需要考虑的新事项。

> 问问你自己：“我需要以何种方式在何时将想法付诸行动？”你建立管理系统是为了让它发挥作用，而不是单纯为了拥有它。

##### 收集

你需要寻找和收集你的一切未竟之事，无论大小、轻重、缓急，只要是那些等待处理的、需要改进的、引起注意的事务，都要收集起来。

> 悬而未决的事务存在两个地方，即任务所处的实际位置和你的大脑。

1. 把一切赶出你的大脑
2. 尽量减少收集工具的数量
3. 定期清空收集工具

> 出错好过模棱两可。

##### 理清：立即执行、指派他人，或者延迟处理

一旦你决定了下一步行动，紧接着，你就会面临以下三种选择：

1. **立即执行**——如果行动能在两分钟内完成，那么你就应该立刻执行。
2. **指派他人**——如果处理这件事情需要花费的时间不止两分钟，那么，你应该问一问自己是不是解决这个问题的最佳人选。如果回答是否定的，那就委托给一个合适的人员去办理。
3. **延迟处理**——如果预计花费的时间超过两分钟，而你又恰恰是最佳人选，那么这时，你就不得不推迟行动，把它记录在“下一步行动”清单上，等以后再来完成。

##### 组织整理

**项目清单的内容范例：**如果某项工作不能一步完成的话，那么，你就需要建立某种机制来提醒自己还有事情尚未处理。

**项目的辅助性资料：**一旦你把项目的辅助性资料按照主题或者题目分类组织整理时，拥有一个运行良好的参考文件归档系统。

**下一步行动的归类——日程表：**

- 需要在指定时间执行的行动
- 需要在指定日期执行的行动
- 需要在指定日期获取的信息
- 不再需要“每日工作清单”

**比较典型的“将来／也许”清单（备忘录）：**是你不愿意去做的事情，或者需要在未来某个指定时间之前持续收到提醒的事情。

**参考资料：**

1. 按特定主题或特定领域分类存储的系统
2. 一般性参考资料归档系统

需要每隔一段时间，全面回顾自己的总体生活和工作情况，并对拟采取的具体行动进行详细检查。

##### 回顾的内容和时机

成功的关键因素：**每周回顾**。

所有悬而未决的事务——“项目”清单（包括现行项目规划）、“下一步行动”、“议事日程”、“等待处理”，甚至“将来／也许”清单，都应该每周回顾一次。

事务都经过了收集、处理、组织整理和回顾这几大步骤。

需要回答的问题：

- 回顾应该要关注哪部分的内容？安排在何时进行？
- 回顾应该怎样进行？每隔多久进行一次才能确保整个系统持续运转，并解放你的大脑，使之能够从事更高层次的思考和组织整理活动？

##### 确定某一时刻具体行动的“四标准法”

1. **情境**——大多数事情都只能在特定的地点完成（在家或办公室）
2. **有多少时间**
3. **有多少精力**
4. **重要性**（ROI）

> 事情总是多得做不完，你可以每次只做一件事。无论是否已经采取行动，关键在于使自己保持良好的状态。

##### 确认每日工作的“三分类法”

- 执行事先安排好的工作
- 处理突发事件
- 安排自己的工作

##### 总体检视工作的“六层次法”

- **5 楼视野**：目的和原则
- **4 楼视野**：愿景
- **3 楼视野**：目标
- **2 楼视野**：关注点及责任范围
- **1 楼视野**：当前项目

#### CH3 纵向管理项目的 5 个阶段

**自然计划模式**——自然计划法不一定就是常规做法：

1. 定义目标和原则
2. 展望结果
3. 头脑风暴／集思广益
4. 组织整理
5. 明确下一步的行动方案

> 当你发现自己身陷一个黑洞时，就应该立刻停手，绝不要再继续挖了。
>
> 不要仅仅忙着做事情，而是要站在旁边静静想一想。

##### 组织整理的基本要点

组织整理的关键步骤如下：

- 明确事件的重要组成部分
- 整理分类（按照下面一个或多个标准）
  - 构成因素
  - 先后顺序
  - 重要程度
- 足够详细的描述

> 任何人都不可能多任务并行，都是一次只能做一件事。

在现实生活中，干扰和打断原本就是难以避免的。当你能够熟练地、快速地分析处理突发事件，并学会利用各种零碎时间来完成行动的时候，你就可以在不同的任务之间敏捷地切换了。这种切换的过程务必要保证整个管理系统的平衡。研究已经证明，你无法真正做到多重任务化，也就是说，你无法在同一时间有意识地专注于一件以上事情；如果你试图那么做，它会显著削弱你的执行能力。

> 你要做的是发现你的世界，然后全身心地投入其中。
>
> 采用这种自下而上的工作方式的首要原因就是，这种方式能够让你清除内心的烦扰、释放受困的心灵，让你有精力去关注那些更有意义、更重要的方面。
>
> 处理你的关注事项，然后你会发现真正吸引你的东西。
>
> 让我们把超前的焦虑变成超前的思考和规划。

关键在于你要学会思考，运用思考的结果进行合理的管理。要培养一个好习惯：在考虑问题的时候高度集中精力，有预见性地发现问题、解决问题，而不是等到迫不得已时才行动。

### Part 3

只要你降低对自己的要求，便会立刻轻松起来。如果你对生活的各个方面——子女的抚养教育、学校的教学制度、团队的精神面貌、软件的代码——都降低标准，那你需要处理或关注的事情就会相应大大减少。

> 如果你不知道具体的下一步行动，那么在现实和目标之间就留下了一个潜在的、巨大的断层。

- **原则一**：养成收集的习惯
- **原则二**：确定“下一步行动”
- **原则三**：学会关注结果

事实上，在那些最聪明、最敏感的人所列出的清单上，未解决和未决定的事情的数量也是最多的。这是为什么？想一想，我们的身体对于头脑中的想象是如何做出反应的。我们的神经系统根本分不清哪些是大脑的想象，哪些是现实的生活。

> 越是才智过人的人，越敏感，也越容易被自己的想象所感染。

生活中只存在两个问题：

1. 你知道你想要达到的目标，但你不知道如何达成它；
2. 你不知道你的目标到底是什么。

如果这种说法是正确的（我认为是的），那么，也就只存在两种解决方法。

当你日复一日地以此为动力来组织整理一切事务时，这将成为习惯，融入你的血液，你看得更透彻、想得更深远、得到更多、效率更高。你不断地发现问题、解决问题，不断地设定目标、达成目标，不断地预想结果、付诸行动。

> 人生的最大乐趣莫过于克服困难、坚定脚步，目睹自己将目标一一实现。
>
> 你的大脑是用来获得想法的，而不是用来保存想法。

##### 沉浸理论

沉浸通常伴随对特定任务的全身心关注，而且你通常会有掌控感，感到目标清晰。处于沉浸状态的个人通常明白接下来会发生什么事情，并能在执行整个任务的过程中得到及时反馈。他们还能体验到行动和意识的融合，并在此过程中丧失其自我意识和时间感。

##### 三个层次

1. 采用最基本的工作流程管理；
2. 执行一个较为高级和综合的全方位生活管理系统；
3. 利用技能创造明确的空间，完成任务，并且使你的表现越来越得体。

##### 日常实践清单

- 基于“待执行事项”决定下一步行动
- 充分利用“等待”类型清单，以便能在适当的时机保存他人交付的预期可交付项目，并审查其后续状况
- 利用“日程”清单收集与他人的沟通信息，并加以管理
- 维护一个简单、易于访问的归档和参考系统
- 将日历表作为纯粹的“硬质景观”加以保存，不要让不相干的新事务破坏其可信度
- 进行“每周回顾”，以保证某个系统的功能正常化，且持续更新

##### 成熟系统的标志

- 一个完整、最新、清晰的项目清单
- 一张角色、职责、兴趣（个人和职业）的地图
- 一个集成化的全面生活管理系统，这个系统是基于某人的当前需求和发展方向定制的，用于动态监控日常工作以外的行为
- 面临的挑战和意外状况将驱使你采用（而不是弃用）这个方法

##### 落地动作

- 建立起用于个人组织整理的设施
- 安排整理你的工作区
- 准备几个工作篮
- 创建一个可行和易于访问的个人参考系统（工作和家用）
- 准备一个好用的计划手册，上面应该有完整的管理项目的清单
- 允许自己做出旨在改善工作环境的任何改变。挂图片，买钢笔，扔东西，重新安排你的工作区。为你重新启程提供支持
- 预留出一些时间，让你可以整理办公室中某一个完整的区域，然后是家中的各个角落。把收集到的一切纳入你的系统当中，并采用本书介绍的方法进行处理
- 同别人分享你从书中获得的知识、你的实践经验以及感受（这是最快的学习方法）
- 3～6 个月后，再回顾本书的内容

## 搞定II

- URL: https://blog.no-claw.com/ff723111/
- 日期: 2021-01-22
- 分类: 读书有感
- 标签: 效率, 搞定三部曲

掌握工作流程所确定的 5 个阶段：**收集、处理、组织整理、回顾和执行**。

### 几条原则

> 有些东西，你越是抵制越难以摆脱。
>
> 很多人把糟糕的管理与命运混为一谈。
>
> 系统的效率与你的感知度成反比。

- **确定原则，而不是监管制度**——规则之所以出现，是因为原则表述不清楚或未能得到信任。
- **资源越是有限，规划越有必要**
- **过度控制等于失去控制**
- **预料之内的意外算不上意外**
- **放慢速度以提升速度**

列出行动和项目清单并不只是为了完成工作，然后无所事事。处理自己关注的事情的目的，在于你可以做自己真正喜欢做的事情，集中精力和创造力全身心地投入其中。

你要养成每周回顾的习惯。在回顾的过程中，要增加可能激发为生活增添价值的有意义的想法的清单，更不要遗漏工作的某些方面。

我们面临的最大挑战就是：

1. 思考目前从事的工作；
2. 为思考的内容采取行动。

### 工作流程的 5 个阶段

这是实现**横向控制**的操作指南——怎样掌握、认识并处理好自己的全部任务。第 2 阶段和第 3 阶段将在“处理与组织整理流程图”中得到进一步说明。在真正成为习惯之前，“处理与组织整理流程图”是你案头非常有效的一种工具。

#### 1. 收集

- 捕获吸引注意力的一切外部事务（工作篮、电子邮件、笔记本、语音邮件等），并将其从大脑的短期记忆中清空。
- 根据需要尽量减少收集工具的数量。
- 通过处理和组织整理（参考下文）定期清空收集工具。

#### 2. 处理

- 处理收集到的项目（决定如何处理收集到的材料）。
- 如果**不需要**采取行动，可以抛开，也可以“存入备忘录”留待日后处理，或者将其归档备查。
- 如果**需要**采取行动，那就确定随后采取的具体行动，要么亲自处理（如果两分钟内可以完成），要么委托他人，要么延迟处理。

#### 3. 组织整理

把收集到的输入信息结果分成恰当的可检索、可检查的类别。4 种主要的行动类别分别是：

- **项目**——决定实施的项目
- **日程表**——具体某一天或某个时刻需要采取的行动
- **下一步行动**——需要尽早采取的行动
- **等待**——其他人承担的项目和采取的行动，但你要加以关注

在此之上：

- 增加有利于工作的次级类别清单（例如“电话”清单、“杂事”清单、“家”清单、“电脑”清单等）。
- 添加对你有影响的长远目标和价值清单。
- 添加需要时可能有用的核查清单（工作职责、“引子”清单、组织结构图等）。
- 针对无须采取行动但需要能检索的信息和材料，建立一般性参考资料归档系统。
- 针对以后可能采取行动的“引子”，建立一种存储系统（“将来／也许”清单、日程表、备忘录）。
- 必要时，为项目建立辅助信息文件。

#### 4. 回顾

- 每天查看日程表和“下一步行动”清单，确保当下的选择有据可依。
- 每周对整个系统做一次完整回顾，让所有清单重新变得可信（详见下文“每周回顾指南”）。
- 定期从更高层面检视目标、责任范围与长远方向。

#### 5. 执行

- 用情境、时间、精力、重要性这四个标准，决定此刻做什么。
- 在事先安排好的工作、突发事件、安排自己的工作这三类之间做出取舍。
- 相信系统给出的选项，然后专注地做那一件事。

### 自然式计划模式

这一模式是参照大脑自然计划各项事务的模式建立起来的。它提供的是**纵向控制**，例如考虑单个具体项目或情境的最有效方式。明确所有项目之后，要轻松自然地加以驾驭，每个项目可能都需要你在一个或多个层面投入更多关注。

#### 1. 目的／指导原则

- 为什么要做这件事？“有目的”究竟是什么意思？
- 为项目做出决策、采取行动时，我们应该遵循哪些关键标准？遵守哪些规则？
- 目的和原则是项目决策的指导性标准。

#### 2. 使命／愿景／目标／成功的结果

- 如果事情大获成功，将会是什么情况？我怎么知道这种情况？
- 利益相关方会如何看待和感受那种成功呢？

#### 3. 头脑风暴

- 关于这件事情，我有哪些想法？现实情况如何？
- 先把所有念头倒出来，不做评判、不分优劣，数量优先于质量。

#### 4. 组织整理

- 从倒出来的想法中辨认出关键的组成部分、先后顺序和轻重缓急。
- 该分层的分层，该排序的排序，让结构自己浮现出来。

#### 5. 明确下一步的行动方案

- 这个项目当前能推进的具体物理动作是什么？
- 由谁在什么情境下完成？把它放进对应的清单。

> 如果你已经把项目从头脑中抛开，那说明计划很充分。如果项目还在你头脑中萦绕，那就坚持继续使用这种模式，直到项目变得明朗。

### 每周回顾指南

第一项挑战是按照这些模式开展工作，第二项挑战则是让这些模式充满活力、始终发挥作用。本指南将为你实现更轻松、更富效力、持续始终的生活及工作方式提供一把万能钥匙。这个流程如果发挥作用，将有助于提升管理指挥中心的思考能力和信心。**如果能做到每隔 7 天运作一次，它将发挥出最大的效力。**

##### 散落的纸片

- 搜罗各种零碎纸片、名片、收据和各类文件，放进工作篮等候处理。

##### 整理笔记

- 回顾一下日志／笔记本上的记录、会议记录和笔记本活页纸上潦草写下的各种笔记，分门别类地记录任务、项目、待处理事项等。

##### 清空大脑

- （按照合适的类别）写下还没有掌握的所有新项目、任务、待处理事项、将来／也许会处理的事项等。

##### 回顾“行动”清单

- 标出完成的行动，查看将要执行的行动的提示信息。

##### 回顾“等待”清单

- 记录为后续措施采取的适当行动，检查标出最近收到的反馈。

##### 回顾“项目（及更重大的结果）”清单

- 依次评估项目、目标和结果的当前情况，确保对每一项都采取了行动。浏览工作进度辅助材料，构想新的行动、要完成的任务和待处理工作等。

##### 回顾以往的日程表

- 仔细查看以往的日程表，搜寻未完成的工作、有用的参考数据等，将其纳入当前系统中。

##### 回顾将来的日程表

- 浏览一下将来的日程安排——包括长期和短期安排，记住需要采取的行动。

##### 回顾相关的核查清单

- 以此作为采取新行动的引子。

##### 回顾“将来／也许”清单

- 查看一下哪些项目现在或许可以开展了，将其转移到项目清单上。

## 搞定III

- URL: https://blog.no-claw.com/88750187/
- 日期: 2021-01-22
- 分类: 读书有感
- 标签: 效率, 搞定三部曲

把工作当成游戏，而且是好玩的游戏，只要我们牢记它的目标、界线、内容和规则就行。

就我的经验而言，欣然采纳 GTD 的读者基本上可以分成 3 大类：

1. 以为自己懂了，其实似懂非懂。
2. 有一定的领悟，但是知道自己还没有充分发挥 GTD 的效用。
3. 掌握了它的精髓，在一定程度上真正做到了“高水平”的运用。

手头常备一个小本子，想起什么就随手记下来，这是个好习惯，即便这个本子只是放在那里。

### GTD 模型的内在逻辑

那么，GTD 模型是怎么回事呢？它的步骤有什么逻辑呢？

**力量＝精力集中**

精力集中就可以做到高速运转，成效显著。如果你不能集中精神，不管是弹钢琴、练习空手道、训练宠物狗、学外语还是和处于青春期的儿子进行一次重要谈话，都收效甚微。

**精力集中＝不分心**

你的脑子开过小差吗？工作效率受到了什么影响？

什么事情最让你分心？我敢肯定，有些日子你心神不定，外界的庞杂事务让你不能放松，也不能把事情顺利完成，比如很大的噪声，比如有人突然闯进你的办公室，比如电脑死机等。不过老实说，你独自一人在安静的房间里，就没有心神不宁的时候吗？肯定有。我们的思绪容易被别人打断，但我们的思绪本身也容易陷入天马行空的胡思乱想中。

**分心＝事务处置不当**

#### 如何释放承诺未兑现时的压力

要想减轻承诺未兑现时的压力，你必须意识到：

- 你要捕捉、明确所有层面的事情并把它们条理化。
- 你自觉地在必要的时候查看、追踪它们的进展情况。

### 全局视角是你最宝贵的财富

把生活当事业，把工作当游戏，你看待它们的正确视角是实现生活、事业双丰收的最终钥匙。

日程表可能是人们自己想出来的把大脑延伸的最好例子。

如果我们把注意力集中在一件事上，事情就能做得很漂亮。而如果我们要考虑的两件事或几件事没有明确的界限，就会出问题。

“有条理”的概念应该变成“掌握主动权”，因为组织整理只是解决问题的一小步，而且也不是第一步。同样，“明确优先级别”的内涵要扩展，变成“在适当层面明确目标”，这比单纯制订战略计划要更深刻。

> 关注吸引你注意力的事情。
>
> “有条理”究竟意味着什么——意义先于条理。

### 处理与组织整理流程图

材料进入“工作篮”之后，只需反复问两个问题：**这是什么？****需要采取行动吗？**

```mermaid
flowchart TD
    IN[材料] --> BOX[工作篮]
    BOX --> Q1{这是什么？}
    Q1 --> Q2{需要采取行动吗？}

    Q2 -- 不需要 --> TRASH[垃圾／回收物]
    Q2 -- 不需要 --> SOMEDAY[将来／也许清单<br/>备忘文件夹]
    Q2 -- 不需要 --> REF[参考资料<br/>纸质／电子清单]

    Q2 -- 需要 --> NEXT{下一步需要<br/>采取什么行动？}
    NEXT -- 需要多步骤行动的任务 --> PROJ[项目]
    PROJ --> PLAN[项目计划]
    PLAN -.行动时备查.-> NEXT

    NEXT --> DO[立即执行<br/>两分钟之内能完成]
    NEXT --> DELEGATE[委派别人]
    NEXT --> DEFER[延迟]

    DELEGATE -- 需要跟踪进度 --> WAIT[等待清单／文件夹]
    DEFER -- 指定时间自己完成 --> CAL[日程表]
    DEFER -- 需要尽快完成的行动 --> NA[下一步行动<br/>行动提示清单]
```

对应的三种处置方式：

1. 马上执行；
2. 交给别人执行；
3. 把它暂时搁置，提醒自己及时追踪查看。

如果可以行动，想清楚具体的下一步行动：**执行**（如果不超过两分钟）、**委派别人**（在“等待”清单上追踪）或者**延后**（列入行动提示清单或收入行动文件夹）。如果某个行动不能一步完成，那么，把它的承诺视为项目，列入项目提示清单。

### 组织整理：四大行动类别

把整理结果进行分类，以便及时查看追踪。行动可分为四大类：

- **项目**——你承诺要完成的事
- **日程表**——必须在指定日期或时间进行的行动
- **下一步行动**——要尽早做的事
- **等待事务**——应由别人执行的项目和行动

在此之上：

- 把这些清单再做细分，使之方便好用（电话、跑腿活、家里、电脑等）。
- 在清单上添加长远目标和对你具有影响的价值观。
- 必要时添加有用的对照表（岗位描述、事务提示清单、组织结构图等）。
- 把无须采取行动、但可能回访的资料归入参考系统。

#### 按情境细分的清单

- **“电话”清单**——列出你要打的所有电话，你可以在任何地方用任何电话拨打。
- **“电脑”清单**——列有必须用电脑来完成的活动：收发电子邮件、起草一份文件、网上搜索资料等。
- **“办公室”清单**——列有必须在办公室才能完成的工作，比如重新整理文档、打印、审阅一份长文件。
- **“家”清单**——列有你需要在家里和家附近完成的事情，比如修理电灯开关、整理工具箱、修剪苹果树等。
- **“任何地方”清单**——列有不受情境限制的事情，比如审阅一份长文件。你可以把它装在公文包里随身携带，随时可以打开翻看，直到看完为止。
- **“外出事宜”清单**——列有你需要外出时顺路处理的事情。

#### “等待”清单

这个细分项下的内容不少，它像 GTD 的其他层面一样，可能使人们大大减轻心理压力。它包括你所等待的、其他来源的一切事务，包括你委派别人去完成的任务、订购而尚未送到的商品、出借物品、老板或潜在客户已经认可的事务等。某件事接下来的行动往往不由你决定，它由别人负责。你的任务是追踪谁是责任人，确保他们收到了任务指令，并适时掌握事务的进度。

#### 将来／也许

第一类是你想要定期总结的事务。它们应该被列成清单或者投入工作篮里，必要时你可以定期查看。比如，你一直在考虑近期学一学西班牙语（但不是本周），你也许希望经常想起这件事。

### 五个动作

- 捕捉
- 明确意义
- 组织整理
- 深思
- 参与

### 高度图：六个视角层次

“工作”至少要在 6 个层面被定义和管理，它们分别对应视角的不同高度，涵盖了从根本意图（对一件事、一项事业、一种生活的意义和价值的理解）直至日常琐事（由意义和价值观引发、推动事务发展的具体下一步行动）。如果你能对自己在多个层面参与社会生活的行为做出评价，妥善地分辨、捕捉和执行各种承诺和事务，就能做到心思澄明，减少精力的无谓消耗。多个层面的和谐可以使办事效率达到最高水平。

优先级自上而下排列，也就是说，你的宗旨和价值观决定你的愿景，构想导出具体目标，具体目标构成关注和职责范围。它们共同引出项目，项目要求通过行动来完成。明确、顺利执行各个关注层面的事务是同等重要的，但是，你在各个层面的思考内容和承诺却有所区别。

| 高度 | 层面 | 回顾频率 |
| --- | --- | --- |
| 5 万英尺 | 事业、目标、生活方式 | 1 年以上 |
| 4 万英尺 | 3～5 年目标 | 每年 |
| 3 万英尺 | 1～2 年目标 | 每季度 |
| 2 万英尺 | 当前职责 | 每月 |

**4 万英尺——愿景。**顺利落实的感觉如何，看起来、听上去是什么样？长远结局和理想图景。

- **格式**：与合伙人、董事会、团队、家庭召开外出会议；对即将启动的项目、会议、整个企业的初步讨论；人生规划；每年重新思考企业的方向；提出理想情景；个人藏宝图
- **频率**：有必要进一步明确和指明方向、协调努力、激发动力的时候

### 自然式计划模式

#### 1. 宗旨／指导原则

- 为什么要做这件事？“符合宗旨”究竟是什么意思？
- 做出决策和执行该项目的重要标准是什么？要遵守什么原则？
- 原则和宗旨是项目决策的指导性标准。

#### 2. 使命／愿景／目标／成功的结果

- 大功告成是什么样？怎么知道已经大功告成？
- 各利益相关方对圆满的结果有何看法，感觉如何？

#### 3. 头脑风暴

- 这件事在我身上体现为哪些情况？现状如何？我知道什么？不知道什么？我该考虑哪些问题？我没有考虑哪些问题？
- 要全面，要坦诚接纳，不做评判，克制批评性的分析。
- 从多个角度考虑。

#### 4. 组织整理

- 指出构成因素（项目细分）、先后或重要性排序。

### 项目规划提示清单

**客户／社区／法律**

- 问题是什么？
- 有哪些规章制度？

**空间／公共设施／设备**

- 什么需要占地方？怎么找地方？
- 要用什么工具？什么时候？
- 电话／电脑

**调查了解**

- 你也许要了解什么情况？

**公关**

- 让别人知道，对事情好不好？怎么做？

**风险**

- 可能发生什么情况？你能处理吗？

**创意思考**

- 谁关心项目的成功？
- 他们会说什么话、提什么问题、给出什么意见是你尚未执行的？
- 这件事你能想到的最坏结果是什么？（反过来，最好的结果是什么？）

### 执行：如何、何时

- 紧急事项与优先级
- 行动是前线

### 每周回顾

回顾系统有两个同等重要的目的：

1. 更新内容；
2. 提供可靠的视角。

#### 保持清爽

**收集零散的文件和材料**

- 把积累的名片、收据和庞杂的纸质材料收集起来，放入工作篮。

**清空工作篮**

- 把待处理的纸质材料、日志、会议记录、语音信箱、献辞和电子邮件等彻底清理。

**清空大脑**

- 写下并处理一切未捕捉的新的“项目”、“行动”、“等待”、“将来／也许”清单。

#### 保持最新

**查看行动清单**

- 把已完成的项目勾掉。查看下一步行动的提示信息并做记录。

**查看翻过去的日程表事务**

- 寻找遗留的行动和参考资料等，把它们转移到日程表新的一页。

**查看即将发生的日程表事务**

- 查看长远和短期的日程安排，捕捉它们所引发的行动。

**查看“等待”清单**

- 记录后续措施，检查最近收到的反馈。

## 效率技巧摘抄（出处待考）

- URL: https://blog.no-claw.com/26314a8/
- 日期: 2021-01-22
- 分类: 读书有感
- 标签: 效率

### 1.两分钟法则

如果一件事可以在两分钟内完成，比如回复邮件，一个简单的家务，就立即完成，因为记住它、计划时间、在后来完成它，可能会花费五分钟甚至更多的时间。

### 2、五分钟法则

拖延症是影响工作效率的大魁首之一，想要治愈它不是给自己定下目标、下定决心去完成一项大任务，而是只在那件事上花五分钟。你会发现在大多数情况下，它在超出五分钟的时候依旧很顺利，因为你已经进入了平坦期。

### 3、不要坚信自己的记忆力很强悍

即使你是一个记忆天才，也要把每件事都从你的脑子里清理出来，并进行记录，方法不重要，可以把它们写在一个笔记本里，也可以放进专门的应用里等等。

### 4、30分钟专注于一件事

在30分钟内只做手头上的事，不去理会其他任何事，没有电话、没有邮件、不说话、不看QQ消息提醒，除非发生火灾。当然，如果老板找你谈话例外，这是没办法的事。

### 5、尽量保持睡眠时间，白天小睡

睡眠少可能导致许多能力退化，不是危言耸听，美国军方研究表明，“每天少睡 1 小时持续一周会导致相当于 0.1 血醇水平的认知退化”。

《睡眠的秘密世界》指出：熬夜之后无论白天你干得有多好，情绪也不会太高。更重要的是前瞻性思考能力、行动的意愿、对冲动的抑制力、乐观程度、同理心、情商等也会下降。

所以，白天小睡真的是个好习惯，你没有发现爱熬夜的自己变笨了吗？

### 6、总是戴着耳机

戴着耳机不一定在听音乐，这可以防止别人接近你、打扰你。有些人听音乐时工作效率更高，比如小编。

### 7、程序员离开手机一会儿真的没关系

工作时把手机调成静音，放在眼睛看不到的地方，可以分批集中时间处理电话短信。

还有邮箱也一样，不用一直去关注，特别是放在早上和晚上处理，把需要解决的和代办事件列表连在一起，有用的存档，做到邮箱清零。

### 8、MI3

早上理出最重要的三件事，或是改成一件必做的，3件应该做的，或是五件可以做的，然后开始做最重要的一件事。不要认为意志力可以解决一切，把最重要的事情放在早晨做，并且尽可能地让所有事情自动化（委托，分批等等）。

### 9、有计划的拖延

你的大脑需要休息，并且有时候新一期的绿箭侠可以比最好的TED演讲创造更大的奇迹。

### 10、假装无能

有时候假装无能能让你更有精力去展示自己的能力。

### 11、不追求完美，程序员更不需要

达尔豪斯大学的心理学教授 Simon Sherry 的完美主义与生产力研究发现，完美主义是生产力的绊脚石：

完美主义者完成任务需要花费更多的时间。

完美主义者因此等待完美时刻而耽搁。就商业而言，如果你等到了完美时刻时间已经太迟。

完美主义往往因为一叶障目而不见泰山，因为过于关注小事情而错失了大场面。

所以，真的，差不多就行了。

最后，还有一个方法就是把信用卡刷爆，当你觉得对工作不满意、没动力、效率不高时，去把你的信用卡刷爆，绝对鸡血满满，这个方法只为大家开心一下，要是这样还没动力：

“吃苦耐劳”真的是优良品质吗，与你怎么做相比，老板们应该更关心你做了什么、达到的效果。所以，效率，还是效率，希望这些实用小技巧对大家有所帮助。

## 吃掉那只青蛙

- URL: https://blog.no-claw.com/4141dd35/
- 日期: 2018-10-25
- 分类: 读书有感
- 标签: 效率

### 书中方法摘记

1. 明確目標：確定你自己究竟想要什麼。目標清晰至關重要。在每天開始工作之前，把你的目標全部寫下來。
2. 精心計劃：把你的想法付諸筆端。你花費在準備工作上的每一分鐘時間，都將使你在工作過程中節約 5 ～ 10 分鐘的時間。
3. 運用 80/20 法則：20%的活動能產生 80%結果。因此，盡量把你的精力集中在那 20%的活動上。
4. 著眼未來：對你來說，最重要的、應該優先處理的事情就是那些將對你以後的生活或者工作產生最重要影響的事情，無論該影響是正面的還是負面的。首先全力以赴地處理這些事情。
5. 學會說「不」：既然你沒有時間去做所有的事情，你必須學會推遲處理那些沒有什麼意義的工作，從而騰出時間來處理那些少數的、重要的工作。
6. 使用 ABCDE 法：根據自己列出的工作清單開始工作之前，先花費一點兒時間，根據輕重緩急對這些事情進行安排，從而確保你先處理最重要、最有價值的事情。
7. 抓住關鍵：要想圓滿完成自己的工作，你必須具備哪些能力和技能？找出這個問題的答案，然後通過日復一日的努力來解決上述問題。
8. 抓大放小：找出你工作中最重要的三件事情，你對公司 90%的貢獻都來自這三件事情。無論如何，先把這些事情做好，然後，你才能騰出更多的時間來安排你的生活。
9. 精心準備：著手工作之前，先把一切都準備就緒：所有的資料、信息、工具、辦公用品，以及你可能用得到的數據，然後，你就可以全心全意地工作了。
10. 循序漸進：如果你下定決心一步一個腳印地前進，那你就能完成最艱巨、最複雜的工作。
11. 精益求精：你在自己的領域內知識越淵博，技能越嫻熟，你動手就越快，任務完成得就越早。
12. 施展才華：確定你最擅長做什麼事情，或者說你能把什麼事情做得最好，然後全身心地投入這些工作，精益求精。
13. 突破瓶頸：確定影響你實現自己目標的瓶頸所在，或者是主要障礙，無論是來自外界還是來自自身，然後集中精力消除這些障礙。
14. 自我施壓：假設你即將離開你所在的城市，外出一個月的時間，離開之前必須把所有重要的工作都處理完。
15. 挖掘潛能：確定你每天什麼時候處於腦力和體力的最佳狀態，然後據此安排自己一天的工作，盡量在這段時間裡處理那些最重要、最緊迫的任務。要注意充分休息，從而保證最佳狀態。
16. 說幹就幹：做你自己的拉拉隊隊長。在任何情況下，都尋求事情積極的一面。把精力集中在如何解決問題上，而不是問題本身。要保持樂觀向上的態度。
17. 避開科技陷阱：你可以利用高科技來提高自己的通訊質量，但是注意不要讓自己成為科技的奴隸。要學會偶爾把所有的通訊設備都關掉，切斷自己與外界的聯繫。
18. 化整為零：把複雜而又艱巨的大任務分割開來，變成許多部分，每次只處理一小部分。
19. 創造大塊時間：為自己安排一份日程表，然後集中精力用那些大塊的時間來處理對你來說最重要的事情。
20. 培養緊迫感：養成迅速處理重要工作的習慣。把自己培養成一個能迅速、圓滿完成工作的人。
21. 全力以赴：根據事情的輕重緩急來安排優先處理的事情，然後立即著手處理最重要的、必須優先處理的事情，全心全意地去做這件事情，決不中途停止，直到百分之百地完成為止。這是工作高效、業績突出的關鍵所在。
22. 下定決心，每天都實施這些規則，直到它們成為你的第二本性。一旦你在時間管理方面養成上述習慣，使之成為自己個性中一個不可分割的部分，你的前途將不可限量。說做就做！吃掉那只青蛙！

### 当时的行动短记

同一天还记了一份更偏执行的短清单。和上面重复的部分不再抄一遍，留下几条当时给自己的提醒：

- **精心计划每一天**：早上列清单，晚上回顾，再安排第二天。当时还在旁边写了个问题：周计划？
- **6P 公式**：Proper Prior Preparation Prevents Poor Performance。事前准备能够避免不良表现。
- **一次一个汽油桶**：把任务分解，一次处理眼前这一段。
- **给任务一个 deadline**：挖掘潜能，也给自己设定截止时间。
- **先难后易**：把最重要、最难的事放在前面，推迟意义不大的工作。

## 驯服头脑中的野兽

- URL: https://blog.no-claw.com/101d9cf0/
- 日期: 2018-10-25
- 分类: 读书有感
- 标签: 效率

### 野兽特征

1. 第一点
   1. 讨厌难的事情 （为了防止浪费能量）
   2. 对所以刺激都有反应 （并行处理）
   3. 力量大 （处理速度快）

##### 驯兽师

1. 第一点
   1. 逻辑导向 （只能串行处理）
   2. 能力消耗大 （很多依赖大脑的工作记忆）
   3. 力量弱小

#### 结论

1. 第一点
   1. 驯兽师无法战胜野兽。（战斗力，野兽是发散意识，驯兽师是集中记忆
   2. 世界上不存在擅长集中注意力的人。（重新来过就好）
   3. 如果能引导野兽，就能获得巨大的力量。（信息干消耗专注力）

##### 给野兽喂食

填饱肚子，和咖啡（减少疲劳感，专注时间会变长，150-200mg 咖啡因）

###### 和咖啡的原则

1. 不要和太多，超过 300mg 效果消弱，400mg 产生副作用
2. 咖啡加速牛奶或者奶油（有些人心跳加速可以缓解）
3. 起床 90min 内不喝（防止和皮质醇冲突）
4. 2B-Alert（请 google，一个美国的算法）
5. 和绿茶一起喝（咖啡因 + 茶氨酸 效果提升）

###### 饮食方法

补充必要营养

- 铁、锌、镁等矿物质
- 维生素 D
- 叶酸、维生素 B12
- ω-3 脂肪酸
- 胆碱
- 必需氨基酸
- S-腺苷甲硫氨酸（SAM-e）

1. “MIND”饮食（多吃对大脑有益的，少吃有害的，不限制卡路里）
2. 良好饮食习惯，记录 mind 饮食法的日期
3. 专注力日志+记分板（记录专注多久了）

##### 当成游戏

① 增加有效的获得回报的预感。
② 减少无效的获得回报的预感。

影响注意力的因素（单调乏味，难度不对）

##### 内观和正念

1. 意志力会越用越少
2. 控制自己会消耗能量
3. 能力用尽无法控制
4. 已经否定了补充糖分理论

###### 观察自己

1. 观察自己所想，比如目前状态，走路状态，
2. 走神之后拉回来，然后继续
3. 一次只做一件事，吃饭的时候不要刷剧
4. 幻想平静的场景

##### 工作环境

1. 专用空间
2. 专用设备（工作手机电脑和生活手机电脑）
3. 账号分区（同工作和生活）
4. 内容拦截（短信和广告）
5. 噪音管理（降噪耳机）
6. 自身性格（外向音乐加强效率，内向降低）
7. 纯音乐（歌词会降低专注力）
8. 工作间隙听音乐
9. 适当记录情绪（比如无聊，焦虑，把情绪物质化，像什么。。。
10. 观察情绪而不是控制

##### 学会放弃和休息

很多人会有如下误区，在众多的压力中，自责是伤害最大的。所以要自我接纳。

① 过分追求专注力。
② 过于责备自己没有专注力。

1. 既然事情已经发生了，接纳就好，不需要评判，只是去观察。
2. 做一些补救的办法，尝试相关的新事物（有优势的，能学到东西的）

###### 休息的方法

1. 微休息(几十秒到几分钟)
2. 任务休息（和番茄工作法类似。不过是防止休息跑远了，在复杂任务间隙做简单任务，达到休息的目的。降低大脑运算速度。
3. 积极休息（休息时做温和的运动，比如定期散步）
4. 超积极休息（高专注力的多巴胺，剧烈运动释放压力）
5. 美军睡眠法（从头到下冥想放松）
6. 偶尔睡个午觉（自己加的，毕竟多阶段休息）
