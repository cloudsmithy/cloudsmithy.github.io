懒猫微服实战入门（十五）：大疆 Pocket 3 素材导入懒猫网盘

发表于2025-06-24|更新于2026-09-05|懒猫微服入门
|总字数:540|阅读时长:1分钟

日常使用 Pocket 3 拍摄视频时，共享素材比较麻烦，要么每台手机都安装 App，要么先导出再发送。我突然想到，可以把素材传到懒猫网盘中，这样就解决了这个痛点。

大疆的机器每次连接都要走这个流程，不得不说真的很麻烦。这个 Wi-Fi 的记忆功能比较鸡肋。

连接之后需要右上角先把视频下载到手机本地，然后点击分享。

这里可以选择各种软件，比如 AirDrop、微信、邮件。我选择懒猫微服，点击后就会跳转到懒猫网盘。

第一次传输时，我发现速度慢得离谱。询问售后才知道，iOS 会在 Wi-Fi 网络无法联网时尝试使用蜂窝数据。

因为大疆 Pocket 3 传输素材时需要连接相机自己的 Wi-Fi，所以手机此时处于 Wi-Fi 无法联网的状态，蜂窝数据速度也不快。

偷偷跑流量算是手机和运营商的传统了，于是我在蜂窝网络设置里关掉懒猫微服的蜂窝数据权限，同时关闭“无线局域网助理”。

关闭之后再重复前面的操作，会发现懒猫网盘打不开了。嗯，这就是预期行为，手机不会再偷偷使用蜂窝数据。

于是我询问大疆售后，能不能让设备直接连接家里的 Wi-Fi，得到的回答是不行，只能手动切换网络。

切回家里的 Wi-Fi 后再传输，速度就舒服多了。虽然没有跑满千兆，但已经够用。

然后把上一步的视频文件夹共享出来，以后把素材都发到这个文件夹里。再共享给其他的懒猫用户，就很方便了。

两个很想吐槽的地方

  1. 大疆 Pocket 3 不能直接连接家里的 Wi-Fi，传文件到网盘时必须切换网络
  2. Apple 的 Lightning 接口不能直接连接普通 USB 设备，需要额外购买合适的转接头
