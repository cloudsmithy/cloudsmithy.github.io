《搞定》个人工作流 SOP

发表于2026-09-16|更新于2026-09-18|读书有感
|总字数:2.9k|阅读时长:8分钟

SOP 编号：GTD-PW-001
版本：1.0
适用范围：个人工作与生活事务管理
依据：《搞定Ⅰ》的五步工作流与自然式计划法、《搞定Ⅱ》的 52 项原则和基本要素、《搞定Ⅲ》的掌控与视角模型
相关资料：搞定(AI提取) · 《搞定》实践清单手册

一、目的

建立一个可信的外部系统，使所有需要关注的事项都能经过同一套流程：

  1. 被及时捕捉；
  2. 被明确其意义；
  3. 被放进正确的位置；
  4. 在需要时被重新看到；
  5. 转化为可以执行的行动。

执行本 SOP 的完成标准不是“把所有事情做完”，而是：

  • 知道自己已经承诺了什么；
  • 知道每件事下一步怎样推进；
  • 知道暂时不做的事情存放在哪里；
  • 能够放心地专注于当前选择。

二、输入与输出

输入

任何正在吸引注意力的内容：

  • 电子邮件、聊天消息和语音留言；
  • 文件、票据、会议记录和便条；
  • 别人提出的请求；
  • 自己作出的承诺；
  • 突然产生的想法；
  • 尚未解决的问题和担忧；
  • 工作、家庭、健康、财务等方面的变化。

输出

每项输入必须转化为以下结果之一：

输出位置内容
删除／垃圾没有价值且不需要行动
参考资料不需要行动，但以后可能查询
将来／也许目前不承诺，以后可能启动
日程表必须在指定日期或时间发生
项目清单需要两个及以上行动才能完成的结果
下一步行动已明确、可以直接开始的具体动作
等待清单由别人负责、自己仍需追踪

三、执行频率

流程执行频率
捕捉事项出现时立即进行
工作篮处理每天进行，全部入口在 24～48 小时内清零
日程表检查每天开始工作前，并在日程变化后检查
行动清单检查每次选择下一项工作时
项目和等待清单回顾每周一次
完整每周回顾每 7 天一次，初期预留连续两小时
责任范围检查大约每月，或职责发生变化时
一两年目标检查按季度或至少每年一次
长期愿景、宗旨和原则每年、重大变化或重要取舍时

四、标准流程

    B --> C[进入工作篮]
    C --> D{这是什么？}
    D --> E{需要行动吗？}

    E -- 否 --> G[参考资料]

    J -- 是 --> K[加入项目清单]
    J -- 否 --> L[明确下一步行动]

步骤 1：捕捉

触发条件

只要一件事开始占据注意力，就启动捕捉。

操作

  1. 用固定工具写下或收下这件事；
  2. 一条记录只表达一件事；
  3. 暂时不判断优先级；
  4. 暂时不展开计划；
  5. 将记录放进会被处理的工作篮。

完成标准

  • 事项已经离开大脑；
  • 记录足以让自己之后想起原意；
  • 知道这条记录何时会再次被看到。

步骤 2：明确意义

从工作篮最上面一项开始，一次处理一项，不挑选，不原样放回。

依次回答：

  1. 这是什么？
  2. 需要行动吗？
  3. 如果完成，想得到什么结果？
  4. 下一步可以直接执行的动作是什么？

不需要行动

  • 没有价值：删除；
  • 以后可能有用：归入参考资料；
  • 以后可能去做：归入将来／也许；
  • 只在未来某日才需要看到：设置日期提醒。

需要行动

先明确完成结果。一个行动无法完成的事项，同时加入项目清单。

下一步行动必须可以直接开始，例如：

  • “给财务打电话确认预算口径”；
  • “搜索三家供应商的报价”；
  • “起草给客户的确认邮件”。

“研究一下”“推进项目”“处理合同”不算已经明确的行动。

完成标准

  • 材料的意义已经明确；
  • 需要的完成结果已经写出；
  • 下一步行动已经决定；
  • 不再需要重新思考同一个问题。

步骤 3：组织整理

根据前一步作出的决定归位。

日程表

只放三类内容：

  1. 指定时间的行动；
  2. 指定日期的行动；
  3. 指定日期才需要看到的信息。

普通任务不得因为“希望今天完成”就放进日程表。

项目清单

使用完成结果描述项目，例如：

  • “合同完成双方签署”；
  • “父母体检安排完成”；
  • “新网站上线”。

每个活跃项目至少有一个下一步行动。

下一步行动清单

按真正影响执行的情境分类，例如：

  • 电话；
  • 电脑；
  • 办公室；
  • 家；
  • 外出；
  • 阅读／回顾。

等待清单

至少记录：

完成标准

  • 所有处理结果已经归位；
  • 行动出现时能快速找到；
  • 项目资料没有代替项目和行动提醒；
  • 会议记录和邮件中没有隐藏的承诺。

步骤 4：选择并执行

每天先查看日程表，再从行动清单选择工作。

选择顺序：

  1. 情境：现在能在哪里、使用什么工具、联系什么人？
  2. 时间：距离下一项固定安排还有多久？
  3. 精力：当前适合深度工作还是简单任务？
  4. 相对重要性：剩余选项中哪一项最值得现在做？

日常工作分成三种状态：

  • 执行预先确定的工作；
  • 处理突然出现的工作；
  • 收集、明确和重新定义工作。

切换之前确认：

  • 新事项是否真的要求立刻改变计划；
  • 如果暂时不处理，是否已经捕捉；
  • 当前行动是否仍服务于有效的项目和目标。

完成标准

  • 同一时刻只专注于一个行动；
  • 改变计划是有意识的决定；
  • 新事项不会因为打断而遗失；
  • 行动结束后，相关清单得到更新。

步骤 5：每日维护

开始工作前

  • 查看今天的日程表；
  • 查看未来一两天需要提前准备的事项；
  • 确认可用时间和当前情境；
  • 选择第一项行动。

工作结束前

  • 收集桌面和临时记录；
  • 记录新产生的项目和行动；
  • 更新已经完成的行动；
  • 更新等待事项；
  • 查看明天的日程；
  • 确认工作篮何时处理。

步骤 6：每周回顾

每周回顾分为三个阶段。

A. 保持清爽

  • 收集零散纸片、票据、会议记录和临时笔记；
  • 清空纸质和电子工作篮；
  • 写下脑中尚未进入系统的事项。

B. 保持最新

  • 查看过去的日程，提取遗留行动和信息；
  • 查看未来几周，发现准备事项和日期冲突；
  • 更新下一步行动清单；
  • 更新等待清单；
  • 逐项查看项目清单；
  • 确保每个项目至少有一个下一步行动；
  • 查看议事日程和将来／也许清单。

C. 发挥创造性

  • 有什么新项目值得启动？
  • 哪个项目应当暂停或取消？
  • 有什么可以委派？
  • 哪个重复问题需要建立核查清单？
  • 将来／也许中有什么现在可以启动？

每周回顾完成标准

  • 项目清单完整、清楚、最新；
  • 每个活跃项目都有下一步行动；
  • 等待事项知道由谁负责、何时跟进；
  • 日程表准确反映未来的硬边界；
  • 可以直接根据行动清单开始工作；
  • 大脑不必继续承担提醒责任。

五、项目规划子流程

当项目模糊、停滞、多人协作或风险较高时，执行自然式计划：

  1. 宗旨：为什么要做？
  2. 原则：有哪些不能突破的边界？
  3. 成功结果：大功告成是什么样？
  4. 头脑风暴：已知什么、未知什么、有哪些可能性？
  5. 组织整理：组成部分、顺序、优先级和责任人是什么？
  6. 下一步行动：现在由谁做什么？

项目计划完成后，必须把具体结果放回项目清单，把动作放回日程表、行动清单或等待清单。

六、异常与恢复流程

真正紧急的事项

先处理人身、财务、法律、业务风险和当天的硬日期事项。计划已经无法兑现时，立即通知相关人员并重新商定承诺。

系统失控

依次执行：

  1. 停止在脑中反复排序；
  2. 写下所有正在吸引注意力的事项；
  3. 收集散落材料和消息；
  4. 逐项明确结果和下一步行动；
  5. 更新项目、行动、等待和日程表；
  6. 查看未来几天的硬日期；
  7. 选择一个当前可以执行的行动；
  8. 安排一次完整每周回顾。

判断最薄弱的环节

表现薄弱环节修复动作
害怕遗漏，脑中一直记事捕捉进行大脑清扫，统一入口
清单都是“推进、处理、研究”明确写出结果和具体行动
知道要做，但找不到记录组织统一清单和归档位置
不愿查看清单回顾执行完整每周回顾
一直规划，很少完成参与选择一个动作并执行
做了很多事，不知道为了什么视角检查项目、责任和目标

七、质量检查

每周回顾结束时确认：

  • 所有捕捉入口都在控制之下；
  • 工作篮中没有长期积压的不明事项；
  • 日程表只保存硬日期；
  • 项目都以完成结果描述；
  • 每个项目都有下一步行动；
  • 下一步行动可以直接执行；
  • 等待事项包含责任人和跟进时间；
  • 参考资料能够快速找到；
  • 系统没有因为分类和工具过多而变得难用；
  • 面对压力时，自己会使用系统而不是放弃系统。
