这些是 2017–2019 年学习嵌入式时留下的记录。51 单片机部分从 Linux 开发环境开始，再读 LED、数码管、按键、定时器和通信；STM32 与树莓派单列，避免混淆硬件平台。

## 使用这些旧笔记

- 51 单片机记录涉及 Keil / Proteus、SDCC 与 stcflash；STM32 记录使用当时的 STM32CubeMX、SW4STM32 和 STM32F767 开发板。按原文的芯片和引脚配置理解代码。
- 同名的 `main.h`、`delay.c` 等文件属于各篇独立实验，不应把不同文章里的版本直接混用。
- 这里保留当时的工具版本和实验结果。本次迁移没有接板重烧或重新测量电路。

## 51 单片机

1. [51 单片机学习笔记：Linux 开发 8051：环境搭建](/8bd7b11b/) — 在 Linux 下配置 SDCC 与 stcflash，记录 8051 程序的编译、串口连接和烧录过程。
2. [51 单片机学习笔记：LED 与流水灯](/fc49a1f5/) — 在 Proteus 与 Keil C 中练习 LED 点亮、闪烁和心形流水灯，记录端口控制与延时写法。
3. [51 单片机学习笔记：常用库函数](/a73de94/) — 整理 51 单片机 C 程序中使用的常用库函数，配合示例记录调用方式。
4. [51 单片机学习笔记：数码管](/1baba95c/) — 从数码管静态显示到动态扫描，整理共阴段码及 74LS138、74LS48 辅助显示的实验。
5. [51 单片机学习笔记：按键](/c9c6472d/) — 51 单片机按键实验：独立按键、按键复用、矩阵键盘，以及 74LS148 编码器的应用。
6. [51 单片机学习笔记：中断与定时器](/283d15fb/) — 学习外部中断的下降沿与低电平触发，整理定时器四种工作方式及计数器实验。
7. [51 单片机学习笔记：串口通信](/a5882897/) — 从串口收发到中断处理，整理串口通信代码与延时、显示等模块的配合方式。
8. [51 单片机学习笔记：蜂鸣器](/10170653/) — 用 51 单片机驱动蜂鸣器，逐步调整程序并使用定时器模拟门铃。
9. [51 单片机学习笔记：PWM](/9e7d6ad0/) — 51 单片机 PWM 学习笔记，记录脉宽调制与输出控制的 C 语言实验代码。
10. [51 单片机学习笔记：I²C 通信](/6a750119/) — 整理 51 单片机 I²C 通信的实验代码，包括延时、通信模块、头文件与主程序。
11. [51 单片机学习笔记：SPI 通信](/84abc641/) — 整理 51 单片机 SPI 通信的实验代码，按延时模块、通信模块和主程序拆分文件。
