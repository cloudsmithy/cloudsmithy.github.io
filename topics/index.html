懒猫微服

刚拿到微服，可以先熟悉硬件和远程登录，再配置家人的账户。准备移植应用时，从开发知识清单开始。

  1. 开箱初探，认识硬件与系统先了解机器的接口、配置与系统环境。
  2. 开启 SSH，配置免密登录建立远程管理入口，方便后续安装与排查。
  3. 多用户管理、权限控制与数据隔离给家人分别配置账户和可以使用的应用。
  4. 上架应用前，需要掌握哪些知识梳理 npm、Linux、Docker 和网络基础，再进入应用开发。

  1. Easysearch 上手：部署与基本操作建立学习环境，了解节点、索引和基本使用方式。
  2. 用 INFINI Console 管理与观察集群查看集群状态、监控数据和管理入口。
  3. 理解 HTTP、HTTPS 与认证配置梳理初始化信息、证书和访问认证的关系。
  4. 使用 S3 进行快照备份与还原从配置快照仓库到执行备份、恢复和排查错误。
